# 05 · 股权治理 — SharpLink Gaming (SBET)

**Phase 5 · 数据截止 2026-07-24**

---

## 一、结论：本报告最反直觉的判断

**治理评分：3.0 / 5 —— 这是本报告五个维度中评分最高的一项（除估值外）。**

在一个所有指标都指向"极端风险"的公司里给治理 3.0 分，需要论证。理由是：

> **DAT 载体的治理只有一个真正的考题：在折价状态下，你还继续增发吗？**
> **BMNR 的答案是继续（季度股本 +21.37%）。SBET 的答案是停止、回购、并且只在溢价处发行。**

这不是"好治理"的绝对标准，而是**相对于同业的、在唯一重要的考题上答对了**。

### 内部人持股 3.54% 的解读

$4,010 万的内部人持仓，在一家 15 人公司里，意味着**平均每人的账面持仓价值可能达数百万美元**（若集中在少数创始人/高管则更高）。

**这是一个真实的利益绑定。**对比 BMNR 的 0.76%（$7,235 万分散在 603M 股中，占比极低），SBET 的内部人对股价的敏感度高 4.7 倍。

**但必须扣分的地方**：内部人持股中有多少是**通过 SBC 无偿授予的**、而非自掏腰包买入的？数据源未披露。考虑到 FY2025 SBC 高达 $3,521 万（约占当时市值 $17.58 亿的 2.0%），**很可能相当部分的 3.54% 来自无偿授予**。
→ **"利益绑定"的质量因此打折。**

⚠️ **尽调缺口**：stockanalysis.com 的 `/holders/` 页面返回 HTTP 404，SEC EDGAR 返回 HTTP 403。**本报告无法取得**：
- 具体的内部人名单与各自持股

- 前十大机构股东名单
- 13D/13G 举牌情况（尤其是 Joe Lubin 的持股）

### Joe Lubin 关联的双面性

**正面（这是 SBET 相对其他 DAT 的唯一软性差异化）：**
1. 以太坊联合创始人的直接参与，赋予 SBET"ETH 生态内部人"地位
2. **这最可能解释了 7 家券商全部给出 Buy/Strong Buy、零 Hold/Sell 的异常一致性**（详见 06_Market_Sentiment.md）
3. 提供了 Galaxy $1.25 亿链上收益基金这类机构级合作的入口
4. 若 SBET 未来能从"持币者"转型为"资产管理人"，Lubin 的网络是唯一可信的路径

**负面（这是本次尽调最严重的未核实风险）：**

围绕 Lubin 存在一个交叉关联的实体网络：

| 实体 | 与 SBET 的关系 | 潜在利益冲突 |
|---|---|---|
| **Ethlabs** | **由 Bitmine、SharpLink 与 Joe Lubin 共同出资** | SBET 的资金投向了一个 Lubin 也个人出资的实体。**估值如何确定？谁受益？** |
| **BMNR (Bitmine)** | 与 SBET 共同出资 Ethlabs | **名义竞争对手实际是共同投资人** —— 这削弱了同业对比的独立性 |
| **EthSystems** | 公告同时提及 SBET 与 BMNR | 同上 |
| **Ethereum Institutional** | 作为独立非营利组织成立（25 天前） | 关系未明 |
| **Galaxy Digital** | 计划与 SBET 合作发行 $1.25 亿链上收益基金 | 费用分成条款未披露 |
| **ConsenSys**（Lubin 创办） | 数据源未提及，但存在天然关联 | 若有服务/托管协议，属关联交易 |

🔴 **核心问题：SBET 的 ETH 由谁托管、由谁质押？**
若答案是 ConsenSys 或任何 Lubin 关联实体，则存在**每年可能达数百万美元的关联交易**，且是股东无法评估的。

**这个问题的答案在 SEC 10-K 的"Related Party Transactions"章节和 DEF 14A 代理声明中，而两者本次均无法取得（EDGAR HTTP 403）。**

→ **本报告因此无法给治理超过 3.0 分**，即使资本配置表现优秀。

## 四、资本配置计分卡

**这是 DAT 治理的核心考场。**逐项打分：

| 决策 | 时间 | 金额 | 对每股 NAV 的影响 | 评分 |
|---|---|---|---|---|
| **在溢价期大规模增发买币** | FY2025 | +$31.30 亿 | 当时增值（mNAV > 1）；但买在 ETH ≈$3,400 高位 | **B−** |
| **在折价期停止净增发** | 2026 | 季度股本 +0.78% | 避免了持续价值毁灭 | **A** |
| **在 0.67× NAV 回购** | FY2025 $3,169 万 + 2026-06 的 210 万股 | ~$4,389 万 | **+约 $2,200 万 NAV 增值** | **A** |
| **按 41% 溢价定向增发 $7,500 万** | ~4 周前 | +$7,500 万 | −$494 万（vs 按市价发行的 −$3,770 万，**避免了 $3,276 万损失**） | **A−** |
| **在低位增持 13,741 枚 ETH** | Q2 2026 | ~$2,611 万 | 中性（等价交换），提高每股含币量 +0.5% | **B+** |
| **SBC $3,521 万 = FY2025 收入的 125%**（15 名员工） | FY2025 | −$3,521 万 | **每年侵蚀 NAV 2.02%**（TTM 已降至 0.98%） | **D** |
| **其他融资费用 $9,976 万** | FY2025 | −$9,976 万 | 募资 $31.3 亿的 3.2%（正常投行费率，但绝对额大） | **C** |
| **出售 $10,558 万投资** | FY2025 | +$10,558 万 | 若为卖 ETH 补现金 → 打破论点；若为处置遗留资产 → 中性 | **未知** |
| **从未派息**（也不该派息） | 全期 | — | 正确：一个折价 33% 的载体应该回购而非派息 | **A** |

### 三笔可量化操作的净影响

| 操作 | NAV 影响 |
|---|---|
| 回购（累计约 $4,389 万，在 ~0.67× NAV） | **+$2,200 万** |
| $7,500 万溢价增发（0.94× NAV） | **−$494 万** |
| 增持 ETH | ~$0 |
| **小计（资本市场操作）** | **+$1,706 万** |
| 减：FY2025 SBC | **−$3,521 万** |
| 减：TTM SBC | **−$1,659 万** |
| **合计** | **−$3,474 万** |

🔴 **决定性发现：管理层通过精明的回购/增发为股东创造了约 $1,706 万的 NAV，但通过股权激励拿走了约 $5,180 万。**
**净结果：−$3,474 万，即每股 −$0.178。**

**这是本节最重要的量化结论：SBET 的资本配置技术是 A 级的，但薪酬自肥抹掉了全部成果还多。**

→ 治理评分因此从"技术表现的 4.0"降至 **3.0**。

| **折价期是否回购** | ✅ **是**（$3,169 万 + 210 万股） | 未见披露 | 未见披露 | **SBET** |

| 是否举债买币 | ✅ **零负债** | ✅ $132 万（≈0） | ❌ **$82.6 亿，净负债 −$60.5 亿** | **SBET / BMNR** |

| 机构持股 | 48.96% | 32.67% | **59.60%** | MSTR |

### 三家的治理定位

**MSTR** = 有真实业务（$4.90 亿软件收入）+ 最高机构认知度，但**举债 $82.6 亿买币**是最激进的杠杆决策。新闻标题印证风险：**"Strategy Valuation Drop Threatens Key Bitcoin Funding Engine"**。若 BTC 继续下跌，MSTR 面临债权人压力 —— 而 SBET 不会。

**BMNR** = 最极端的载体（3 名员工、$95.2 亿市值），且**在折价状态下仍以每季 +21.37% 的速度增发**。这是价值毁灭的教科书案例：在 0.79× NAV 发行，每募 $1 摧毁 $0.21 的 NAV。若持续一年（+21.37%/季 ≈ +118%/年），NAV/股 的侵蚀将是灾难性的。

**SBET** = 折价最深、规模最小、摊薄史最极端，**但当前的资本配置行为是三家中最正确的**，且**零负债**。

> **一句话总结：SBET 是"过去做得最差、现在做得最好"的那一家；BMNR 是"现在正在做错"的那一家；MSTR 是"结构性风险最大"的那一家。**

**"总股东回报率 −42,807.01%" 需要正确解读**：这个数字就是股本增幅的负值，反映的是**一年内的极端摊薄**，不是"股东亏了 42,807%"。
按实际经济结果计：**股东投入 ≈$30.46 亿 → 今日市值 $11.33 亿 = −62.8%**（详见 04_Financial_Quality.md 第五节）。

**不派息是正确的决策**：一个以 0.67× NAV 交易的载体，每 $1 用于回购能买回 $1.50 的 NAV，而每 $1 派息只值 $1。**回购的效率是派息的 1.5 倍。**管理层在这一点上做对了。
