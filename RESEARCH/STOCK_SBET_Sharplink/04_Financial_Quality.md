## 三、⚠️ 数据矛盾 #1 的独立裁决：哪张表的净利润是对的？

**矛盾陈述**：

| | 利润表 | 现金流量表 | 差异 |
|---|---|---|---|
| TTM 净利润 | **−$14.19 亿** | **−$28.38 亿** | **2.00×** |
| FY2025 净利润 | **−$7.346 亿** | **−$14.69 亿** | **2.00×** |

两个期间都恰好差 2.00 倍 —— 这不是随机误差，是**系统性的口径差异或数据源错误**。

### 用资产负债表恒等式独立裁决

**恒等式**：期末权益 = 期初权益 + 融资净额 + SBC − 累计亏损

| 项目 | 金额（百万） | 依据 |
|---|---|---|
| FY2024 末权益（估） | **+2** | FY2024 市值 $3M ÷ PB 1.51 |
| FY2025 融资现金流 | **+2,999** | 现金流量表 |
| FY2025 SBC（计入权益） | **+35** | 现金流量表 |
| TTM 融资现金流（Q1'26 部分，估） | ~0 | 与 FY2025 高度重叠 |
| TTM SBC 增量（估） | +10 | |
| **= 若无亏损的权益** | **+3,046** | |
| **实际期末权益** | **1,740** | 数据源 |
| **⇒ 推算累计亏损** | **−1,306** | 3,046 − 1,740 |

**对比两个候选值**：

| 候选 | 数值 | 与推算 −$1,306M 的差距 |
|---|---|---|
| **利润表 TTM** | **−$1,419M** | **−8.7%** ✅ |
| 现金流表 TTM | −$2,838M | **−117%** ❌ |
| 利润表 FY2025 | −$734.59M | 期间不完全可比 |

### ✅ 裁决：**利润表的净利润是可信的一方。**

**理由**：利润表的 −$14.19 亿与资产负债表恒等式推算的 −$13.06 亿仅差 8.7%（可由估计误差解释），而现金流量表的 −$28.38 亿会导致权益变为负值（$3,046M − $2,838M = $208M，远低于实际 $1,740M）。

**推测原因**：现金流量表的"净利润"行可能记录了 **ETH 的毛未实现损失**（未与已实现收益轧差），而"其他调整 +$482.76M" 正是把非现金部分加回。若把 −$2,838M + $482.76M = −$2,355M，仍不吻合，说明数据源在该行存在汇总错误。

**本报告全文采用利润表数字（TTM −$14.19 亿）**，并在 sources/bibliography.md 记录此裁决过程。

## 四、🔴 核心财务风险：现金跑道 0.61 年

### 计算

| 项目 | 数值 |
|---|---|
| 现金及等价物（2026-03-31） | **$1,688 万** |
| TTM 经营现金流 | **−$2,767 万** |
| 资本开支 | ≈$0（TTM 未披露，FY2025 仅 −$1 万） |
| **年现金消耗** | **$2,767 万** |
| **现金跑道** | **0.61 年 = 7.3 个月** |

### 根本原因：收入是 ETH，费用是美元

**这是理解 SBET 全部财务问题的钥匙。**

| 事实 | 数值 |
|---|---|
| TTM 收入 | **+$3,937 万** |
| TTM 毛利率 | **95.62%** |
| TTM 毛利润 | **+$3,765 万** |
| **TTM 经营现金流** | **−$2,767 万** |
| **收入到现金的"泄漏"** | **$6,532 万** |

**一家毛利率 95.62%、毛利润 $3,765 万的公司，经营现金流却是 −$2,767 万。**

对经营性公司，这种缺口意味着应收账款暴增或存货堆积 —— 是典型的财务造假红旗。
但对 SBET，原因是结构性且无害于"真实性"的：**质押奖励以 ETH 实物形式收取，会计上确认为收入，但不产生一分钱现金。**

→ **收入的 94% 从来没有变成现金。** 而 15 名员工的工资、审计费、法律费、上市维护费、托管费必须用美元支付。

### 这个问题只有三条出路，全部有代价

| 出路 | 代价 | 是否已发生 |
|---|---|---|
| **(a) 卖 ETH 换现金** | **打破"永久持有"的核心投资论点**；每次卖出都在低位实现亏损 | FY2025 已卖出 $10,558 万投资（"Proceeds from sale of investments"）⚠️ |
| **(b) 在折价处增发** | 每股 NAV 下降；按 0.67× NAV 发行，每募 $1 毁灭 $0.49 的 NAV | FY2025 增发 $31.30 亿（当时是溢价，属于正确操作） |
| **(c) 溢价定向增发** | 需要有买家愿意付溢价 —— 不可持续，依赖特定投资人关系 | **4 周前的 $7,500 万，41% 溢价** ✅ |

⚠️ **注意 (a) 已经发生过**：FY2025 现金流量表 "Proceeds from sale of investments **+$105.58M**"。
公司已经卖出过约 $10,558 万的投资。**这需要在下一份财报中确认是否为 ETH，以及是否是为了补现金。**

### $7,500 万增发后的跑道

$1,688 万 + $7,500 万 = $9,188 万 ÷ $2,767 万/年 = **3.32 年**

✅ **短期跑道问题已解决。**但注意：
1. 这依赖一次性的溢价定向增发，**不是可重复的机制**
2. 3.32 年后如果 ETH 仍在 $1,900 且折价仍在 33%，同样的问题会以同样的方式再来
3. 一致预期 FY2026E FCF **+$2,264 万**（转正），但见数据矛盾 #3 —— 该数字与同页 −$7.126 亿净利润无法调和，可信度低

**本报告判定：跑道从"紧急"降级为"结构性"。它不是 12 个月内的生存威胁，但它是折价存在的正当理由之一。**

## 五、摊薄的完整量化

### 股本变化

| 时点 | 股本 | 推算依据 |
|---|---|---|
| FY2021 | ~1.93M | 净亏 $55.64M ÷ EPS −$28.80 |
| FY2022 | ~0.207M | 净亏 $15.23M ÷ EPS −$73.56 |
| FY2023 | ~0.230M | 净亏 $14.24M ÷ EPS −$62.04 |
| FY2024 | **~0.366M** | 净利 +$10.10M ÷ EPS +$27.62 |
| FY2025 | ~99.7M | 净亏 $734.59M ÷ EPS −$7.37（加权平均） |
| **当前** | **195.08M** | 数据源 |

**FY2024 → 当前：0.366M → 195.08M = 533 倍。**
数据源报告的股本同比：**+42,807.01%**（一致）。

### 摊薄的经济后果

**测试**：若股本仍是 FY2024 的水平，今天的每股含 ETH 量会是多少？
886,725 ÷ 366,000 = **2.42 枚 ETH/股**（vs 实际 0.0045455 枚）
→ 但这是无意义的对比，因为那 533 倍股本换来了 886,725 枚 ETH（FY2024 时是 0 枚）。

**有意义的测试：募集的资本创造了多少价值？**

| 项目 | 金额 |
|---|---|
| FY2025 发行普通股募集 | **+$31.30 亿** |
| 减：回购 | −$0.317 亿 |
| 减：其他融资 | −$0.998 亿 |
| **= 净募集** | **+$29.99 亿** |
| 加：FY2024 末权益 | +$0.02 亿 |
| 加：累计 SBC | +$0.45 亿 |
| **= 股东投入的总资本** | **≈$30.46 亿** |
| **今日股东权益（NAV）** | **$17.40 亿** |
| **今日市值** | **$11.33 亿** |
| **按 NAV 计的资本损失** | **−42.9%** |
| **按市值计的资本损失** | **−62.8%** |

🔴 **股东投入约 $30.46 亿，今日 NAV $17.40 亿、市值 $11.33 亿。按市值计已损失 62.8%。**

**这是本报告最重要的历史事实**：不是"股价跌了 77%"，而是**"投入的真金白银损失了 63%"**。
两者不同：股价跌幅受股本变化污染，资本损失率不受。

### 但归因必须准确

| 损失来源 | 占比 | 是否管理层责任 |
|---|---|---|
| ETH 价格下跌（$3,400 → $1,900，−44%） | **~68%** | 部分。买入时机由 DAT 模式的结构决定（溢价期才能增发，而溢价期=币价高点） |
| 折价扩大（1.0× 或以上 → 0.67×） | **~26%** | **不是管理层责任**，是全行业现象（MSTR 0.87、BMNR 0.79） |
| 现金消耗 + SBC 累计（≈$0.45 亿 + $0.5 亿） | **~3%** | **是管理层责任** |
| 其他融资费用 $0.998 亿 | **~3%** | **是管理层责任**（募资 $31.3 亿付出 $1 亿费用 = 3.2%，属正常投行费率） |

→ **约 94% 的损失来自 ETH 价格与行业折价，约 6% 来自管理层可控的成本。**
→ 这个归因很重要：它说明 **SBET 的问题是"买了一个下跌的资产"，不是"管理层挥霍"**。

## 八、传统财务指标的"无意义"标注（必读）

| 指标 | 数值 | 为何无意义 |
|---|---|---|
| **ROE** | −163.06%（Statistics）/ −68.27%（Ratios） | 分子是 ETH 浮亏，不是经营亏损。ETH 涨则 ROE 变成 +100%，跌则 −100%。**它测量的是币价，不是资本效率** |
| **ROA** | −101.44% / −68.00% | 同上 |
| **ROIC** | −101.80% / −69.08% | 同上。"投入资本回报率"对一个买币持有的载体没有定义 |
| **ROCE** | −81.54% / −68.19% | 同上 |
| **WACC** | **61.87%** | **算术产物**：由 Beta 10.48 推出。用 61.87% 做任何折现都会得到荒谬结果。**这是 DCF 完全不适用的直接证明** |
| **EBITDA / EBIT** | −$14.2 亿 | 主要是 ETH 浮亏，与"经营性盈利能力"无关 |
| **PE** | n/a（亏损） | 分母无意义 |
| **Altman Z-Score** | **198.77** | **荒谬。**因为负债≈0，Z 分数公式的分母趋于 0。**不代表"极度安全"** |
