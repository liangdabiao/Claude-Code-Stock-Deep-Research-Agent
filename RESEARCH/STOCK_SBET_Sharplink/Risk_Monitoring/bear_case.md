**数据截止 2026-07-24**

## 核心熊市论点：折价融资死亡螺旋

**这是 SBET 唯一真正致命的风险，且它是自我强化的。**

### 螺旋的机制

```
现金跑道 0.61 年（TTM 口径）→ 现金即将耗尽
        ↓
必须融资（因为质押收益是 ETH 而非美元，付不了美元账单）
        ↓
但 mNAV = 0.67 → 只能以 NAV 的 67% 折价发行新股
        ↓
每融 $1，摊薄掉现有股东 $1.49 的 NAV（1 ÷ 0.67）
        ↓
每股 NAV 下降 → 股价进一步下跌 → mNAV 进一步下降
        ↓
下次融资折价更深 → 摊薄更严重
        ↓
        ⟲ 回到起点，加速
```

### 🔑 螺旋的数学

**假设公司每年需要 $4,000 万现金运营开支，通过折价增发筹集**：

| 年份 | mNAV | 需融资 | 摊薄的 NAV | 股本增加 | 每股 NAV | 股价（mNAV 递减） |
|---|---|---|---|---|---|---|
| 起点 | 0.67 | — | — | 195.08M | $8.72 | $5.81 |
| 1 | 0.65 | $4,000 万 | −$6,154 万 | +7.1M（+3.6%） | $8.36 | $5.43 |
| 2 | 0.62 | $4,000 万 | −$6,452 万 | +7.4M（+3.7%） | $7.98 | $4.95 |
| 3 | 0.58 | $4,000 万 | −$6,897 万 | +8.1M（+4.0%） | $7.55 | $4.38 |
| 4 | 0.53 | $4,000 万 | −$7,547 万 | +9.1M（+4.3%） | $7.06 | $3.74 |
| **5** | **0.48** | $4,000 万 | −$8,333 万 | +10.4M（+4.7%） | **$6.51** | **$3.12** |

**5 年后（假设 ETH 价格完全不变 $1,900）**：
| 项 | 起点 | 5 年后 | 变化 |
|---|---|---|---|
| 每股 NAV | $8.72 | **$6.51** | **−25.3%** |
| mNAV | 0.67 | **0.48** | −28.4% |
| **股价** | **$5.81** | **$3.12** | **−46.3%** |

🔴 **在 ETH 价格完全不变的情况下，折价融资螺旋可以让股价跌 46%。**
→ **这是熊市情景中最容易被忽略的部分：你可以在 ETH 不跌的情况下亏损一半。**

### ✅ 但公司已经在阻断这个螺旋（重要的反证）

| 管理层行动 | 证据 | 效果 |
|---|---|---|
| **回购而非增发** | 最近一季回购 210 万股 | ✅ 反向操作 |
| **仅在溢价时增发** | $75M 注册直接发行，**41% 溢价**定价 | ✅ 增值而非摊薄 |
| **股本季度增速 +0.78%** | vs BMNR +21.37% | ✅ 慢 27 倍 |
| **现金跑道从 0.61 → 3.32 年** | 出售部分 ETH / 现金管理 | ✅ 压力大幅缓解 |
| **每股 ETH +0.5%/季** | 官方披露 | ✅ 正增长 |

🔑 **本报告的核心判断：折价融资螺旋是最严重的风险，但管理层目前正在正确应对。**
→ **这是 2026-08-13 Q2 财报必须验证的第一件事。**
→ **若 Q2 股本 > 205M（即恢复摊薄），本熊市情景立即成为主线论点，估值分项应从 4.0 降至 1.5，整体从 1.90 降至 ~1.4。**

## 详解各情景

### 情景 1：ETH 熊市延续（概率 25%）

**触发**：ETH 从 $1,900 跌至 $1,200（−36.8%）

| 项 | 数值 |
|---|---|
| NAV/股 | 0.0045455 × 1200 + 0.0865 = **$5.54** |
| mNAV（恐慌扩大） | **0.60** |
| **股价** | **$3.33** |
| **跌幅** | **−42.7%** |

🔑 **注意非线性**：ETH 跌 36.8%，股价跌 42.7%（放大 1.16×）。
**放大来自 mNAV 从 0.67 → 0.60 的同步恶化。**

**历史依据**：过去一年 ETHA −48.33% 时，SBET −77.49%（放大 1.60×）。
→ **本情景的 1.16× 放大系数是保守的。若沿用历史 1.60×，跌幅会是 −58.9%。**

**支持证据**：
- ETH 已从高位大幅回落（ETHA 52 周区间 $11.53–$36.80，当前 $14.04，接近低位）
- 新闻显示 2026 年中 BTC 已跌 33%（"Bitcoin Down 33% at Mid-Year 2026"）
- 加密市场处于下行周期

**反驳证据**：
- ETHA 当前 $14.04 已接近 52 周低点 $11.53（仅高 21.8%），下行空间已被部分消化
- BTC 近期回升至 7 周高位（"Bitcoin Climbs to 7-Week High"，3 天前）
- BTC 周期修复度 ≈23.8%（见 §02_Industry_Analysis）

### 情景 2：折价融资死亡螺旋（概率 15%）—— 最独特的风险

**已在上文详解。关键是：这个情景不需要 ETH 下跌。**

**触发条件的具体指标**：
| 指标 | 阈值 | 当前 |
|---|---|---|
| 股本 | **> 205M**（即 +5%/季） | 195.08M（+0.78%） |
| 现金余额 | < $1,000 万 | $1,688 万 |
| 是否在 mNAV < 1.0 时增发 | 是 | 否（41% 溢价发行） |

**为何概率仅 15% 而非更高**：管理层已展示了正确的行为（回购 + 溢价发行 + 跑道改善至 3.32 年）。
**为何不是 0%**：现金跑道 3.32 年不是无限；若 ETH 长期低迷，3 年后压力会重现。

### 情景 3：ETHA 获批质押（概率 20%）—— 最被低估

| 项 | 变化前 | 变化后 |
|---|---|---|
| ETHA 净年化成本 | −0.25% | **+2.75%（正收益）** |
| SBET 净年化成本 | −0.25% | −0.25% |
| **SBET 相对劣势** | **0%** | **−3.00%/年** |
| 合理年化折价率 | −5.25% | **−8.25%** |
| **5 年合理 mNAV** | **0.774** | **0.670** |
| 对应合理股价 | $6.75 | **$5.84** |

🔴 **这个情景不会让股价下跌，但会让当前的 0.67 折价从"便宜"变成"公允"。**
→ **上行空间从 +30.3% 归零。**
→ **这是最危险的情景，因为它不表现为价格下跌，而表现为论点消失。**

**为何概率高达 20%**：美国 ETF 质押监管正在演进，多家发行人已提交申请。这是一个"何时"而非"是否"的问题。
⚠️ **本报告无法取得该监管进程的一手资料，20% 为主观估计。**

### 情景 4：DAT 板块信用崩塌（概率 10%）

**触发链条**：
```
MSTR $82.6 亿债务 + BTC 下跌 → 触发债务契约
        ↓
MSTR 被迫抛售 BTC → BTC 大跌 → ETH 联动下跌
        ↓
市场判定"DAT 模式失败" → 全板块 mNAV 重估
        ↓
SBET mNAV 跌至 0.42（低于 52 周低点隐含的 0.51）
```

| 项 | 数值 |
|---|---|
| ETH | $1,400 |
| NAV/股 | $6.45 |
| mNAV | **0.42** |
| **股价** | **$2.62** |
| **跌幅** | **−54.9%** |

**证据**：新闻 2026-06-29 PYMNTS 已明确指出 **"Strategy 估值下跌威胁关键的比特币融资引擎"**。
🔑 **这个风险与 SBET 自身经营完全无关，且不可对冲（除非不持有）。**
✅ **唯一的缓解：SBET 零负债，不会被迫抛售 ETH，可以熬过去（若现金跑道足够）。**

### 情景 5：双重打击（概率 20%）—— 最可能的实际路径

**这是本报告认为最现实的熊市路径 —— 温和的 ETH 下跌 + 温和的折价扩大。**

| 项 | 数值 |
|---|---|
| ETH | $1,520（−20%） |
| NAV/股 | **$6.99** |
| mNAV | **0.55**（本报告观察区间的上沿） |
| **股价** | **$3.85** |
| **跌幅** | **−33.7%** |

🔑 **ETH 只跌 20%，股价跌 33.7%（放大 1.69×）。这与历史观测的 1.60× 一致。**
→ **这个 1.6–1.7× 的下行放大系数，是 SBET 相对 ETHA 的核心成本。**

### 情景 6：极端 —— ETH → $800（概率 5%）

| 项 | 数值 |
|---|---|
| ETH | $800（−57.9%） |
| NAV/股 | $3.72 |
| mNAV | 0.50 |
| **股价** | **$1.86** |
| **跌幅** | **−68.0%** |

**在此情景下的公司存续性**：
| 项 | 状态 |
|---|---|
| 总负债 | **$0** → ✅ **不会破产** |
| NAV | $7.25 亿 → 仍远大于市值 |
| 现金 | $1,688 万 + 可出售 ETH → 可维持运营 |
| **结论** | **✅ 公司不会消亡，但股东可能亏损 68%** |

🔑 **零负债的价值在极端情景下最明显：SBET 不会归零，而 MSTR 在类似情景下有真实破产风险。**
