# 03 · 业务拆解 — SharpLink Gaming (SBET)

**Phase 3 · 数据截止 2026-07-24**

---

## 一、拆解的正确切口

对一家经营性公司，业务拆解要回答"利润从哪来、边际经济性如何、定价权在哪"。
对 SBET，这三个问题的答案分别是：**协议奖励 / 无边际概念 / 无定价权**。

**因此本节改为回答三个对 DAT 真正有意义的问题：**
1. **每股含币量（ETH per share）如何变化？** —— 这是 DAT 唯一的"经营绩效"指标
2. **质押收益能否被独立验算？** —— 这是收入真实性检验
3. **每一次融资/回购是增值还是毁灭价值？** —— 这是 DAT 唯一的"管理能力"体现

---

## 二、核心指标：每股含 ETH 量

### 当前值

| 项目 | 数值 | 计算 |
|---|---|---|
| ETH 持仓 | **886,725 枚** | 2026-06-30 公告 |
| 在外股本 | **195.08M 股** | |
| **每股含 ETH** | **0.0045455 枚** | 886,725 ÷ 195,080,000 |
| 每股净现金 | **$0.0865** | $1,688 万 ÷ 195.08M |
| **NAV/股公式** | **0.0045455 × ETH价格 + $0.0865** | |

### 验算这个公式

代入 ETH = $1,900：NAV/股 = 0.0045455 × 1,900 + 0.0865 = 8.636 + 0.087 = **$8.72**
数据源报告的 BVPS = **$8.73**（2026-03-31）
→ **偏差 0.1%。公式成立，且证明账面权益确实就是"ETH 市值 + 现金"。**

这是一个重要的验证：它同时确认了
(a) 会计上 ETH 按公允价值计量（ASU 2023-08）
(b) 除 ETH 与现金外，公司几乎没有其他有价值的资产或负债
(c) 联盟营销业务在账面上的价值 ≈ $0

### 每股含币量的历史变化 —— DAT 的真实"业绩"

| 时点 | ETH 持仓 | 股本 | 每股含 ETH | 变化 |
|---|---|---|---|---|
| FY2024 末 | 0 | ~0.366M | 0 | — |
| FY2025 末 | ~850,000（估） | 99.7M（估） | **~0.008526** | 起点 |
| Q1 2026 (3/31) | **872,984** | ~193M（估） | **~0.004523** | **−47%** ⚠️ |
| 2026-06-30 | **886,725** | 195.08M | **0.0045455** | **+0.5%** |

⚠️ **这张表是本节最重要的发现，但也是最不确定的。**
FY2025 末的股本（99.7M，由 EPS −$7.37 ÷ 净亏 −$7.346 亿反推，是**加权平均股数**而非期末股数）与 Q1 的期末股本不可直接比较，因此 **"−47%" 很可能是加权平均 vs 期末的口径差异，不是真实的每股含币量腰斩**。

**可信的部分**：Q1 2026 → 2026-06-30 期间，**每股含 ETH 量从 0.004523 上升至 0.0045455（+0.5%）**。
这个区间数据可靠（两个时点都是期末口径），并且它告诉我们一件确定的事：
→ **在折价状态下，SBET 最近一个季度做到了每股含币量正增长。**
→ 机制：回购 210 万股（降低分母）+ 增持 13,741 枚 ETH（提高分子）+ 溢价增发（增加分子多于分母）。

**这是 SBET 相对 BMNR 的决定性差异**：BMNR 季度股本仍在 +21.37%，在折价状态下继续摊薄，其每股含币量必然在下降。

## 三、质押收益的可验证性检验（CoVe）

### 检验 1：FY2026E 一致预期能否被独立算式复现？

| 步骤 | 数值 |
|---|---|
| ETH 持仓 | 886,725 枚 |
| ETH 价格（推导） | $1,900 |
| 持仓市值 | $16.85 亿 |
| 以太坊全网质押 APY（假设） | 3.0% |
| **独立算出的年化质押收入** | **$5,054 万** |
| **券商一致预期 FY2026E 收入** | **$5,269 万** |
| 一致预期区间 | $4,940 万 – $5,830 万 |
| **偏差** | **+4.3%（且落在预期区间内）** |

✅ **通过。** 且注意：**独立算出的 $5,054 万落在券商区间 $4,940–5,830 万之内**，说明 5 家券商本质上都在做同一道乘法。

**推论（重要）**：
"FY2026E 营收 +87.80%" 这个增长率**不含任何经营性增长**。它 = 全年化效应（FY2025 只有部分年份持有 ETH）+ 持仓规模从 ~85 万增至 ~88.7 万枚。
→ **任何把 SBET 的 +87.80% 或 TTM 的 +1048.50% 当作"高成长"来给成长溢价的做法，都是把资产负债表扩张误读为损益表增长。**

### 检验 2：FY2025 分部收入能否复现？

| 步骤 | 数值 |
|---|---|
| ETH 金库分部 FY2025 收入 | **$2,559 万**（数据源披露） |
| FY2025 期间平均持仓（估） | ~40 万枚（从 0 爬升至 ~85 万，近似取半） |
| FY2025 期间 ETH 均价（估） | ~$3,000 |
| 平均持仓市值 | ~$12 亿 |
| × 3% APY × 持有期占比（估 0.7 年） | **$2,520 万** |
| **偏差** | **−1.5%** |

✅ **通过。** 两个独立年度的验算都成立，**质押收入的真实性可以确认。**

### 检验 3：TTM 收入 $3,937 万的隐含 APY 是否合理？

| 步骤 | 数值 |
|---|---|
| TTM 总收入 | $3,937 万 |
| 减：联盟营销 TTM | $230 万 |
| = 推断 ETH 金库 TTM 收入 | **$3,707 万** |
| 期间平均持仓（估） | ~87 万枚 |
| 期间 ETH 均价（估） | ~$2,400（Q2'25–Q1'26 下跌途中） |
| 平均持仓市值 | ~$20.9 亿 |
| **隐含 APY** | **1.77%** |

⚠️ **偏低。**若 ETH 均价取 $2,000，隐含 APY = 2.13%；若取 $1,700，则 2.50%。
以太坊主网质押 APY 在 2025–2026 年因全网质押量上升确实已降至 2.5–3.5% 区间，所以 **1.8–2.5% 略低但不至于不可能**（还需扣除流动性质押服务商的分成）。

**判定：通过，但边缘。** 这提示两件事：
1. 实际到手 APY 可能低于 3%（服务商抽成 / 部分仓位未质押）
2. **FY2026E 的 $5,269 万一致预期可能偏乐观 5–15%**。若真实 APY 是 2.5% 而非 3.0%，收入应为 $4,212 万（比预期低 20%）。

**这是本节发现的第一个实质性下调风险。**

## 四、"毛利率 95.62%" 的祛魅

### 数据矛盾 #5：两个毛利率

| 来源 | TTM 毛利润 | TTM 毛利率 |
|---|---|---|
| Statistics 页 | **$3,765 万** | **95.62%** |
| Financials 页 | **$21 万** | **0.53%** |

**相差 179 倍。**这是本次尽调发现的最严重数据矛盾之一。

**本报告的判定**：
- FY2025 两页一致（毛利润 $2,615 万 / 毛利率 93.22%），说明历史数据可靠
- TTM 列的 $21 万显然是数据源的 TTM 汇总错误（可能把 ETH 减值计入了成本行）
- **采用 95.62% 作为经济上正确的毛利率**，因为它与 FY2025 的 93.22% 连续，也与"持币收租无直接成本"的商业实质一致

### 但 95.62% 毛利率毫无意义

| 论断 | 说明 |
|---|---|
| 它不代表定价权 | 质押 APY 由以太坊协议参数与全网质押量决定，公司零影响力 |
| 它不代表效率 | 持有资产并领取协议奖励**本来就没有成本** |
| 它不可复制为竞争优势 | **任何持有等量 ETH 并质押的主体（包括个人钱包）都能得到同样的毛利率** |
| 它掩盖了真实的成本结构 | 真实拖累在毛利率下方：营业利润率 **−3,600.54%** |

**边际毛利率检验（本框架的常规工具）在此处失效且失效有意义：**
FY2024 → FY2025：Δ收入 = $2,440 万，Δ毛利润 = $2,524 万 → **边际毛利率 103.4%**（>100%）。
超过 100% 说明新增业务不仅零成本，还顺带回收了旧业务的成本。
→ **对经营性公司，边际毛利率 >100% 是极强的正面信号（规模效应）；对 SBET，它只说明"新增的收入是纯粹的资产收益，与经营无关"。**
→ **这是本报告刻意展示"常规工具在 DAT 上会给出误导性正面信号"的例子。**

## 五、成本结构拆解：钱花在哪

### 从毛利率 95.62% 到营业利润率 −3,600.54%

TTM：毛利润 $3,765 万 → 营业利润 **−$14.18 亿**。中间蒸发了 **$14.56 亿**。

**这 $14.56 亿是什么？**

| 成分 | 估计金额 | 依据 |
|---|---|---|
| **ETH 公允价值未实现损失** | **≈$14.2 亿** | 主体。ASU 2023-08 要求计入当期损益。持仓 ~87 万枚 × 成本 $3,400 → 市值 $1,900，浮亏 ≈$13 亿，量级吻合 |
| 股权激励（SBC） | **$1,659 万** | 现金流量表明确披露 |
| 现金运营费用 | ≈$4,000 万 | 由 OCF −$2,767 万 + 收入非现金性质倒推 |
| 折旧摊销 | **$0.4 万** | 几乎为零（无固定资产） |
| 所得税 | $223 万 | |

**决定性洞察：SBET 的"亏损"98% 是 ETH 的浮亏，不是经营亏损。**

**这有两个重要含义：**

**含义 1（正面）**：−$14.19 亿的净亏损**不消耗现金，也不代表经营失败**。它是持仓市值变化的会计记录。若 ETH 反弹，同一个机制会产出巨额"利润"。
→ **因此 PE、EPS、净利率、ROE 对 SBET 全部无意义。**FY2024 的 PE 0.28 与 ROE +122.28% 就是这个机制的反面（当年有 +$1,010 万的非经营性收益）。

**含义 2（负面）**：**真正需要担心的不是 $14 亿的账面亏损，而是那 ≈$4,000 万 的现金运营费用。**
这才是唯一真实消耗股东资源的部分，也是 0.61 年现金跑道的来源。

### 现金费用的绝对量级检验

15 名员工，年现金运营费用 ≈$4,000 万 → **人均 $267 万/年**。
加上 SBC $1,659 万 → 人均总薪酬相关+运营 ≈$375 万/年。

**这是极高的。**对比：
- 管理 $16.85 亿资产，年现金成本 $4,000 万 = **资产的 2.37%**
- ETHA 管理 $53.7 亿资产，费率 **0.25%**
- **SBET 的运营成本率是 ETHA 的 9.5 倍**

即使假设那 $4,000 万里有一半是一次性的（转型费用、法律、审计），常态化后仍是 **1.2% 的资产费率，即 ETHA 的 4.8 倍**。

→ **这是护城河 0.5/5 的量化核心：SBET 提供的产品（ETH 敞口）比竞品贵 5–10 倍，唯一的补偿是 3% 质押收益与 33% 折价。**

## 六、资本配置的逐笔拆解（DAT 的真实"经营"）

对 DAT 而言，管理层唯一能做的"经营决策"就是：**在什么价格增发、在什么价格回购、买多少币。**
以下逐笔量化最近三笔已披露的操作。

### 操作 1：回购 210 万股（2026-06-30 公告）

| 项目 | 数值 |
|---|---|
| 回购股数 | 2,100,000 股（"over 2.1 million"） |
| 估计回购均价 | ~$5.81（用报告日价格保守估计） |
| 现金支出 | **$1,220 万** |
| 买回的 NAV（按 $8.73/股） | **$1,833 万** |
| **NAV 增值** | **+$613 万** |
| 每股 NAV 增值 | **+$0.031** |
| 增值率 | 回购金额的 **+50.2%** |

✅ **在 0.67× NAV 回购，每花 $1 创造 $1.50 的 NAV。这是教科书级正确的资本配置。**

*注：FY2025 现金流量表显示全年回购 $3,169 万，说明回购是持续性政策而非一次性。*

### 操作 2：$7,500 万定向增发，"按约 41% 溢价定价"（约 4 周前）

| 项目 | 数值 |
|---|---|
| 募集金额 | $7,500 万 |
| 市价 | ~$5.81 |
| **发行价（41% 溢价）** | **~$8.19** |
| 发行股数 | **9.16M 股** |
| 发行价 vs NAV $8.73 | **0.94× NAV** |
| **NAV 摊薄** | **−$494 万** |
| 每股 NAV 摊薄 | **−$0.025** |

⚠️ **仍然摊薄，但只摊薄 6%。**若按市价 $5.81 发行同样金额，需发行 12.91M 股，NAV 摊薄将是 **−$3,770 万**（7.6 倍）。
→ **41% 溢价把摊薄从 −$3,770 万压到 −$494 万，避免了 $3,276 万的价值毁灭。**

⚠️ **口径不确定**："41% 溢价"未明确是相对市价还是相对某日均价。若是相对 NAV 的溢价（即发行价 $12.31），则是 **+$3,280 万的 NAV 增值**。本报告采用保守解读（相对市价）。

### 操作 3：增持 13,741 枚 ETH（含 6 月的 10,000 枚）

| 项目 | 数值 |
|---|---|
| 增持数量 | 13,741 枚（872,984 → 886,725） |
| 估计成本（按期间均价 ~$1,900） | **$2,611 万** |
| 增持后每股含币量变化 | 0.004523 → 0.0045455（**+0.5%**） |

✅ **中性至正面。**用溢价募集的资金在币价低位买币，是飞轮的正确用法。

### 三笔操作合计

| 操作 | NAV 影响 |
|---|---|
| 回购 210 万股 | **+$613 万** |
| $7,500 万溢价增发 | **−$494 万** |
| 增持 13,741 枚 ETH | ~$0（等价交换） |
| **净影响** | **+$119 万（约 +$0.006/股）** |

**结论：在折价状态下，管理层做到了资本配置的 NAV 中性偏正。**
在一个"任何价格都增发"的行业里（BMNR 季度股本 +21.37%），这是 SBET 治理拿到 3.0/5 的唯一依据。（详见 05_Governance_Analysis.md）

## 七、一个思想实验：SBET 要值 $8.73（1.0× NAV）需要什么

| 需要发生的事 | 现状 | 差距 |
|---|---|---|
| 现金运营成本降至 ETHA 水平（0.25% 资产费率） | 2.37% | **需砍掉 89% 的现金费用** |
| 现金跑道 > 3 年 | 0.61 年（增发前） | 需要 $8,300 万现金（$7,500 万增发几乎刚好达到） |
| 停止一切净摊薄 | 季度 +0.78%（已接近停止） | **已基本达成** |
| 质押 APY 确认 ≥3% 且可持续 | 推算 1.8–2.5% | 需验证 |
| Galaxy $1.25 亿链上收益基金落地并贡献管理费 | "Plan to Launch" | 未落地 |
| 行业折价整体收窄（MSTR 回到 1.0×） | MSTR 0.87 | 依赖币价与情绪 |

**判定：**其中三项（停止摊薄、现金跑道、增持币量）**SBET 已经做到或接近做到**。
剩下三项（成本率、APY 验证、行业折价）**不在管理层控制范围内或需要重大结构变化**。
→ **合理 mNAV 应该在 0.67 与 1.0 之间，本报告基准取 0.77。**（详见 07_Valuation_Moat.md）
