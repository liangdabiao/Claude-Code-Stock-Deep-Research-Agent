# 现金流分析 — SharpLink Gaming (SBET)

**数据截止 2026-07-24**

---

## 一、本文件的核心问题

对经营性公司，现金流分析问的是"利润是否变成了现金"。
对 SBET，答案是**"没有，而且永远不会"** —— 但原因不是造假，是结构。

**本文件回答三个问题：**
1. 为什么毛利率 95.62%、毛利润 $3,765 万的公司，OCF 是 **−$2,767 万**？
2. 这 **$6,532 万的泄漏**是红旗还是结构性特征？
3. 公司靠什么活着，还能活多久？

---

## 二、OCF vs 净利润：常规检验在这里说明什么

### 常规的 OCF / NI 比率检验

| 年份 | 净利润（利润表） | OCF | **OCF/NI** | 常规解读 |
|---|---|---|---|---|
| TTM | −$1,419M | −$27.67M | **0.0195** | — |
| FY2025 | −$734.59M | −$17.54M | 0.0239 | — |
| FY2024 | **+$10.10M** | **−$22.81M** | **−2.26** | 🔴 盈利但现金流出 |
| FY2023 | −$14.24M | **+$0.58M** | −0.041 | — |
| FY2022 | −$15.23M | −$5.94M | 0.390 | — |
| FY2021 | −$55.64M | −$6.07M | 0.109 | — |

**常规解读会说**：FY2024 报出 +$1,010 万净利润却流出 $2,281 万现金 —— 典型的盈利质量红旗。
**正确解读**：FY2024 的 +$1,010 万来自一笔非经营性收益（可能是债务重组或资产处置，EPS +$27.62 而收入仅 $366 万），本来就不该产生现金。

**对 TTM 与 FY2025，OCF/NI ≈ 0.02 不是"利润没变成现金"，而是"利润根本不是现金流概念"** ——
净亏损 $14.19 亿中 98% 是 ETH 的未实现公允价值损失，它既不消耗现金也不产生现金。

→ **OCF/NI 比率对 SBET 完全失效。本文件改用「毛利润 → OCF」的桥接分析。**

## 三、⭐ 核心分析：毛利润 $3,765 万 → OCF −$2,767 万 的桥

| 步骤 | 金额（百万） | 说明 |
|---|---|---|
| **TTM 收入** | **+39.37** | |
| **TTM 毛利润（95.62%）** | **+37.65** | |
| **减：收入的非现金部分** | **−37.07** | ⭐ **质押奖励以 ETH 实物收取** |
| = 实际收到的现金收入 | **+0.58** | 仅联盟营销 $230 万的一部分 |
| 减：现金运营费用 | **≈−40.0** | 倒推值（15 名员工 + 上市/审计/法律/托管） |
| 减：所得税 | −2.23 | |
| 加：Δ 应付账款 | +4.93 | 延后付款 |
| 加：SBC 加回（非现金） | +16.59 | |
| 加/减：其他 | ≈+12.5 | |
| **= 经营现金流** | **−27.67** | |

### 🔑 决定性洞察

> **SBET 的收入 94% 从来没有变成现金。它以 ETH 的形式留在了资产端。**
> **而 15 名员工的工资、审计费、法律费、上市维护费、托管费必须用美元支付。**

**这个错配不是会计问题，是商业模式的结构：**
- 收入 = ETH（资产）
- 费用 = USD（现金）
- → **每一年，公司都在把资产负债表上的 ETH 换成损益表上的"收入"，同时用现金余额支付账单**

### 这是红旗还是结构？—— 判定：结构，但后果与红旗相同

| 判定维度 | 结论 |
|---|---|
| 是否是财务造假？ | **不是。**质押收益真实（3 项独立验算通过），只是形态是 ETH |
| 是否可持续？ | **不可持续，除非把 ETH 换成美元（即卖币）** |
| 是否有解决办法？ | 有：(a) 卖出质押收益部分的 ETH（每年约 $3,707 万，足以覆盖 $4,000 万的现金费用）(b) 持续融资 |
| 为什么公司不这么做？ | 因为"持有的 ETH 数量增长"是投资论点的核心 KPI。卖币会让每股含币量停止增长 |

🔑 **这里有一个尚未被市场充分讨论的洞察**：
**SBET 的年质押收益（≈$3,707 万）与年现金运营费用（≈$4,000 万）几乎完全相等。**
→ 如果公司选择**每年卖掉全部质押收益**来支付运营，它就能实现现金流平衡，**且 ETH 本金一枚不动**。
→ 代价是：ETH 持仓数量停止增长（当前每季 +0.5% 的每股含币量增长会归零）。
→ **这是 SBET 面临的真实权衡，也是"ETH 持仓数是否下降"成为最关键跟踪指标的原因。**

如果这是卖 ETH 补现金，则出路 (a) 已经在使用中，投资论点的核心（永久持有）已经被打破。

| FY2022 | $194 万 | $349 万 | 55.6% | — |

🔴 **FY2025：SBC $3,521 万 = 当年收入的 125.5%。公司有 15 名员工 → 人均 $234.7 万/年。**

**SBC 不消耗现金，但它 100% 消耗股东价值。**
对一个 NAV 载体，SBC 的经济含义特别直接：**它是把 NAV 的一部分无偿转给员工。**
- FY2025：**2.02% 的 NAV 被转移**
- TTM：**0.98%**（已减半，是正面变化）

**在本报告的合理 mNAV 推导中，SBC 的 0.98% 是三大拖累之一**（另两项是现金运营成本 2.37% 与风险溢价）。

**累计**：FY2021–TTM 的 SBC 合计 **$5,581 万**。
对比：管理层通过折价回购 + 溢价增发创造的 NAV 约 **+$1,706 万**。
→ **净 −$3,875 万。资本配置技术的成果被薪酬完全抵消还多。**（详见 05_Governance_Analysis.md）

## 八、FY2025 现金流的特写：一个 $31.3 亿的单一年份

FY2025 是 SBET 唯一有意义的现金流年份。逐行读它：

| 项目 | 金额（百万） | 解读 |
|---|---|---|
| 发行普通股 | **+3,130** | 在溢价期（mNAV > 1）发行 —— **当时是正确的** |
| 回购普通股 | **−31.69** | 同年也在回购 —— 说明后半年已进入折价期 |
| 其他融资 | **−99.76** | 募资 $31.3 亿的 **3.19%** —— 正常投行费率 |
| 融资现金流 | **+2,999** | |
| 购买投资 | **−3,060** | 几乎把募到的钱全部买了 ETH（102% 的募资额） |
| 出售投资 | **+105.58** | ⚠️ 用途未披露 |
| 投资现金流 | **−2,954** | |
| 经营现金流 | **−17.54** | |
| **净现金流** | **+27.03** | 现金余额从约 −$1,015 万增至 $1,688 万 |

### 三个观察

**观察 1：募资 $31.30 亿，买币 $30.60 亿 = 97.8% 的资金效率。**
只有 2.2% 留在了公司。这解释了为何现金跑道只有 0.61 年 —— **管理层把几乎全部资金都投入了 ETH，没有留足运营储备。**
这是一个**激进但内部一致**的决策：如果你相信 ETH 会涨，留现金是浪费。

**观察 2：融资费用 3.19% 属于正常水平。**
中小盘公司的 ATM/follow-on 承销费率通常 3–6%。$9,976 万虽然绝对额大，但**不是滥用**。

**观察 3：同一年既发行 $31.30 亿又回购 $3,169 万。**
这不矛盾 —— 它精确记录了 FY2025 内 mNAV 从溢价翻转到折价的时点。
**发行发生在溢价期，回购发生在折价期。这是正确的顺序。**

## 九、与同业的现金流对比

| 指标 | **SBET** | **BMNR** | **MSTR** |
|---|---|---|---|
| OCF | **−$2,765 万** | −$2.93 亿 | −$5,086 万 |
| FCF | **−$2,767 万** | −$2.95 亿 | −$8,829 万 |
| 现金余额 | **$1,688 万** | **$3.40 亿** | **$22.1 亿** |
| 总债务 | **零** | $132 万 | **$82.6 亿** |
| 净现金/(净负债) | +$1,688 万 | +$3.39 亿 | **−$60.5 亿** |
| **现金 ÷ 年消耗（跑道）** | **0.61 年** 🔴 | **1.16 年** | **43.5 年** |
| 员工数 | 15 | 3 | 1,539 |

**三家全部经营现金流为负 —— 这是 DAT 商业模式的共同特征，不是 SBET 独有的问题。**

**但跑道差异巨大**：
- **MSTR** 有 $22.1 亿现金 + $4.90 亿软件业务收入 → 跑道 43.5 年（但有 $82.6 亿债务的利息压力）
- **BMNR** 有 $3.40 亿现金 → 1.16 年
- **SBET** 只有 $1,688 万 → **0.61 年（增发前），同业最短**

→ **这是 SBET 折价最深（0.67 vs BMNR 0.79 vs MSTR 0.87）的一个合理原因。市场对最短跑道要求最高折价，这是理性的。**
