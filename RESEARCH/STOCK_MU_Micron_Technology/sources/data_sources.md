## 四、本报告中「事实」与「推断」的区分

### 事实（有来源可核）
- 所有财务数字（来自 C 级聚合平台）
- 估值倍数与历史序列
- 分析师一致预期与目标价分布
- 业务分部名称、员工数、成立年份
- 新闻标题与日期（相对时间）

### 推断（作者判断，无直接来源）
| 推断 | 依据 | 置信度 |
|---|---|---|
| Cloud Memory 为当前利润主引擎 | 组织架构变化 + 毛利率跃升 + 股价对云厂商财报的联动 | 中高 |
| 行业处于周期顶部区域 | 毛利率/ROIC/资本开支/估值四项同时处历史极值 | 中高 |
| HBM 定价权高于标准 DRAM | 行业常识 + 认证壁垒 | 中高 |
| 资本开支将在 FY2027–28 转化为供给 | 半导体产能建设周期常识 | 高 |
| 边际营业利润率 ~93% | 由损益表数据直接计算 | 高（计算） |

### 假设（用于建模，非事实）
- DCF 中的正常化 FCF（$60B / $22B / $8B）
- WACC（9.5% / 10.5% / 12.0%）
- 永续增长率（3.5% / 2.5% / 2.0%）
- 情景概率（30% / 45% / 25%）
- 无风险利率 4.0%、股权风险溢价 5.0%

**所有假设均已在 `Valuation/dcf_analysis.md` 中显式列出并说明理由。**

## 五、方法论局限

1. **样本期过短**：估值分位基于 5 个财年，统计意义有限。理想应覆盖 10–15 年（含 2018、2019、2022 三轮周期）。
2. **无 A 级来源**：所有财务数据经第三方聚合，存在口径调整与重述风险。
3. **新闻仅到标题级**：未读全文，因此新闻类引用仅用于情绪判断，不作为事实依据。
4. **同业对比不完整**：缺少全球前两大 DRAM 厂商。
5. **无行业数据**：无 DRAM/NAND 价格指数、无市占率数据、无产能数据。
6. **单线程执行**：未使用多智能体交叉验证，降低了发现矛盾信息的概率。
