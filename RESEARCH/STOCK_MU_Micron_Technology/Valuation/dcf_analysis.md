# DCF 估值分析 —— Micron Technology（MU）

> ⚠️ **方法论前置声明**：对周期性重资产企业做单点 DCF 在方法论上是不可靠的，因为结果几乎完全由「正常化自由现金流」这一个假设决定。本节采用**三情景正常化法**，并**明确标注哪些是事实、哪些是作者假设**。所有输出均非目标价、非预测。

## 一、模型输入

### 事实基础（可核验）

| 项目 | 数值 | 来源 |
|---|---|---|
| 当前市值 | $1,040,115M | StockAnalysis 统计页 |
| 股本 | 1.13B 股 | 同上 |
| 净现金 | +$23.75B | 现金 26.02 − 债务 6.38 |
| TTM 自由现金流 | $26,172M | 现金流量表 |
| FY2026E 自由现金流（一致预期） | $49,550M | 分析师预测页 |
| FY2021–25 累计自由现金流 | $1,224M | 现金流量表 |
| FY2021–25 平均自由现金流 | $245M | 计算 |
| Beta（5Y） | 2.14 | 统计页 |

### WACC 推导（作者假设）

| 参数 | 取值 | 说明 |
|---|---|---|
| 无风险利率 | 4.0% | 假设值，需以当期 10Y UST 核实 |
| 股权风险溢价 | 5.0% | 常用假设 |
| Beta | 2.14 | 实测值 |
| **CAPM 股权成本** | **4.0% + 2.14×5.0% = 14.7%** | |
| 债务成本（税后） | ~4% | 净现金公司，权重极低 |
| **加权 WACC** | **≈14.5%** | 若严格按 CAPM |
| **本模型采用** | **9.5% / 10.5% / 12.0%** | 🔴 **低于 CAPM 结果** |

> **诚实披露**：严格按 Beta 2.14 计算的股权成本高达 14.7%，将使所有情景估值大幅低于下表。本模型采用 9.5–12% 的折现率，是为了**给多头情景以合理机会**（论点是 Beta 反映历史周期性，而 AI 需求可能降低未来波动）。若读者不接受这一让步，请将下表所有估值再下调 30–45%。

## 二、三情景 DCF

### 🐂 牛市情景：AI 存储范式转移

**核心假设**：HBM 长约化 + AI 资本开支多年可见，使自由现金流中枢永久抬升至接近当前峰值。

| 参数 | 取值 |
|---|---|

| WACC | 9.5% |
| 永续增长 | 3.5% |
| 经营价值 | 60.0 / (0.095 − 0.035) = **$1,000B** |
| + 净现金 | $23.8B |
| **股权价值** | **$1,024B** |
| **每股** | **$906** |
| vs 现价 | **−1.6%** |

### 🎯 基准情景：周期被拉长但未消失

**核心假设**：HBM 确实抬升了行业盈利中枢，但周期性仍在。取当前峰值 FCF 的约 45% 作为跨周期中枢。

| 参数 | 取值 |
|---|---|

| WACC | 10.5% |
| 永续增长 | 2.5% |

| **每股** | **$264** |
| vs 现价 | **−71.3%** |

### 🐻 熊市情景：均值回归

**核心假设**：产能过剩重现，FCF 回落至接近历史模式（但因 HBM 存在，高于 FY21–25 均值 $245M）。

## 四、敏感性分析（基准情景）

正常化 FCF × WACC 对每股价值的影响（含净现金 $21/股）：

|---|---|---|---|

> **读表方法**：要让 DCF 支持现价 $920.95，需要「正常化 FCF ≥ $60B **且** WACC ≤ 9.5% **且** 永续增长 ≥ 3.5%」三个条件同时成立。而 $60B 的正常化 FCF 高于分析师对 FY2026 峰值年的预期（$49.55B）。

## 五、结论

**在本模型的任何一组非极端假设下，$920.95 的股价都超过 DCF 内在价值。** 唯一能支持当前价格的路径，是相信 AI 已经把存储行业的自由现金流中枢**永久性**抬升到 $60B 以上 —— 相当于 FY2021–FY2025 五年总和（$1.22B）的 **49 倍**，且每年重复。

> ⚠️ **本节不构成投资建议。** DCF 结果对假设高度敏感；持不同假设的理性投资者可以得出完全相反的结论。本节的价值不在于给出价格，而在于**明确指出必须相信什么才能接受当前价格**。
