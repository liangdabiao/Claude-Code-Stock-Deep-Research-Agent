# 熊市情景分析 — Microsoft (MSFT)

**数据截止 2026-07-24 | 股价 $381.70 | 熊市目标价 $235（−38.4%）| 概率 25%**

---

## 一、熊市论点的核心

# 🔑 **熊市不需要微软"变差"。它只需要微软"保持现状再两年"。**

**这是微软熊市案例最危险的特征：它不依赖任何负面事件的发生，只依赖已经在发生的趋势不逆转。**

---

## 二、熊市的五个支柱

### 支柱 1：⭐⭐ 自由现金流转化率已经腰斩，且没有触底信号

| 财年 | FCF / 净利润 | 变化 |
|---|---|---|
| FY2021 | **91.59%** | — |
| FY2022 | 89.57% | −2.02pp |
| FY2023 | 82.19% | −7.38pp |
| FY2024 | 84.04% | +1.85pp |
| FY2025 | 70.32% | −13.72pp |
| **TTM** | **🔴 58.23%** | **🔴 −12.09pp** |

**五年累计下滑 33.36pp（−36.4%）。最近两年是下滑最快的两年。**

⚠️ **且 54 位分析师预期 FY2026 自由现金流 $644.7 亿 —— 比 TTM 的 $729.16 亿还低 11.6%。**
⚠️ **即：卖方自己预期这个下滑至少还要持续一年。**

**熊市推论：若 FY2027 的 FCF/NI 继续降至 50%，则报告口径 FCF 约 $650 亿，P/FCF 升至 43.7×（高于 5 年均值），股价需下跌以维持倍数。**

---

### 支柱 2：⭐⭐ 资本开支没有任何减速迹象

| 财年 | 资本开支（亿美元） | 增速 | 资本开支/折旧 |
|---|---|---|---|
| FY2021 | 206.2 | — | 1.76× |
| FY2022 | 238.9 | +15.8% | 1.65× |
| FY2023 | 281.1 | **+17.7%** | 2.03× |
| FY2024 | 444.8 | **🔴 +58.24%** | 2.00× |
| FY2025 | 645.5 | **🔴 +45.13%** | 1.89× |
| **TTM** | **972.3** | **🔴 +50.62%** | **🔴 2.23×** |

# 🔴 **最近三年增速：+58.24% / +45.13% / +50.62%。这不是减速，这是加速的高原。**

**六年累计资本开支超出折旧 $1,387.92 亿。**
**六年中没有任何一年资本开支/折旧接近 1.0（维护性水平）。**

**熊市推论：**
- 若 FY2027 资本开支再增 30% 至 $1,264 亿，OCF 即使增 15% 至 $1,957 亿，报告口径 FCF 仅 $693 亿 —— **五年零增长**。
- 反向 DCF 要求的 FY2030 FCF $2,280 亿（见 `Valuation/reverse_dcf_implied_growth.md`）将彻底失效。

---

### 支柱 3：⭐⭐ 折旧的"子弹"正在飞来

**已经投入但尚未计提折旧的资本，最终必须进入利润表。**

| 稳态折旧压力测试 | 数值 |
|---|---|
| 假设折旧最终追上当前资本开支水平 | D&A 从 $436.29 亿 → **$972.25 亿** |
| **税前利润冲击** | **🔴 −$535.96 亿** |
| 占 TTM 税前利润 $1,545.0 亿 | **🔴 −34.7%** |
| 税后冲击（税率 18.96%） | −$434.3 亿 |
| **调整后净利润** | $125,216M − $43,430M = **$818.8 亿** |
| **调整后 EPS** | **🔴 $10.95**（vs 当前 $16.79，**−34.8%**） |
| **按现价 $381.70 的隐含 PE** | **🔴 34.9×** |
| vs 5 年均值 PE 33.96 | **略贵** |

# ⭐⭐ **在稳态折旧下，微软的 PE 不是 22.73，而是 34.9 —— 比 5 年均值还贵。**
# 🔑 **"PE 便宜 33%"这个牛市论点，在稳态折旧下完全消失。**

⚠️ **关键限定：折旧是非现金支出，它打击利润表和 PE，但不打击自由现金流。**
⚠️ **所以这枚子弹只对"用 PE 估值"的投资者有效 —— 而市场已经换到现金流的靶场了（见 `Valuation/historical_multiples.md`）。**
🟡 **这使支柱 3 的杀伤力弱于支柱 1 和 2，但它摧毁了"PE 便宜"这个最流行的多头理由。**

---

### 支柱 4：⭐ ROIC 的价差在系统性压缩

| 财年 | ROIC | WACC | **价差** |
|---|---|---|---|
| FY2021 | **91.14%** | 10.10% | **+81.04pp** |
| FY2022 | 71.56% | 10.10% | +61.46pp |
| FY2023 | 51.60% | 10.10% | +41.50pp |
| FY2024 | 43.13% | 10.10% | +33.03pp |
| FY2025 | 37.18% | 10.10% | +27.08pp |
| **TTM** | **32.10%** | 10.10% | **🔴 +22.00pp** |

**五年压缩 59.04pp，即 −72.9%。**

**DuPont 拆解显示压缩来自哪里：**

| 分量 | FY2021 | TTM | 变化 |
|---|---|---|---|
| 税后营业利润率 | 33.71% | **37.93%** | **🟢 +12.5%** |
| **投入资本周转率** | **2.70×** | **🔴 0.85×** | **🔴 −68.5%** |

🟢 **好消息：ROIC 的下滑 100% 来自资本密度上升，0% 来自竞争侵蚀 —— 利润率反而在改善。**
🔴 **坏消息：若按当前速度线性外推，微软的 ROIC 将在约 8.9 年后触及 WACC。**

⚠️ **熊市不需要 8.9 年。它只需要市场开始按"价差 +22pp 且在下降"而不是"价差 +81pp"来定价。**

---

### 支柱 5：⭐ 股东回报正在被资本开支挤出

| 六年资本配置迁移 | FY2021 | **TTM** |
|---|---|---|
| **资本开支占比** | **28.08%** | **🔴 65.54%** |
| **股东回报占比（回购+分红）** | **59.79%** | **🔴 32.42%** |
| 净回购（回购 − 股权激励） | **$251.94 亿** | **🔴 $98.82 亿** |
| **净回购/市值** | **1.31%** | **🔴 0.35%** |
| 回购收益率 | 0.98% | **🔴 0.13%** |
| **股东总回报率** | 1.78% | **🔴 1.09%** |

# 🔴 **股价跌了 24.55%，但股东实际拿到手的现金回报率从 1.78% 降到了 1.09%（−38.8%）。**
# 🔑 **通常股价下跌会提高回购的性价比。微软反过来 —— 因为现金都去了数据中心。**

⚠️ **熊市推论：微软正在从"现金回报型蓝筹"变成"资本密集型成长股"。若这个身份转换被市场完全定价，估值体系应从"公用事业式 DCF"切换到"周期性资本开支公司"，倍数将进一步下移。**

## 三、熊市情景的量化路径

### 情景 B1：温和熊市 —— "再烧两年"（概率 15%）

| 假设 | 数值 |
|---|---|
| FY2027 资本开支增速 | +30%（至 $1,264 亿） |
| FY2027 OCF 增速 | +15%（至 $1,957 亿） |
| **FY2027 报告口径 FCF** | **$693 亿** |
| FCF/净利润 | 约 48% |
| 市场给予的 P/FCF | 5 年均值 40.95×（不再扩张） |
| **隐含市值** | $2.84 万亿 |
| **隐含股价** | **约 $382**（横盘） |

🟡 **注意：温和熊市的结果不是暴跌，而是"三年不涨"。这是最容易被低估的风险形态。**

### 情景 B2：估值体系切换（概率 7%）

| 假设 | 数值 |
|---|---|
| 市场把微软重估为"资本密集型公司" | P/FCF 从 38.89 降至 30×（FY2022 的 29.42 附近） |
| FY2027 FCF | $693 亿 |
| **隐含市值** | $2.08 万亿 |
| **隐含股价** | **🔴 约 $280（−26.6%）** |

### 情景 B3：云增长失速（概率 3%）

| 假设 | 数值 |
|---|---|
| Intelligent Cloud 增速从 20.8% 降至 10% | 营收增速降至 8% |
| 资本开支被迫停止但已投入资产开始满额折旧 | EPS 降至约 $11.5 |
| 市场给予成熟软件公司 PE 18× | |
| **隐含股价** | **🔴 约 $207（−45.8%）** |

**加权熊市目标价：**

$$\frac{382 \times 15\% + 280 \times 7\% + 207 \times 3\%}{25\%} = \frac{57.3 + 19.6 + 6.2}{0.25} = \mathbf{\$332}$$

⚠️ **本报告在 `00_Executive_Summary.md` 中采用的熊市价 $235，比这个加权值更悲观 —— 因为它对应的是"报告口径 DCF $226.06 + 少量缓冲"，即熊市论点全部成立的终局，而非加权平均。两者并存，读者可自行选择参照系。**

## 四、⭐ 熊市论点的自我检验（哪些论据其实很弱）

| 熊市论据 | 强度 | 反驳 |
|---|---|---|
| 自由现金流转化率腰斩 | **🔴 强** | 无有效反驳 —— 这是已发生的事实 |
| 资本开支无减速迹象 | **🔴 强** | 无有效反驳 —— 三年增速 +58%/+45%/+51% |
| 稳态折旧使 PE 升至 34.9× | 🟡 中 | 折旧不影响现金流；市场已换到现金流尺子 |
| ROIC 价差压缩 | 🟡 中 | 压缩 100% 来自资本密度，0% 来自利润率；价差仍有 +22pp |
| 股东回报被挤出 | 🟡 中 | 六年连续净还债 $264.14 亿，未举债扩张，纪律仍在 |
| **"会计造假"** | **🟢 弱 —— 已被证伪** | **OCF/净利润 = 1.359（六年最高）。若有盈余管理，该比值应 < 1** |
| **"应收账款注水"** | **🟢 弱 —— 已被证伪** | **应收账款增量/营收增量 = 16.2%，六年最低** |
| **"债务失控"** | **🟢 弱 —— 已被证伪** | **利息保障倍数 52.10；Debt/EBITDA 0.65；六年净还债** |
| **"客户流失"** | **🟢 弱 —— 已被证伪** | **递延收入连续六年正增长，累计 $313.57 亿** |

# ⭐ **诚实结论：微软的熊市案例只有两根真正的支柱（自由现金流转化 + 资本开支），其余都是软的。**
# 🔑 **而这两根支柱其实是同一根 —— 资本开支。**

✅ **这正是本报告给 🟡🟡🟡 而不是 🔴 的原因：单一根因、可观测、可证伪、且不涉及公司诚信或竞争力。**
