## 二、⭐ 增长的会计学：营收 +17.88%，自由现金流 +5.12%

| 指标 | TTM 增速 |
|---|---|
| 营收 | **+17.88%** |
| 毛利 | +12.13% |
| 营业利润 | **+15.89%** |
| 净利润 | **+22.96%** |
| **EPS** | **+29.83%** |
| 经营现金流 | **+30.17%** |
| **自由现金流** | **🔴 +5.12%** |

🔑 **注意这个序列的形状：从营收到经营现金流，每一层增速都在放大（+17.88% → +30.17%）。**
🔑 **然后在最后一层，坍塌到 +5.12%。**

**放大的原因（前五层）**：
- 营业利润率扩张（45.62% → 46.80%）
- 有效税率 18.96%（低于法定）
- **折旧摊销 $436.29 亿是非现金费用，压低了利润但不影响 OCF** ← 这是 OCF 增速 +30.17% 超过净利润 +22.96% 的主因
- 股本 −0.13%，EPS 增速（+29.83%）超过净利润增速（+22.96%）

**坍塌的原因（最后一层）**：
- 资本开支 $645.51 亿 → $972.25 亿，**+50.62%**

🔑 **一句话：折旧摊销让经营现金流看起来很好，但折旧摊销正是资本开支的会计影子。同一笔钱在现金流量表里被加回了两次的错觉。**

**严格验证这一点：**

| 财年 | OCF/净利润 | 折旧摊销 | 折旧摊销/营收 |
|---|---|---|---|
| FY2021 | 1.252 | $116.86 亿 | 6.95% |
| FY2022 | 1.224 | $144.60 亿 | 7.29% |
| FY2023 | 1.210 | $138.61 亿 | 6.54% |
| FY2024 | 1.345 | $222.87 亿 | 9.09% |
| FY2025 | 1.337 | $341.53 亿 | 12.12% |
| **TTM** | **1.359** | **$436.29 亿** | **13.71%** |

🔴 **OCF/净利润从 1.252 升到 1.359（看起来是盈利质量改善），但改善的全部来源是折旧摊销从 6.95% 升到 13.71% 的营收占比。**
🔑 **这是一个资本开支的伪装，不是盈利质量的改善。**
**任何只看 OCF/净利润的分析都会在微软这里得出完全错误的结论。**

### 推断：$972 亿资本开支几乎全部归属 Intelligent Cloud

**依据**：
1. P&BP 是软件订阅业务（M365、Teams、Exchange），资本开支需求低
2. MPC 是硬件/授权/搜索，资本开支需求中等且规模萎缩
3. AI 数据中心资本开支在定义上服务于云与 AI 推理/训练 → Intelligent Cloud

**若成立，则：**

| 项 | 数值 |
|---|---|
| Intelligent Cloud TTM 营收 | $1,283.63 亿 |
| 归属资本开支（假设 85%） | ≈$826.4 亿 |
| **资本开支 ÷ 该分部营收** | **≈64.4%** |
| 全公司口径（对比） | 30.55% |

🔑 **如果推断成立，Intelligent Cloud 每 $1 营收需要 $0.64 的年度资本开支。**
🔑 **这已经不是软件的经济学，而是电信/公用事业的经济学。**

**对照参考**：软件公司典型资本开支/营收 2%–5%；电信运营商 15%–20%；数据中心 REIT 30%+。
**微软的 Intelligent Cloud 在 64% 这个量级上，超过了所有传统重资产行业。**

⚠️ **这是一个推断，不是事实。** 但如果它大致成立，则意味着：
- **Intelligent Cloud 的长期稳态利润率将显著低于 P&BP**
- **公司整体 46.80% 的营业利润率会随着 IC 占比上升（34.42% → 40.33%）而结构性承压**
- ✅ **但当前营业利润率仍在上升（45.62% → 46.80%），说明这一效应尚未显现，或被 P&BP 的利润率扩张抵消**

## 四、定价权检验

**定价权的最严格证据不是毛利率水平，而是毛利率在成本冲击下的稳定性。**

| 财年 | 毛利率 | 营收增速 |
|---|---|---|
| FY2021 | 68.93% | +17.53% |
| FY2022 | 68.40% | +17.96% |
| FY2023 | 68.92% | +6.88% |
| FY2024 | **69.76%** | +15.67% |
| FY2025 | 68.82% | +14.93% |
| **TTM** | **68.31%** | **+17.88%** |

🔑 **六年毛利率区间：68.31% – 69.76%，波动幅度仅 1.45 个百分点。**
✅ **在营收增速从 6.88% 到 17.96% 大幅波动、业务结构从软件向云大幅迁移、AI 成本剧增的六年里，毛利率基本纹丝不动。**

**这是极强的定价权证据。**

⚠️ **但注意最后一行：TTM 68.31% 是六年最低。**
**且分析师预测 FY2026 毛利率 67.81%，将再降 0.50pp。**

🔑 **毛利率的方向已经转向下 —— 幅度很小（六年累计 −0.62pp），但这是 Intelligent Cloud 占比上升的第一个可见财务后果。**

### 交叉验证：营业利润率却在上升

🔑 **营业费用率从 27.34% 降至 21.51%，下降 5.83 个百分点 —— 这才是营业利润率扩张 5.21pp 的全部来源。**
✅ **微软在毛利率微降的情况下，通过营业费用（研发+销售管理）的规模效应实现了利润率扩张。**

### ⭐ ROIC 崩塌的杜邦分解

**ROIC ≈ 税后营业利润率 × 投入资本周转率**

| 财年 | 税后营业利润率* | **隐含投入资本周转率** | ROIC |
|---|---|---|---|
| FY2021 | 33.71% | **2.70×** | 91.14% |
| FY2023 | 33.85% | 1.52× | 51.60% |
| FY2025 | 36.97% | 1.01× | 37.18% |
| **当前** | **37.93%** | **🔴 0.85×** | **32.10%** |

*\*= 营业利润率 × (1 − 18.96% 税率)*

🔑 **利润率上升了（33.71% → 37.93%，+4.22pp），投入资本周转率崩了（2.70× → 0.85×，−68.5%）。**
🔑 **ROIC 崩塌 100% 来自资本密集化，0% 来自盈利能力恶化。**

✅ **这是一个至关重要的区分**：
- 如果 ROIC 崩塌来自利润率下降 → 竞争力问题 → 护城河受损 → 应大幅下调评级
- **实际来自资本周转率下降 → 商业模式重资产化 → 护城河未受损，但资本效率永久性降低**

🔑 **这就是为什么护城河仍给 4.5/5，而财务质量降到 3.5/5。**
