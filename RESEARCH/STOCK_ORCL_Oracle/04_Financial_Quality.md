## 二、🔴 发现一：五年股东回报 100% 来自借债

这是本报告最重要的发现，且是**纯算术，不含任何假设**。

### 现金流量表五年汇总（百万美元）

| 项目 | FY2022 | FY2023 | FY2024 | FY2025 | FY2026 | **五年累计** |
|---|---|---|---|---|---|---|
| 经营现金流 | 9,539 | 17,165 | 18,673 | 20,821 | 31,977 | **98,175** |
| 资本开支 | −4,511 | −8,695 | −6,866 | −21,215 | −55,663 | **−96,950** |
| **自由现金流** | **5,028** | **8,470** | **11,807** | **−394** | **−23,686** | **+1,225** |
| 股息 | −3,457 | −3,668 | −4,391 | −4,743 | −5,787 | **−22,046** |
| 回购 | −17,341 | −2,503 | −3,242 | −1,500 | −206 | **−24,792** |
| **股东回报合计** | | | | | | **−46,838** |

### 缺口与融资的对应

```
五年累计自由现金流          +$ 1,225M
五年累计股东回报            −$46,838M
──────────────────────────────────────
                    缺口   −$45,613M

五年净新增长期债务：
  FY2022  −8,250
  FY2023 +12,444
  FY2024  −3,500
  FY2025  +3,707
  FY2026 +39,151
──────────────────────────────────────
              合计          +$43,552M
```

> **缺口 $45,613M ≈ 净新增债务 $43,552M**（差额 $2,061M 由并购、投资处置、优先股等其他项目解释）

**结论**：**Oracle 过去五年支付给股东的 468 亿美元，本质上是借来的。** 这不是指控，这是现金流量表的算术结果。

### 为什么这很重要

一家公司可以在某一年用债务平滑股东回报——这是正常的资本管理。但**连续五年、累计 456 亿美元的缺口全部由债务填补**，意味着：

1. 股息的"可持续性"不是由经营现金流支撑的，而是由**融资渠道的可得性**支撑的
2. 一旦信用市场收紧（**债券收益率已在跳升**），股息政策将面临直接压力
3. 12 年连续增长的股息记录，在最后五年是**用杠杆维持的**

## 三、🔴 发现二：回购的崩塌是最诚实的压力信号

```
FY2022  −$17,341M  ████████████████████████████████████████
FY2023  −$ 2,503M  ██████
FY2024  −$ 3,242M  ███████
FY2025  −$ 1,500M  ███
FY2026  −$   206M  ▌                            ← −98.8%（相对 FY2022）
```

**回购是所有资本配置项里最容易砍掉的**（不像股息，砍了会被市场惩罚；不像资本开支，砍了会失去战略窗口）。

**回购从 $173 亿降到 $2.06 亿，是管理层在用行动告诉市场：现金非常紧张。**

同时：
- 股息**仍在增长**（$5,787M，+22%）
- 流通股 YoY **+1.68%**（回购停止后，SBC 开始净稀释股东）

| 财年 | 回购 | 股份变动 |
|---|---|---|
| FY2022 | −$17,341M | 大幅减少 |
| FY2026 | −$206M | **+1.68%（稀释）** |

**SBC 是 $4,811M/年，而回购只有 $206M。** 这意味着股权激励正在净稀释股东，且不再被回购对冲。

## 四、🔴 发现三：首次发行优先股

FY2026 融资活动中出现一行历史上从未有过的科目：

```
Preferred stock issued    +$4,954M
```

**Oracle 有史以来第一次发行优先股。**

**为什么重要**：一家投资级、市值曾达 $6,500 亿的公司发行优先股，通常意味着：
- 普通债务的边际成本已经不划算
- 或评级机构对进一步举债的容忍度接近极限
- 优先股在会计上可计入权益，**能改善 D/E 比率的表观数字**

⚠️ 这是一个**技术性但重要的信号**：公司在寻找不进一步恶化杠杆指标的融资方式。

### Altman Z-Score = 2.18 的含义

| 区间 | 含义 |
|---|---|
| Z > 3.0 | 安全区 |
| **1.8 < Z < 3.0** | **灰色区（不确定）** ← **Oracle 在这里（2.18）** |
| Z < 1.8 | 困境区 |

⚠️ **Altman Z 对科技公司的适用性有限**（模型建立在制造业样本上，对轻资产公司偏低估）。但 Oracle 现在**恰恰不再是轻资产公司**——$556.6 亿的年度资本开支已经把它变成了一家重资产企业。**在这个转型语境下，Z-Score 2.18 的警示意义反而增强了。**

### 利息负担测算

```
EBIT                    $20,606M
利息保障倍数            4.48
───────────────────────────────
隐含年度利息支出      ≈ $ 4,600M
```

**压力测试**：若 FY2027 再新增 $500 亿债务（为支撑 $880 亿资本开支所必需），按 6% 利率：

```
新增利息           = $50,000M × 6% = $3,000M
预计总利息         = $4,600M + $3,000M = $7,600M
FY2027E EBIT      ≈ $27,000M（保守，考虑折旧上升）
───────────────────────────────────────────────
FY2027E 利息保障  ≈ 3.55   ← 从 4.48 降至 3.55
```

**利息保障跌破 3.0 通常是评级下调的触发线。** 按当前轨迹，Oracle 在 FY2028 前后可能触及。

## 六、盈利质量交叉验证

| 检验 | 计算 | 结果 | 判定 |
|---|---|---|---|
| OCF / 净利润 | 31,977 / 16,984 | **1.88** | 🟢 **优秀**（利润有现金支撑） |
| **FCF / 净利润** | −23,686 / 16,984 | **−1.39** | 🔴 **资本开支吞噬全部利润** |
| 净利润 / 营业利润 | 16,984 / 20,606 | 0.82 | 🟢 正常（差额为利息与税） |
| ROE | 53.38% | | ⚠️ **高 ROE 来自高杠杆，非高效率** |
| **ROIC** | **11.48%** | | 🟡 vs WACC 9.88%，利差仅 1.6pp |
| ROA | **6.51%** | | 🔴 **资产效率低**（重资产化的直接结果） |
| SBC / 营业利润 | 4,811 / 20,606 | 23.3% | 🟡 可接受 |

### 🔑 ROE 53.38% 的陷阱

用杜邦分解（近似）：
```
ROE = 净利率 × 资产周转率 × 权益乘数
    = 25.37%  ×   ~0.26   ×   ~8.1
```

**Oracle 的 ROE 53.38% 主要来自权益乘数（约 8 倍），不是来自经营效率。**

对照：
- ROA 只有 **6.51%**（MSFT 14.81%，GOOGL 12.96%）
- ROIC 只有 **11.48%**（MSFT 27.24%，GOOGL 24.93%，AMZN 13.49%）

**如果只看 ROE 53.38% 就认为 Oracle 是一家高效率公司，会得出完全错误的结论。**

## 九、必须承认的另一面（避免单向叙事）

本章的基调是负面的，但以下事实同样成立，不应被忽略：

1. **OCF/NI = 1.88 是优秀的**。Oracle 的利润是真金白银，不是应计操纵。这与 LITE（OCF/NI 0.50）形成鲜明对比。
2. **经营现金流增长 53.58%**，$319.8 亿是历史最高。核心业务在赚钱。
3. **营业利润率 30.59% 仍然优秀**，且五年持续改善（FY2022 25.74%）。
4. **资本开支是主动选择，不是被动困境**。Oracle 可以随时把资本开支砍到 $100 亿，立刻产生 $200 亿+ 的自由现金流——**这是一个战略赌注，不是经营失败**。
5. **递延收入 +$46.4 亿说明客户在预付**，需求侧有真实支撑。

> **正确的框架不是"Oracle 财务恶化了"，而是"Oracle 主动用财务安全边际换取了一个战略机会窗口"。问题只在于：这个交换的价格是否划算，以及安全边际还剩多少。**

**本报告的判断：安全边际已经很薄（Debt/EBITDA 5.60，ROIC−WACC 利差 1.6pp，Altman Z 2.18），且 FY2027 的资本开支预测显示消耗仍在加速。这个赌注还有 1–2 年的容错空间，之后就必须见到回报。**
