## 一、投资论点（三句话）

1. **Oracle 正在做一件真实的事**：把一家 79% 毛利率的数据库许可证公司，改造成一家资本密集的 AI 云基础设施公司。收入端已经见效——FY2026 增长 17.35%，是十年最快，FY2027 一致预期 +32.6%。

2. **代价是整个资产负债表**：FY2026 资本开支 **$556.6 亿**（FY2024 仅 $68.7 亿，两年 8.1 倍），自由现金流 **−$236.9 亿**，靠 **$460.9 亿新增长期债务 + $49.5 亿优先股（史上首次）** 填补。总债务达 **$1,674 亿**，Debt/EBITDA **5.60**。

3. **市场已经用脚投票**：股价 52 周 **−52.46%**，市值从 FY2026 末的 $6,502 亿跌至 $3,312 亿（**−49.1%**）。这次下跌**不是估值泡沫破裂，而是对商业模式的重新定价**——市场在问：这些资本支出到底能不能赚回成本？

## 三、决定一切的那个问题

> **AI 数据中心的资本开支，是"成长性资本开支"（一次性建成后收租），还是"维持性资本开支"（GPU 每 4–6 年报废，永远停不下来）？**

| 若是成长性资本开支 | 若是维持性资本开支 |
|---|---|
| 建设期结束后 FCF 爆发式转正 | FCF 永远为负或微薄 |
| 当前 PE 19.72 是便宜的 | 当前价格仍然贵 |
| 折旧上升被收入增长覆盖 | 折旧永久吞噬利润 |
| 目标价 $249 合理 | 股价还有下行空间 |

**本报告的判断：证据尚不足以下定论，但天平在向"维持性"倾斜。** 依据：

- 分析师预测 FY2027 FCF **进一步恶化至 −$477 亿**——建设期没有结束的迹象
- 毛利率从 79.08% 一路降至 65.82%，FY2027E 再降至 **60.10%**——云业务的单位经济结构性劣于旧业务
- ROIC 已从 FY2024 的 15.77% 降至 **11.48%**，而 WACC 为 **9.88%**——**利差只剩 1.6 个百分点**

## 四、五个不可回避的事实

### 事实 1：五年的股东回报，是借钱发的

| FY2022–FY2026 累计 | 金额 |
|---|---|
| 自由现金流 | **+$1,225M** |
| 股息 | −$22,046M |
| 回购 | −$24,792M |
| **缺口** | **−$45,613M** |
| **同期净新增长期债务** | **+$43,552M** |

差额 $45,613M 与新增债务 $43,552M **几乎完全吻合**。这不是巧合，这是资本配置的事实。

### 事实 2：资本开支强度是所有同业的近三倍

| 公司 | Capex | 经营现金流 | **Capex/OCF** |
|---|---|---|---|
| MSFT | $97.23B | $170.14B | **57%** |
| GOOGL | $132.40B | $185.68B | **71%** |
| AMZN | $151.00B | $148.53B | **102%** |
| **ORCL** | **$55.66B** | **$31.98B** | **174%** |

MSFT、GOOGL、AMZN 用经营赚来的钱建数据中心。**只有 Oracle 是借钱建的。**

### 事实 3：回购已被迫停止，股息仍在借钱发

| 财年 | 回购 | 股息 |
|---|---|---|
| FY2022 | **−$17,341M** | −$3,457M |
| FY2023 | −$2,503M | −$3,668M |
| FY2024 | −$3,242M | −$4,391M |
| FY2025 | −$1,500M | −$4,743M |
| **FY2026** | **−$206M（−98.8%）** | **−$5,787M（仍在增）** |

回购从 $173 亿塌到 $2.06 亿——**这是现金紧张最诚实的信号**。而股息还在涨（12 年连增），并且是借钱发的。这个组合不可持续。

### 事实 4：首次发行优先股

FY2026 发行 **$49.54 亿优先股**——Oracle 历史上第一次。当一家投资级公司开始发优先股，说明普通债务的边际成本已经不划算，或者评级机构的容忍度已到极限。

### 事实 5：分析师与市场的背离达到极端

| | 数值 |
|---|---|
| 当前股价 | **$114.99** |
| 分析师平均目标价 | **$249.24（+116.75%）** |
| 分析师最低目标价 | $145（仍比现价高 26%） |
| 评级分布（43 家） | 29 Strong Buy / 8 Buy / 5 Hold / 0 Sell / 1 Strong Sell |
| RSI | **27.43（超卖）** |
| 价格 vs 200 日均线 | **−38.6%** |

**43 家分析师里没有一家给"卖出"，最悲观的目标价也比现价高 26%，而股票跌了 52%。** 这种背离要么意味着极端的错杀机会，要么意味着卖方模型尚未消化资本开支的现实。

## 五、护城河评级：3.0 / 5

| 业务 | 护城河 | 说明 |
|---|---|---|
| **数据库 / 中间件** | **4.5 / 5** | 极高转换成本，企业核心系统迁移代价巨大，40 年积累 |
| **Fusion / NetSuite (SaaS)** | 3.0 / 5 | 真实的 ERP 转换成本，但面对 SAP、Workday、Salesforce 的充分竞争 |
| **OCI（云基础设施）** | **1.0 / 5** | **几乎没有护城河**。GPU 算力是商品，客户随时可迁移，价格是唯一变量 |
| **加权综合** | **3.0 / 5** | 老业务的护城河真实且深；新业务的护城河接近于零 |

⚠️ **战略悖论**：Oracle 正在把老业务（高毛利、宽护城河）赚的钱，投入到新业务（低毛利、无护城河）里。这在战略上可能是必要的（否则会被云时代淘汰），但在资本回报上是**从高 ROIC 业务向低 ROIC 业务的资本迁移**。

## 六、估值结论

| 方法 | 结果 |
|---|---|
| PE / Forward PE | 19.72 / 14.28 —— 十年最低分位，**表面便宜** |
| PEG | 0.50 —— 表面极便宜 |
| EV/EBITDA | 15.61（FY2026 为 26.09）—— 显著回落 |
| P/FCF | **无法计算（FCF 为负）** |
| **反向 DCF** | 市场隐含要求 **永续 FCF $326.7 亿/年**；当前 −$236.9 亿。**需要 $563 亿的现金流反转** |
| **三情景 DCF 概率加权** | **约 $142 / 股** |
| **相对现价 $114.99** | **+23%** |

**估值结论**：与 MU（周期极值）和 LITE（估值荒谬）不同，**ORCL 在当前价位上不是明显高估的**。DCF 概率加权中枢 $142 略高于现价 $114.99。

**但这个"上行空间"是由 20% 概率的牛市情景（$310）拉起来的，基准情景仅 $135，熊市情景 $45。这是一个赔率结构极不对称的赌注——不是安全边际。**

## 七、投资建议框架

### ❌ 不适合的投资者
- 追求确定性现金流回报的投资者（FCF 为负，股息靠借债）
- 保守型 / 低风险偏好投资者（Altman Z 2.18，信用风险真实存在）
- 无法承受 −60% 波动的投资者
- 需要 3 年内看到结果的投资者（资本开支周期尚未见顶）

### ⚠️ 可能适合的投资者
- 明确接受这是**高赔率二元赌注**而非价值投资的投资者
- 能持有 5 年以上、穿越整个资本开支周期的投资者
- 仓位控制在可承受完全损失范围内的投资者

### 🔑 最重要的一句话

> **不要因为 PE 19.72 就认为 Oracle 便宜。这家公司的市盈率之所以低，是因为它的盈利尚未被它已经花掉的 $556 亿资本开支的折旧所侵蚀。FY2027 起，折旧会开始报复性上升。**
