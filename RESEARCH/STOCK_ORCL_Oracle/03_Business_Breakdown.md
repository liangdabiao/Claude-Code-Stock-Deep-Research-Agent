## 一、用毛利率反推业务结构变化

这是本章节的核心方法：**在没有分部数据的情况下，毛利率的变化路径本身就是分部结构变化的指纹。**

| 财年 | 收入 | 毛利率 | 毛利 | 收入增量 | 毛利增量 | **边际毛利率** |
|---|---|---|---|---|---|---|
| FY2022 | 42,440 | 79.08% | 33,563 | — | — | — |
| FY2023 | 49,954 | 72.85% | 36,390 | +7,514 | +2,827 | **37.6%** |
| FY2024 | 52,961 | 71.41% | 37,818 | +3,007 | +1,428 | **47.5%** |
| FY2025 | 57,399 | 70.51% | 40,472 | +4,438 | +2,654 | **59.8%** |
| **FY2026** | **67,357** | **65.82%** | **44,336** | **+9,958** | **+3,864** | **38.8%** |
| FY2027E | 89,320 | 60.10% | 53,680 | +21,963 | +9,344 | **42.5%** |

**引用**：[stockanalysis.com, 2026-07-24, ORCL Financials, https://stockanalysis.com/stocks/orcl/financials/, Source Quality: B]

### 关键推断

**Oracle 的存量业务毛利率约 79%（FY2022 水平），而增量业务的边际毛利率只有 38–48%。**

FY2026 新增的 $99.6 亿收入，只带来 $38.6 亿毛利——**边际毛利率 38.8%，是存量业务的一半**。

**这就是"云"的真面目**：它带来收入，但它的单位经济与许可证业务完全不同。

### 推断的分部经济画像

| 业务 | 推断收入占比 | 推断毛利率 | 增长 | 性质 |
|---|---|---|---|---|
| 数据库许可 + 技术支持 | ~40–45% | **~85–90%** | 低个位数 | 🟢 **利润引擎** |
| 云应用 SaaS（Fusion/NetSuite） | ~20–25% | ~70–75% | 中双位数 | 🟢 健康 |
| **OCI 云基础设施** | **~20–25%** | **~30–40%** | **极高** | 🔴 **毛利稀释源** |
| 硬件 + 服务 | ~10–15% | ~40–50% | 下降 | 🟡 拖累 |

⚠️ **上表为推断，不是披露数据。** 但边际毛利率 38.8% 这个计算结果是**从披露数据直接算出的**，可信度高。

## 二、利润引擎的真相

### 谁在赚钱？谁在花钱？

```
【赚钱的业务】数据库 + 中间件 + 技术支持
  · 毛利率 ~85–90%（推断）
  · 资本开支需求：接近零
  · 护城河：4.5/5
  · 增长：低个位数
  · 现金流：极强，是全公司的现金来源
                ↓ 输血 ↓
【花钱的业务】OCI 云基础设施
  · 毛利率 ~30–40%（推断）
  · 资本开支需求：$556.6 亿/年
  · 护城河：1.0/5
  · 增长：极高
  · 现金流：极度为负
```

**这就是 Oracle 的战略本质：用一个高 ROIC、宽护城河的业务，为一个低 ROIC、无护城河的业务提供资本。**

### 这个战略是否合理？

**支持的理由**（不能忽视）：
1. **不做会死**。如果企业的工作负载全部迁移到 AWS/Azure/GCP，Oracle 的数据库业务最终会被云原生数据库（Aurora、Spanner、Snowflake）蚕食。自建云是**防御性的必要投资**。
2. **数据库 + 云的绑定确实创造价值**。跑 Oracle DB 的企业上 OCI 有真实的技术与成本理由。
3. **收入验证正在发生**。FY2026 有机增长 17.35%，递延收入 +$46.4 亿。

**反对的理由**：
1. **ROIC 正在下降**：15.77%（FY2024）→ 15.11%（FY2025）→ **11.48%（FY2026）**。资本正在从高回报业务流向低回报业务。
2. **WACC 是 9.88%**。利差只剩 **1.6 个百分点**。再降一点就是**价值毁灭**。
3. **规模劣势结构性存在**。AWS/Azure/GCP 的采购议价、能源合约、软件复用摊薄都优于 Oracle。

## 三、增量资本的回报测算（本报告核心计算）

这是判断 Oracle 的关键计算。

### 已投入与将投入的资本

| 期间 | 资本开支 |
|---|---|
| FY2025 | $21,215M |
| FY2026 | $55,663M |
| FY2027E（推算） | **~$88,000M** |
| **FY2025–FY2027 合计** | **~$164,878M** |

> FY2027E 推算方法：分析师预测 FY2027 FCF = −$47,730M。若 OCF 增至约 $40,000M（随收入增长 32.6%，按 FY2026 的 OCF/收入 47.5% 保守下调至 45%），则 Capex ≈ 40,000 + 47,730 ≈ **$87,730M**。

### 这些资本必须赚多少才不毁灭价值？

```
投入资本         ≈ $164,878M
WACC             = 9.88%
────────────────────────────────
所需年度 NOPAT   = 164,878 × 9.88% = $16,290M
所需年度 EBIT    = 16,290 ÷ (1 − 25% 税率) ≈ $21,720M
```

**即：这 $1,649 亿的资本开支，必须每年产生约 $217 亿的营业利润，才刚好达到资本成本。**

作为参照：**Oracle FY2026 全公司的营业利润是 $20,606M。**

> **换句话说：Oracle 必须让 OCI 业务产生一个"再造一个 Oracle"级别的营业利润，才能证明这轮资本开支没有毁灭价值。**

### 需要多少收入？

假设 OCI 成熟期营业利润率 25%（乐观，因为需承担全部折旧）：

```
所需 OCI 收入 = $21,720M ÷ 25% = $86,880M
```

**需要约 $869 亿的 OCI 年收入。** 而 Oracle FY2026 全公司收入是 $673.6 亿，FY2027E 是 $893.2 亿。

**这意味着**：OCI 必须成长到接近今天整个 Oracle 的规模，且维持 25% 营业利润率，这轮投资才刚好打平资本成本。

⚠️ **这不是说 Oracle 一定做不到。** AWS 今天的年收入量级远超这个数字。但这明确了赌注的规模：**这是一个需要 5–10 年、且必须全程不出错的赌注。**

## 四、定价权分析

| 业务 | 定价权 | 证据 |
|---|---|---|
| 数据库 / 技术支持 | 🟢 **极强** | 40 年提价历史，客户无法迁移，毛利率 85%+ |
| Fusion / NetSuite | 🟡 中等 | 订阅制提价能力，但有替代品 |
| **OCI** | 🔴 **极弱** | **GPU 算力是商品。客户比价、可多云部署** |

**关键证据**：如果 OCI 有定价权，在 AI 算力全球短缺、Nvidia GPU 一卡难求的 2025–2026 年，Oracle 的**毛利率应该上升**。

**实际结果：毛利率从 70.51% 降至 65.82%，预测再降至 60.10%。**

> **在自己产品最短缺的时候毛利率反而下降——这是"没有定价权"最硬的证据。**

对比 Micron（MU）：同样在 AI 周期中，存储涨价让它的毛利率冲上 58%+。**Oracle 没有拿到这个红利，因为它是算力的转售方，不是稀缺资源的拥有方。稀缺资源是 Nvidia 的 GPU 和电力，Oracle 只是把它们组装起来出租。**

## 五、客户经济学

### 已知的优质客户（政府/国防）

| 客户 | 金额 | 期限 | 年化 | 占 FY2026 收入 |
|---|---|---|---|---|
| 五角大楼 | 最高 $7B | 10 年 | $700M | 1.04% |
| 美国海军 | $3.31B | 5 年 | $662M | 0.98% |
| **合计** | $10.31B | — | **$1,362M** | **2.02%** |

**评价**：金额不大，但质量极高——政府合同违约风险低、期限长、且高度依赖 Oracle 的安全认证与合规能力，**AWS/Azure 难以简单替代**。这类业务是 Oracle 真实差异化的体现。

### 未知的关键风险：AI 客户集中度

⚠️ **本报告未能核实 Oracle 的 AI 算力客户集中度。**

**为什么这是最重要的未知**：

```
情形 A：OCI 收入分散在数百个企业客户
  → 风险可控，需求可持续

情形 B：OCI 收入高度集中于少数 AI 实验室
  → 单一客户的融资状况 = Oracle 的信用状况
  → Oracle 用债务建的资产，服务于同样在烧钱的客户
  → 风险叠加，是一条脆弱的链条
```

**如果是情形 B，Oracle 实质上是在为客户提供"表外融资"** —— 它借债建数据中心，客户用未来的融资来付租金。这条链上任何一环断裂，都会向上传导。

**这是投资者在做决定前必须自行查证的第一件事**（10-K「Concentration of Credit Risk」、RPO 明细、财报电话会）。

## 六、递延收入：可见性还是义务？

| 财年 | 递延收入变动 |
|---|---|
| FY2025 | +$154M |
| **FY2026** | **+$4,642M（30 倍）** |

**双面解读**：

| 🟢 正面 | 🔴 负面 |
|---|---|
| 客户预付现金，需求真实 | 这是**负债**，Oracle 必须交付 |
| 收入可见性大幅提升 | 若数据中心延期（威斯康星电力问题），面临违约 |
| 降低应收账款风险 | **美化了 FY2026 的 OCF**：$319.8 亿中 14.5% 来自此项 |

**调整后视角**：
```
FY2026 报告 OCF        $31,977M
减：递延收入贡献        −$4,642M
────────────────────────────────
"经营性" OCF           $27,335M
资本开支               −$55,663M
────────────────────────────────
调整后 FCF             −$28,328M  （比报告的 −$23,686M 更差）
```

## 七、业务拆解结论

| 结论 | 判定 |
|---|---|
| Oracle 有真实的利润引擎吗？ | 🟢 **有**。数据库业务毛利率 ~85%+，护城河 4.5/5 |
| 新业务的单位经济成立吗？ | 🔴 **边际毛利率仅 38.8%，且在下降** |
| Oracle 在 OCI 上有定价权吗？ | 🔴 **没有**。算力短缺期毛利率反而下降是直接证据 |
| 这轮资本开支需要多大回报？ | **约 $217 亿年度 EBIT ≈ 再造一个 Oracle** |
| 客户结构是否安全？ | ⚠️ **未知，且是最大风险点** |
| 战略是否必要？ | 🟢 是 |
| 战略是否会成功？ | ⚠️ **未知。这是一个二元结果** |
