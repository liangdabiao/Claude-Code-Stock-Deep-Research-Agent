# Oracle (ORCL) 历史趋势分析（FY2022–FY2026）

> 单位：百万美元 | 财年截止 5 月 31 日

---

## 一、五年叙事：从"稳定的现金牛"到"高杠杆的成长赌注"

| | FY2022 | FY2026 | 变化 |
|---|---|---|---|
| 收入 | 42,440 | 67,357 | **+58.7%** |
| 收入增速 | 4.84% | 17.35% | 🟢 加速 |
| **毛利率** | **79.08%** | **65.82%** | 🔴 **−13.26pp** |
| 营业利润率 | 25.74% | 30.59% | 🟢 +4.85pp |
| 净利润 | 6,717 | 16,984 | +152.9% |

| 市值 | 191,667 | 650,246 | +239% |

**一句话总结**：五年间 Oracle 收入增长 59%、利润增长 153%、资本开支增长 1,134%，自由现金流从 +$50 亿变成 −$237 亿，股价先涨 3.4 倍再跌 52%。

## 二、四个阶段

### 阶段 1：FY2022 — 现金牛的最后一年

```
收入增速  4.84%      低但稳定
毛利率    79.08%     软件业顶级水平
FCF       +$5,028M   健康
回购      −$17,341M  激进（占市值 9%）
Capex/OCF 47%        克制
```

**这一年的 Oracle 是一家典型的成熟企业软件公司**：低增长、超高毛利、大额回购。市场给 PE 29.84。

### 阶段 2：FY2023 — Cerner 收购年

```
收入增速  17.71%     🟢 收购驱动
现金收购  −$27,721M  Cerner
新增债务  +$33,494M  为收购融资
毛利率    72.85%     🔴 −6.23pp（Cerner 是低毛利业务）
FCF       +$8,470M   仍健康
```

**转折点**：Oracle 首次用大额债务进行战略性扩张。毛利率开始下滑。

### 阶段 3：FY2024 — 消化年

```
收入增速  6.02%      🔴 收购效应消退
Capex     $6,866M    暂时回落
FCF       +$11,807M  🟢 五年最高
净债务偿还 −$3,500M  在去杠杆
ROIC      15.77%     🟢 五年最高
```

**这是 Oracle 五年中财务状况最好的一年。** 如果故事停在这里，Oracle 会是一家优秀的价值股。

### 阶段 4：FY2025–FY2026 — AI 资本开支爆炸

```
              FY2025      FY2026
Capex        $21,215M    $55,663M    +162%
FCF            −$394M   −$23,686M
新增债务     +$3,707M   +$39,151M
优先股             —     +$4,954M    🔴 首次
回购          −$1,500M      −$206M    🔴 −98.8% vs FY2022
毛利率         70.51%      65.82%
股本变动            —      +1.68%    🔴 转为稀释
```

**Oracle 从"现金牛 + 回购"模式，切换为"举债 + 建云 + 稀释"模式。**

## 三、毛利率的结构性下滑（最重要的长期趋势）

| 财年 | 毛利率 | 同比变化 | 边际毛利率 |
|---|---|---|---|
| FY2022 | **79.08%** | — | — |
| FY2023 | 72.85% | −6.23pp | **37.6%** |
| FY2024 | 71.41% | −1.44pp | **47.5%** |
| FY2025 | 70.51% | −0.90pp | **59.8%** |
| FY2026 | **65.82%** | **−4.69pp** | **38.8%** |
| FY2027E | **60.10%** | **−5.72pp** | **42.5%** |

> 边际毛利率 = Δ毛利润 / Δ收入，用于反推增量业务的经济性（Oracle 未披露 OCI 分部毛利率）。

```
毛利率下滑轨迹：

FY2022  ███████████████████████████████████████ 79.08%
FY2023  ████████████████████████████████████    72.85%
FY2024  ███████████████████████████████████     71.41%
FY2025  ███████████████████████████████████     70.51%
FY2026  █████████████████████████████████       65.82%
FY2027E ██████████████████████████████          60.10%
                                                 ↓
                                          五年累计 −19pp
```

**含义**：新增的每一美元收入，只带来约 40 美分毛利，而存量业务是 79 美分。**Oracle 正在用低质量收入替换高质量收入的结构。**

**如果这个趋势延续到 FY2030，毛利率将跌破 50%——那时 Oracle 就不再是一家软件公司，而是一家基础设施租赁公司，应该用完全不同的估值倍数。**

## 四、利润率的分岔：毛利率跌，营业利润率涨

| 财年 | 毛利率 | 营业利润率 | 差额（费用率） |
|---|---|---|---|
| FY2022 | 79.08% | 25.74% | 53.34% |
| FY2023 | 72.85% | 26.21% | 46.64% |
| FY2024 | 71.41% | 28.99% | 42.42% |
| FY2025 | 70.51% | 30.80% | 39.71% |
| FY2026 | 65.82% | 30.59% | **35.23%** |

**费用率五年下降 18.1 个百分点。** 这是真实的运营效率改善（销售费用、管理费用摊薄）。

> 🟢 **对多头有利的证据**：Oracle 的营业利润率能在毛利率下滑 13pp 的情况下反而提升 4.85pp，说明管理层的成本控制能力很强。
>
> 🔴 **但**：费用率下降有极限。当毛利率降至 60.10%（FY2027E）时，若费用率无法继续下降，营业利润率必然见顶回落。**FY2026 营业利润率已从 FY2025 的 30.80% 微降至 30.59%——可能已经见顶。**

## 五、债务与股东回报的此消彼长

| 财年 | 净新增长期债务 | 回购 | 分红 | 自由现金流 |
|---|---|---|---|---|
| FY2022 | −8,250 | **−17,341** | −3,457 | +5,028 |
| FY2023 | +12,444 | −2,503 | −3,668 | +8,470 |
| FY2024 | −3,500 | −3,242 | −4,391 | +11,807 |
| FY2025 | +3,707 | −1,500 | −4,743 | −394 |
| FY2026 | **+39,151** | **−206** | −5,787 | **−23,686** |

```
回购金额（十亿美元）：

FY2022  █████████████████████████████████  17.34
FY2023  █████                               2.50
FY2024  ██████                              3.24
FY2025  ███                                 1.50
FY2026  ▏                                   0.21   ← −98.8%
```

**分红却持续增长（12 年连续增长记录）：**

```
FY2022  $3,457M
FY2023  $3,668M  +6.1%
FY2024  $4,391M  +19.7%
FY2025  $4,743M  +8.0%
FY2026  $5,787M  +22.0%   ← 在 FCF 为 −$237 亿时仍增长 22%
```

> 🔴 **FY2026 在自由现金流为负 $237 亿的情况下，将分红提高 22%。这只能靠借债实现。**
>
> **管理层为什么这么做？** 最可能的解释：中断 12 年连续增长记录会引发红利指数基金强制卖出，并被市场解读为财务困境信号。**分红已经变成一个不能后退的承诺——这本身就是风险。**

**两种解读：**
1. 🟢 **市场过度反应，现在是买点**（多头论点）
2. 🔴 **市场在重新分类：Oracle 不再是软件公司，而是资本密集型基础设施公司，理应用更低倍数**（空头论点）

**本报告倾向第 2 种，但承认第 1 种有真实概率**——见 [07_Valuation_Moat.md](../07_Valuation_Moat.md)。

## 七、趋势总结

| 趋势 | 方向 | 强度 |
|---|---|---|
| 收入增速 | 🟢 加速（4.84% → 17.35%） | 强 |
| 毛利率 | 🔴 结构性下滑（79% → 66% → 60%E） | **强** |
| 营业利润率 | 🟢 改善但可能见顶 | 中 |
| 净利润 | 🟢 快速增长 | 强 |
| **自由现金流** | 🔴 **崩塌（+$50 亿 → −$237 亿）** | **极强** |
| 资本开支 | 🔴 指数级增长（+1,134%） | **极强** |
| 债务 | 🔴 快速累积（$1,674 亿） | 强 |
| 回购 | 🔴 几乎停止（−98.8%） | 强 |
| 股本 | 🔴 从回购转为稀释（+1.68%） | 中 |
| ROIC | 🔴 持续下滑（15.77% → 11.48%） | 强 |
| 估值倍数 | 🟡 腰斩（PE 38.73 → 19.72） | 强 |

**核心趋势判断：Oracle 正在经历一次商业模式的转型。所有"增长"指标向好，所有"质量"指标恶化。这场转型的成败将在 FY2028–FY2029 见分晓。**
