## 三、五个决定性对比

### 对比 1：谁在用自己的钱建云？（Capex/OCF）

```
IBM     7%  █                   基本不投（已放弃云军备竞赛）
MSFT   57%  ███████████         自筹有余
GOOGL  71%  ██████████████      自筹有余
AMZN  102%  ████████████████████  刚好打平
ORCL  174%  ██████████████████████████████████  🔴 借钱建
```

**这是 Oracle 与超大规模云厂之间最本质的差异，也是本次同业对比中最重要的发现。**

MSFT 与 GOOGL 在投入同等甚至更大的绝对资本开支后，仍分别产生 **+$729 亿** 和 **+$533 亿** 自由现金流。Oracle 产生 **−$237 亿**。

**含义**：如果 AI 需求放缓，MSFT/GOOGL 只需减少投入就能立刻恢复巨额 FCF；**Oracle 则会背着 $1,674 亿债务面对一堆折旧中的资产。**

### 对比 2：谁真正创造了经济利润？（ROIC − WACC）

```
MSFT   +17.14pp  ████████████████████
GOOGL  +14.11pp  ████████████████
IBM     +7.37pp  █████████
AMZN    +2.19pp  ███
ORCL    +1.60pp  ██  🔴 几乎不创造经济价值
```

**Oracle 的资本回报率仅比资本成本高 1.6 个百分点。**

考虑到：
- ROIC 正从 15.77%（FY2024）→ 12.81%（FY2026）→ 11.48%（当前）持续下滑
- 新增的 $556 亿资本开支尚未计入分母（一旦计入，ROIC 会进一步下降）

> **Oracle 有很大概率在未来 1–2 年内 ROIC 跌破 WACC，即进入摧毁股东价值的区间。**

## 四、IBM 作为镜鉴

IBM 是唯一一家已经走完"传统企业 IT → 云转型"完整周期的公司：

| 阶段 | IBM 的经历 |
|---|---|
| 尝试期（2013–2019） | 大举投入 IBM Cloud，试图挑战 AWS/Azure |
| 失败确认（2020–2021） | 云份额未突破，剥离 Kyndryl |
| 战略收缩（2022 至今） | **Capex/OCF 降至 7%**，转向混合云软件与咨询 |
| 结果 | FCF 恢复至 **+$137.9 亿**，ROIC 13.96%，**高于 Oracle 的 11.48%** |

> **IBM 的教训：在超大规模云基础设施上，第二梯队玩家很难赢。IBM 认输后反而恢复了现金流和资本回报率。**
>
> ⚠️ **反驳**：Oracle 与 IBM 的关键差异在于 Oracle 拥有数据库这一不可替代的资产，且 OCI 的增长（FY2027E 收入 +32.60%）远超 IBM 云当年的表现。**Oracle 可能不会重蹈覆辙。但 IBM 案例说明了失败的代价是什么。**
