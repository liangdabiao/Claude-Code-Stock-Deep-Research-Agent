# Oracle (ORCL) 现金流深度分析

> 本文件是理解 Oracle 投资论点的**核心**。单位：百万美元。

---

## 一、利润 vs. 现金流交叉验证（强制项）

| 财年 | 净利润 | 经营现金流 | **OCF/NI** | 自由现金流 | **FCF/NI** | 判断 |
|---|---|---|---|---|---|---|
| FY2026 | 16,984 | 31,977 | **1.88** | **−23,686** | **−1.39** | 🟢 OCF 优秀 / 🔴 FCF 崩塌 |
| FY2025 | 12,443 | 20,821 | 1.67 | −394 | −0.03 | 🟢 / 🔴 |
| FY2024 | 10,467 | 18,673 | 1.78 | 11,807 | 1.13 | 🟢 / 🟢 |
| FY2023 | 8,503 | 17,165 | 2.02 | 8,470 | 1.00 | 🟢 / 🟢 |
| FY2022 | 6,717 | 9,539 | 1.42 | 5,028 | 0.75 | 🟢 / 🟡 |
| **累计** | **55,114** | **98,175** | **1.78** | **+1,225** | **0.02** | |

### 结论一：会计利润没有造假

OCF/NI 五年均值 1.78 且每一年都 >1.4。**Oracle 的净利润是有现金支撑的。** 这是软件订阅模式的典型特征——递延收入先收钱后确认。

**在这一点上，Oracle 与那些"利润高但收不到钱"的公司完全不同。不应把 Oracle 与财务造假类比。**

### 结论二：但现金没有留给股东

FCF/NI 五年累计 0.02。**赚到的现金 99% 立刻投进了数据中心。**

```
每 $100 会计利润的去向（五年累计）：

净利润                  $100
+ 非现金加回            $ 78   （折旧、股权激励、递延收入）
= 经营现金流            $178
− 资本开支              $176
= 自由现金流            $  2   ← 股东实际能分到的
```

## 三、🔑 核心计算：五年股东回报 100% 由债务融资

**这是纯算术，不含任何假设：**

| 项目 | 五年累计（百万美元） |
|---|---|
| 自由现金流 | **+1,225** |
| 现金分红 | **−22,046** |
| 股份回购 | **−24,792** |
| **股东回报合计** | **−46,838** |
| **资金缺口** | **−45,613** |
| | |
| 净新增长期债务 | **+43,552** |
| 优先股发行 | **+4,954** |
| **新增融资合计** | **+48,506** |

> **Oracle 过去五年支付给股东的每一美元中，有 97.4 美分来自借款，而非经营创造的自由现金流。**

这不是"用债务优化资本结构"，这是**用债务维持股东回报的表象**。

⚠️ **公平的反面论证**：如果把资本开支视为投资而非维持性支出，则应该用"经营现金流 − 维持性资本开支"来衡量可分配现金。FY2026 折旧 $9,294M 可作为维持性资本开支的粗略代理：

```
调整后可分配现金 = OCF $31,977M − 维持性 Capex ≈$9,294M = $22,683M
FY2026 股东回报 = 分红 $5,787M + 回购 $206M = $5,993M
覆盖倍数 = 3.78 倍   ← 看起来完全安全
```

**两种算法给出完全相反的结论。哪个对？**

答案取决于一个问题：**这 $556 亿的增长性资本开支能否产生足够回报？** 如果能，第二种算法对；如果不能，它就是被资本化的费用，第一种算法对。**这正是 Oracle 的核心投资争议。**

## 四、递延收入的双面性

| 财年 | 递延收入变动 | 占 OCF 比例 | 调整后 OCF | 调整后 FCF |
|---|---|---|---|---|
| FY2026 | **+4,642** | **14.5%** | 27,335 | **−28,328** |
| FY2025 | +154 | 0.7% | 20,667 | −548 |
| FY2024 | +656 | 3.5% | 18,017 | 11,151 |
| FY2023 | +781 | 4.6% | 16,384 | 7,689 |
| FY2022 | +7 | 0.1% | 9,532 | 5,021 |

**🟢 正面解读**：递延收入 +$46.42 亿说明客户在预付——这是收入可见度和客户承诺的证据，也是 RPO（剩余履约义务）大幅增长的现金体现。

**🔴 反面解读**：它是一项负债，代表尚未交付的服务。它美化了当期 OCF，但**必须在未来用真实成本（算力、电力、人力）去兑现**。FY2026 若剔除该项，自由现金流为 **−$283 亿**（而非 −$237 亿）。

**中立结论**：递延收入增长本身是好事，但它使 FY2026 的 OCF 增长（+53.6%）看起来比业务实际改善更强。

## 五、折旧滞后：一个被低估的风险

| 财年 | 资本开支 | 折旧摊销 | Capex/D&A |
|---|---|---|---|
| FY2022 | 4,511 | 3,122 | 1.44 |
| FY2023 | 8,695 | 6,108 | 1.42 |
| FY2024 | 6,866 | 6,139 | 1.12 |
| FY2025 | 21,215 | 6,174 | **3.44** |
| FY2026 | **55,663** | **9,294** | **5.99** |

### 为什么这很重要

FY2025+FY2026 两年资本开支合计 **$76,878M**。若按 6 年直线折旧：

```
年化折旧增量 = $76,878M / 6 = $12,813M / 年
FY2026 实际折旧仅  $9,294M
→ FY2027 折旧可能达到 $18,000M–$22,000M
```

**影响 EPS：**

```
若 FY2027 折旧增加 $10,000M（税后约 $7,500M）
FY2027E 净利润（隐含）≈ $23,200M
折旧完全体现后 ≈ $15,700M
→ EPS 从 ≈$8.05 降至 ≈$5.45
→ 现价 $114.99 对应的真实 Forward PE 从 14.28 升至 ≈21.1
```

> 🔴 **"Forward PE 仅 14.28" 这个多头核心论点，建立在一个尚未完全计提折旧的盈利基数之上。**
>
> ⚠️ 上述折旧年限（6年）为假设值，GPU 服务器实际折旧年限行业内争议很大（3–6 年）。若按 5 年折旧，影响更大；按 8 年则影响减半。**这是本报告最敏感的假设之一，读者应自行判断。**
