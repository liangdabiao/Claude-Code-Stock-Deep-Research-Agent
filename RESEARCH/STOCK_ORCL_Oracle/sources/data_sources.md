## 一、已使用的数据源

### stockanalysis.com（主要，B 级）

| 页面 | 提供的数据 | 本报告用途 |
|---|---|---|
| `/stocks/orcl/statistics/` | 市值、EV、PE/PS/PB、ROE/ROA/ROIC、WACC、债务、流动性、空头、Beta、Altman Z、Piotroski F、员工数 | 估值与财务健康度的核心输入 |
| `/stocks/orcl/financials/` | FY2022–FY2026 利润表（收入、毛利、营业利润、净利、EPS、D&A、SBC） | 五年趋势分析、边际毛利率计算 |
| `/stocks/orcl/financials/cash-flow-statement/` | OCF、Capex、FCF、债务发行/偿还、优先股、回购、分红、递延收入变动、收购 | **本报告最核心的数据源**——股东回报融资来源分析全部基于此 |
| `/stocks/orcl/financials/ratios/` | 历史 PE/PS/PB/EV-EBITDA、历史 ROIC | 历史估值分位分析 |
| `/stocks/orcl/forecast/` | 分析师目标价、评级分布与修正、FY2027E 收入/EPS/毛利/FCF | 市场预期分析、矛盾识别 |
| `/stocks/orcl/` | 公司概况、近期新闻 | 定性背景 |

**同业**：`/stocks/msft/statistics/`、`/stocks/googl/statistics/`、`/stocks/amzn/statistics/`、`/stocks/ibm/statistics/`

## 三、数据缺口对结论的具体影响

| 缺口 | 影响的分析 | 本报告的处理 |
|---|---|---|
| **分部数据（OCI 独立利润率）** | 无法直接判断云业务经济性 | 🟡 用**边际毛利率**（Δ毛利/Δ收入）反推，结论标注为推断 |
| **客户集中度 / RPO** | 无法量化 AI 大客户的对手方风险 | 🔴 仅作定性讨论，列为黑天鹅风险 |
| **债务到期结构** | 无法评估再融资时点的集中度 | 🔴 用总量和 Debt/EBITDA 替代，承认不精确 |
| **折旧年限政策** | 折旧滞后风险无法精确量化 | 🟡 用 6 年假设 + 3–8 年敏感性区间处理，明确标注 |
| **内部人/机构持股** | 治理分析缺乏直接证据 | 🟡 用**自由流通股占比 59.4%** 反推内部人约 40.6%，标注为推断 |
| **信用评级** | 信用风险为推断 | 🔴 用 Debt/EBITDA 5.60、利息保障 4.48、Altman Z 2.18 替代 |
| **管理层指引原文** | 无法引用具体的资本开支指引 | 🟡 用 FY2027E FCF −$477 亿反推 ≈$950 亿资本开支 |

## 四、数据一致性检查记录

| 检查项 | 结果 |
|---|---|
| 利润表净利润 vs 现金流量表净利润 | ✅ 一致（FY2026 均为 $16,984M） |
| OCF − Capex = FCF | ✅ 一致（31,977 − 55,663 = −23,686） |
| 五年累计 FCF 与逐年加总 | ✅ 一致（+$1,225M） |
| 市值 / 净利润 ≈ PE | ✅ 大致一致（331,230 / 16,984 = 19.50 vs 报告 19.72，差异因 TTM 口径） |
| EV = 市值 + 债务 − 现金 | ✅ 一致（331.23 + 167.43 − 31.89 = 466.77 vs 466.76） |
| ROE / ROA = 权益乘数 | ✅ 合理（53.38 / 6.51 = 8.20） |
| **Forecast 页收入预测** | ❌ **自相矛盾**（$130.47B vs $89.32B），已处理 |
| **分析师目标价 vs FCF 预测** | ❌ **不相容**，已在正文说明 |

> 🟢 **除 Forecast 页的两处矛盾外，核心财务数据内部一致性良好。这提升了对 B 级来源的信心。**

## 六、方法论声明

| 项目 | 说明 |
|---|---|
| 研究执行方式 | **串行、单线程、直接 WebFetch** |
| 未使用 | 子代理并行研究（Agent 工具）、Workflow 编排、WebSearch |
| 原因 | 会话级指令限制 + WebSearch API 不可用 |
| 数据源数量 | **1 个主要来源**（stockanalysis.com）+ 少量新闻背景 |
| 交叉验证方式 | 内部一致性检查、利润 vs 现金流、公司 vs 同业、分析师预期 vs 现金流预测 |
| **最大方法论风险** | **单一数据源。若该源数据有误，本报告无法察觉** |
