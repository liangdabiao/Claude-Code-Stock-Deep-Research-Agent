## 二、业务构成

Oracle 的业务可分为三个截然不同的层次，它们的经济特征差异巨大：

### 层次 1：数据库与中间件（传统基石）

| 项目 | 说明 |
|---|---|
| 核心产品 | Oracle Database、Exadata、中间件、Java |
| 商业模式 | 许可证 + 年度技术支持（续费率极高） |
| 毛利率特征 | **极高**（软件许可证边际成本接近零） |
| 护城河 | **4.5/5** —— 企业核心交易系统，迁移风险与成本极高 |
| 增长 | 低个位数，成熟 |
| 战略地位 | **现金奶牛**，为其他业务输血 |

### 层次 2：应用软件 SaaS（转型中段）

| 项目 | 说明 |
|---|---|
| 核心产品 | Fusion Cloud ERP、Fusion Cloud EPM、Fusion Cloud SCM、Fusion Cloud HCM、**NetSuite**、Oracle Health |
| 商业模式 | 订阅制 SaaS |
| 毛利率特征 | 中高（70–80% 量级，行业常态） |
| 护城河 | **3.0/5** —— ERP 转换成本真实，但面对 SAP / Workday / Salesforce 充分竞争 |
| 增长 | 中双位数 |
| 战略地位 | 转型的成功部分 |

**引用**：[stockanalysis.com, 2026-07-24, ORCL Profile（产品线披露）, https://stockanalysis.com/stocks/orcl/, Source Quality: B]

### 层次 3：OCI 云基础设施（当前的一切）

| 项目 | 说明 |
|---|---|
| 核心产品 | Oracle Cloud Infrastructure，尤其是 **AI/GPU 算力租赁** |
| 商业模式 | 按用量计费的基础设施租赁 |
| 毛利率特征 | **低**（重资产、高折旧、电力成本） |
| 护城河 | **1.0/5** —— **算力是商品，几乎没有转换成本** |
| 增长 | 极高（是当前收入加速的唯一来源） |
| 战略地位 | **公司押上资产负债表的赌注** |

⚠️ **重大证据缺口**：本次研究**未能获取 Oracle 的分部收入拆分**（Cloud Infrastructure / Cloud Applications / License Support / Hardware / Services 各自的收入与利润率）。SEC EDGAR 返回 HTTP 403。**以下关于分部的所有量化描述均为推断。**

**关键读数**：

- FY2027E +32.60% 若兑现，将是 Oracle 四十年历史上最快的增长

**这是本报告必须承认的多头核心事实：Oracle 的收入转型正在真实发生。**

## 四、收入的质量：一个关键的现金流线索

FY2026 现金流量表中，**递延收入（Unearned Revenue）变动 = +$4,642M**，而 FY2025 仅 +$154M。

| 财年 | 递延收入变动 |
|---|---|
| FY2022 | +$7M |
| FY2023 | +$781M |
| FY2024 | +$656M |
| FY2025 | +$154M |
| **FY2026** | **+$4,642M** |

**解读**：递延收入激增 30 倍，说明 Oracle 收到了大量**预付款**。这通常意味着签下了大额的多年期预付合同（推断：AI 算力预售）。

**双向含义**：
- 🟢 **正面**：收入可见性提升，客户用真金白银锁定了产能，这是需求真实的强证据
- 🔴 **负面**：预收款是**负债**，也意味着 Oracle 必须交付。若无法按时建成数据中心，将面临违约风险。同时，预收款美化了 FY2026 的经营现金流——**$319.8 亿 OCF 中有 $46.4 亿来自这一项，占 14.5%**

**引用**：[stockanalysis.com, 2026-07-24, ORCL Cash Flow Statement, https://stockanalysis.com/stocks/orcl/financials/cash-flow-statement/, Source Quality: B]

## 六、价值链位置

```
    电力 / 土地              ← 🔴 瓶颈（威斯康星州 $7B 电力问题）
         ↓
    Nvidia GPU / 网络设备    ← 🔴 议价能力弱，成本刚性
         ↓
    Oracle OCI 数据中心      ← 【Oracle 在这里】重资产、低毛利
         ↓
    AI 实验室 / 企业客户      ← 🔴 议价能力强，可多云采购
```

```
    Oracle Database          ← 【Oracle 在这里】🟢 定价权强
         ↓
    企业核心业务系统          ← 转换成本极高，被锁定
```

**Oracle 同时处在价值链的两个完全不同的位置**：
- 在数据库业务上，它是**收租方**（高毛利、强定价权）
- 在 OCI 业务上，它是**被夹在中间的重资产运营商**（上游 Nvidia 与电力涨价，下游客户压价）

这正是毛利率从 79.08% 塌至 65.82% 的结构性原因。

## 八、业务底座结论

| 维度 | 判定 |
|---|---|
| 老业务是否稳固？ | 🟢 是。数据库/中间件护城河真实，40 年积累 |
