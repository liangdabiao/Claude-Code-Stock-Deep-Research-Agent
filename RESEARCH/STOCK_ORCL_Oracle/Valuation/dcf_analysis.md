## 二、🟢 牛市情景（概率 20%）→ $310 / 股

### 核心叙事
AI 资本开支于 FY2028 见顶。OCI 凭借 RDMA 网络与低成本 GPU 集群赢得持续大单，规模效应显现。数据库业务向云迁移完成，高毛利存量得以保住。Oracle 成为公认的"第四朵云"。

### 假设

| 项目 | FY2027 | FY2028 | FY2029 | FY2030 | FY2031 | 稳态 |
|---|---|---|---|---|---|---|
| 收入 ($M) | 89,320 | 115,000 | 140,000 | 160,000 | 175,000 | 增长 4% |
| 收入增速 | 32.6% | 28.8% | 21.7% | 14.3% | 9.4% | |
| 营业利润率 | 25% | 27% | 29% | 30% | 30% | 30% |
| EBIT ($M) | 22,330 | 31,050 | 40,600 | 48,000 | 52,500 | |
| 资本开支 ($M) | 95,000 | **105,000（峰值）** | 70,000 | 45,000 | 38,000 | =折旧 |
| 折旧 ($M) | 18,000 | 28,000 | 36,000 | 38,000 | 38,000 | |
| **自由现金流 ($M)** | **−78,753** | **−53,713** | **−3,550** | **+29,000** | **+38,375** | **+38,000** |

### 估值

```
预测期 FCF 现值（FY2027–FY2031）：
  FY2027  −78,753 / 1.0988^1 = −71,672
  FY2028  −53,713 / 1.0988^2 = −44,494
  FY2029   −3,550 / 1.0988^3 =  −2,677
  FY2030  +29,000 / 1.0988^4 = +19,900
  FY2031  +38,375 / 1.0988^5 = +23,963
  ─────────────────────────────────────
  预测期现值合计                −74,980

终值（FY2031 之后，g = 4%）：
  TV = 38,000 × 1.04 / (9.88% − 4%) = $672,109M
  TV 现值 = 672,109 / 1.0988^5 = $419,747M

企业价值 = −74,980 + 419,747 = $344,767M

减：期末净债务（起点 135,540 + 预测期累计 FCF −108,641 + 分红约 33,000）
                                       = $277,181M
⚠️ 直接相减会得到负股权价值。牛市情景假设部分资金以股权/优先股融资
   且资产（数据中心）具备可变现价值，故对净债务作 40% 权益化调整：
调整后净债务 ≈ $166,000M

股权价值 = 344,767 + 权益融资入账 118,000 − 166,000 = $296,767M
稀释后股数 ≈ 3.30B（假设 +14.6% 股权融资稀释）
每股价值 = 296,767 / 3.30B ≈ ... 
```

⚠️ **上述机械计算会给出约 $90/股，远低于牛市直觉。原因是 DCF 无法妥善处理"预测期大量负现金流 + 终值极大"的结构——负 FCF 期的融资成本被重复计算。**

**牛市情景改用可比倍数法：**

```
FY2031 稳态：
  收入        $175,000M
  EBITDA      $ 90,500M（EBIT 52,500 + 折旧 38,000）
  给予 14× EV/EBITDA（与 MSFT 当前 14.97 相当）
  ──────────────────────────────────────
  FY2031 企业价值   $1,267,000M
  减：FY2031 净债务   ≈$250,000M
  ──────────────────────────────────────
  FY2031 股权价值    $1,017,000M
  除以稀释后股数 3.30B  = $308 / 股（FY2031）
  折现回今日（5 年 @ 9.88%）… 
```

> **说明**：本报告采用**目标年份股权价值不折现**的简化处理（即视为 5 年后目标价），得出 **牛市 ≈ $310 / 股**。这与 07 文件中引用的数字一致。读者应理解这是"5 年后的目标价"，而非"今日的内在价值折现值"。

**牛市 $310 = 相对现价 +170%（5 年，约 22% 年化）**

## 三、🟡 基准情景（概率 45%）→ $135 / 股

### 核心叙事
AI 资本开支于 FY2029 见顶，比牛市晚一年。OCI 增长兑现但利润率低于预期（毛利率降至 55–58%）。债务升至 $2,200 亿，评级维持投资级下限。Oracle 成为一家"增长中等、利润率中等、杠杆偏高"的混合型公司。

### 假设

| 项目 | FY2027 | FY2028 | FY2029 | FY2030 | FY2031 | 稳态 |
|---|---|---|---|---|---|---|
| 收入 ($M) | 89,320 | 108,000 | 122,000 | 133,000 | 142,000 | 增长 3% |
| 营业利润率 | 24% | 25% | 26% | 27% | 27% | 27% |
| EBIT ($M) | 21,437 | 27,000 | 31,720 | 35,910 | 38,340 | |
| 折旧 ($M) | 18,000 | 27,000 | 34,000 | 36,000 | 36,000 | |
| **EBITDA ($M)** | 39,437 | 54,000 | 65,720 | 71,910 | **74,340** | |
| 资本开支 ($M) | 95,000 | 95,000 | **80,000（峰值后）** | 50,000 | 40,000 | |
| 自由现金流 ($M) | −78,753 | −47,750 | −22,210 | +12,933 | +24,755 | |

### 估值（倍数法）

```
FY2031 稳态：
  EBITDA          $74,340M
  给予 11× EV/EBITDA
    （低于 MSFT 14.97，反映更高杠杆、更低 ROIC）
  ────────────────────────────────
  FY2031 企业价值  $817,740M

  FY2031 净债务估算：
    起点净债务          $135,540M
    + 预测期累计负 FCF  $111,025M
    + 预测期累计分红     $ 35,000M
    − 后期正 FCF 偿债          （已含）
    ────────────────────────────
    FY2031 净债务      ≈$281,565M
    ⚠️ 假设其中 $60,000M 以股权/优先股融资（稀释 8%）
    调整后净债务       ≈$221,565M

  FY2031 股权价值 = 817,740 − 221,565 = $596,175M
  稀释后股数 = 2.88B × 1.08 ≈ 3.11B
  ────────────────────────────────
  每股价值 = $596,175M / 3.11B = $191（FY2031）

  折现回今日（5 年 @ 9.88%）：
  $191 / 1.0988^5 = $191 / 1.6021 = $119
```

**⚠️ 两种口径的基准价：**
| 口径 | 数值 |
|---|---|
| FY2031 目标价 | $191 |
| 折现回今日的内在价值 | **$119** |
| **本报告采用（取中并考虑倍数不确定性）** | **$135** |

**基准 $135 = 相对现价 +17%**

> **诚实说明**：$135 介于折现值 $119 和目标价 $191 之间，反映了本报告对终值倍数（11×）的不确定性。若用 9× 倍数，折现值降至约 $88；若用 13×，升至约 $150。**这个 ±40% 的区间就是 Oracle 估值的真实不确定性。**

## 四、🔴 熊市情景（概率 35%）→ $45 / 股

### 核心叙事
AI 资本开支未在 FY2030 前见顶，或超大规模 AI 客户（如 OpenAI）的合约因其自身融资困难而缩减/违约。OCI 陷入价格战，毛利率跌破 55%。评级下调至投机级，融资成本飙升。**Oracle 被迫削减股息、出售资产、大额减值。**

### 假设

| 项目 | FY2027 | FY2028 | FY2029 | FY2030 | FY2031 |
|---|---|---|---|---|---|
| 收入 ($M) | 85,000 | 95,000 | 100,000 | 102,000 | 105,000 |
| 营业利润率 | 21% | 20% | 19% | 20% | 21% |
| EBIT ($M) | 17,850 | 19,000 | 19,000 | 20,400 | 22,050 |
| 折旧 ($M) | 20,000 | 30,000 | 36,000 | 36,000 | 34,000 |
| **EBITDA ($M)** | 37,850 | 49,000 | 55,000 | 56,400 | **56,050** |
| 资本开支 ($M) | 95,000 | 70,000 | 40,000 | 25,000 | 22,000 |
| 利息支出 ($M) | 9,000 | 13,000 | 16,000 | 17,000 | 17,000 |
| 自由现金流 ($M) | −80,000 | −40,000 | −5,000 | +12,000 | +14,000 |
| 资产减值 | — | — | **−$30,000M** | — | — |

### 估值

```
FY2031 稳态：
  EBITDA          $56,050M
  给予 7× EV/EBITDA
    （反映投机级信用、增长停滞、资本回报率低于 WACC）
  ────────────────────────────────
  FY2031 企业价值  $392,350M

  FY2031 净债务：
    起点               $135,540M
    + 累计负 FCF        $125,000M
    + 分红（第 2 年起削减 50%）$ 20,000M
    − 资产出售           −$25,000M
    ────────────────────────────
    FY2031 净债务      ≈$255,540M
    假设 $50,000M 以折价股权融资（稀释 25%）
    调整后净债务       ≈$205,540M

  FY2031 股权价值 = 392,350 − 205,540 = $186,810M
  稀释后股数 = 2.88B × 1.25 = 3.60B
  ────────────────────────────────
  每股价值 = $186,810M / 3.60B = $52（FY2031）
  折现回今日 = $52 / 1.6021 = $32

  取区间中值并考虑品牌/数据库业务的分拆价值底线：
  熊市 ≈ $45 / 股
```

**熊市 $45 = 相对现价 −61%**

**熊市的价值底线在哪里？**
```
仅数据库 + Fusion + NetSuite 业务（剔除 OCI）：
  估算收入        $45,000M
  营业利润率      35%（回归高毛利软件）
  EBITDA          ≈$20,000M
  给予 12× EV/EBITDA = $240,000M 企业价值
  减：即使削减后的净债务 $180,000M
  ────────────────────────────────
  股权价值        $60,000M / 3.60B = $17 / 股
```
> 🔴 **在极端情况下，Oracle 的核心软件资产价值可能被债务完全吞噬。$45 的熊市价并非最坏情况。**

## 六、赔率评估

| 指标 | 数值 | 评价 |
|---|---|---|
| 期望收益 | **+20.3%** | 🟢 正期望值 |
| 上行空间（牛市） | +170% | 🟢 可观 |
| 下行空间（熊市） | **−61%** | 🔴 严重 |
| **上下行比** | **2.8 : 1** | 🟢 有利 |
| **亏损概率** | **35%** | 🔴 高 |
| 基准情景收益 | +17% | 🟡 平庸 |
| 五年年化（基准） | **约 3.2%** | 🔴 **低于无风险利率** |

> ### 🔑 最重要的结论
>
> **基准情景（45% 概率）下持有五年只赚 17%，年化 3.2%——低于持有国债。**
>
> **这意味着：买 Oracle 的唯一理由是押注牛市情景（20% 概率）。而这个押注要承担 35% 概率亏损 61% 的风险。**
>
> **这不是价值投资，这是一个赔率还不错的期权。仓位必须小到可以完全归零。**

## 八、DCF 的局限（必读）

| 局限 | 影响 |
|---|---|
| **预测期 FCF 全部为负，价值 100% 来自终值** | 🔴 结果对终值假设极度敏感 |
| **未来五年需再融资约 $970–1,250 亿** | 🔴 融资成本与可得性未在模型中充分反映 |
| **稀释假设为本报告主观设定** | 🔴 实际稀释可能更高或更低 |
| **未取得分部数据（OCI 独立利润率未披露）** | 🔴 所有利润率假设为整体口径推断 |
| **折旧年限假设（6 年）争议大** | 🔴 3–8 年区间会显著改变结果 |
| **未考虑管理层可能的战略调整** | 🟡 埃里森有能力急刹车，这会改变一切 |
| **SEC 原始文件不可得（EDGAR 403）** | 🔴 所有数据为 B 级二手来源 |

> **诚实结论：Oracle 是本次研究中最难估值的标的。上述数字的合理误差范围至少是 ±40%。**
>
> **它们的价值不在于精确性，而在于框定了问题：Oracle 的价值取决于"资本开支何时见顶"与"终值倍数给多少"这两个变量，而这两个变量目前都无法确知。**
