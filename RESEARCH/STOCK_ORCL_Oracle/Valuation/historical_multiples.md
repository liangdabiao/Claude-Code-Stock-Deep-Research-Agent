## 三、⚠️ 但历史分位在这里会严重误导

**这是本文件最重要的一节。**

### 同样的 PE，完全不同的公司

| | **FY2022（PE 29.84）** | **当前（PE 19.72）** |
|---|---|---|
| 毛利率 | **79.08%** | **65.82%**（FY2027E 60.10%） |
| 自由现金流 | **+$5,028M** | **−$23,686M** |
| Capex/OCF | 47% | **174%** |
| 总债务 | 约 $760 亿 | **$1,674 亿** |
| Debt/EBITDA | 约 2.5 | **5.60** |
| ROIC | 14.38% | **11.48%** |
| ROIC − WACC | +4.50pp | **+1.60pp** |
| 回购 | −$17,341M | −$206M |
| 股本变动 | 大幅回购 | **+1.68% 稀释** |
| Altman Z | 更高 | **2.18（灰区）** |
| 业务性质 | 高毛利软件 | 资本密集基础设施 |

> **FY2022 的 Oracle 是一家 79% 毛利、正 FCF、低杠杆、大额回购的软件公司，市场给 PE 29.84。**
>
> **今天的 Oracle 是一家 66% 毛利（并将降至 60%）、负 FCF $237 亿、Debt/EBITDA 5.60、停止回购并开始稀释的资本密集型公司，市场给 PE 19.72。**
>
> **PE 从 29.84 降到 19.72（−34%）——但公司质量的下降幅度可能更大。**

**核心判断：这不是"估值回归历史低位"，这是"市场对一家已经改变的公司重新定价"。**

### 一个检验：如果 Oracle 真的变成了基础设施公司，合理倍数是多少？

| 参照公司 | 类型 | EV/EBITDA |
|---|---|---|
| 微软 | 软件 + 云（高质量） | 14.97 |
| **Oracle 当前** | 转型中 | **15.61** |
| Equinix（数据中心 REIT）* | 基础设施 | 通常 18–22 |
| 传统电信/公用事业* | 重资产 | 通常 6–9 |

> *为一般行业区间的常识性参照，未取得当日实际数据，仅供定性判断。

**若 Oracle 最终被市场归类为"高增长数据中心运营商"，15–20 倍 EV/EBITDA 合理；若被归类为"重资产、高杠杆、回报率平庸的基础设施企业"，8–12 倍更合理。**

**当前的 15.61 倍隐含市场仍在给 Oracle 软件公司的待遇。**

## 四、股息率视角

| 财年 | 股息率（估算） |
|---|---|
| FY2022 | ~1.80% |
| FY2023 | ~1.28% |
| FY2024 | ~1.36% |
| FY2025 | ~1.02% |
| FY2026 | ~0.89% |
| **当前** | **1.74%** |

**当前股息率 1.74% 是五年最高，接近 FY2022 水平。**

⚠️ **但股息的可持续性存疑**：
```
FY2026 分红        $5,787M
FY2026 自由现金流  −$23,686M
覆盖倍数           负数（由债务支付）
派息率（会计口径）  34.31%   ← 看起来很安全
派息率（FCF 口径）  不可计算  ← 实际情况
```

> **34.31% 的派息率是一个会计幻觉。用自由现金流衡量，Oracle 的股息 100% 由借款支付。**

**股息率上升不构成买入理由，除非自由现金流转正。**

## 五、多空双方对历史分位的解读

### 🟢 多头解读

> "Oracle PE 19.72、Forward PE 14.28、EV/EBITDA 15.61 全部处于五年最低。而收入增速 17.35% 是五年最高，FY2027E 预计 +32.60%。**用五年最低的估值买五年最高的增长，这是明显的错误定价。**"

**这个论点的合理之处**：加速的收入增长确实值得更高而非更低的倍数。市场情绪（RSI 27.43，−52.46%）确实处于极端。

### 🔴 空头解读

> "估值倍数下降的同时，公司的**每一项质量指标**都在恶化。市场不是在犯错，而是在把 Oracle 从'软件公司'重分类为'资本密集型基础设施公司'。**这个重分类过程可能还没结束。**"

**这个论点的合理之处**：ROIC 从 15.77% 降到 11.48%、FCF 从 +$118 亿变成 −$237 亿、Debt/EBITDA 5.60、毛利率将降至 60.10%——这些都不是情绪，是事实。

### 本报告的判断

**两方都有道理，但空头掌握的是已确认的事实，多头依赖的是未来的假设。**

历史分位是有用的**情绪指标**，但对 Oracle 而言不是有效的**价值指标**——因为公司的商业模式本身已经改变。

## 六、结论

| 问题 | 答案 |
|---|---|
| 当前估值处于历史什么分位？ | **PE / EV/EBITDA / P/OCF 均为五年最低** |
| 这意味着便宜吗？ | 🟡 **不必然**。同期公司质量下降幅度可能更大 |
| 股息率 1.74% 有吸引力吗？ | 🔴 **不安全**。股息由债务支付 |
| 历史分位可作为买入依据吗？ | 🔴 **不可以**。商业模式已改变，历史不可比 |
| 应该用什么代替？ | **绝对估值（DCF）+ 反向 DCF 检验隐含假设** |
