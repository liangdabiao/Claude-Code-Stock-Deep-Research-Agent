## 二、市场如何区别对待这四家

| 公司 | 52 周涨跌 | Capex/OCF | FCF | 净现金/净债务 |
|---|---|---|---|---|
| **GOOGL** | **+68.08%** | 71% | +$53.27B | **净现金 +$121.68B** |
| AMZN | +1.67% | 102% | −$2.47B | 净债务 −$92.45B |
| MSFT | −24.55% | 57% | +$72.92B | 净债务 −$47.20B |
| **ORCL** | **−52.46%** | **174%** | **−$23.69B** | **净债务 −$135.54B** |

**市场的定价逻辑清晰可见**：

```
奖励：能自筹资金 + 净现金 + 有其他利润引擎  →  GOOGL +68%
中性：能自筹资金 + 有零售现金流缓冲          →  AMZN +2%
惩罚：能自筹但增速放缓                        →  MSFT −25%
重罚：不能自筹 + 高杠杆 + 无缓冲              →  ORCL −52%
```

**这不是"AI 泡沫破裂"，这是"AI 资本开支的融资方式被重新定价"。** 市场在 2026 年学会了区分谁在用利润建、谁在用债务建。

⚠️ 注意 MSFT 也跌了 24.55% —— 说明市场对**整个云资本开支周期的回报率**都产生了怀疑，不只是针对 Oracle。这一点对本报告的判断很重要：**Oracle 的问题有一部分是行业性的，不完全是公司特有的。**

## 三、Oracle 在竞争格局中的真实位置

### 云基础设施市场结构（推断，规模按收入量级）

```
第一梯队（自筹资金、规模效应、全栈）
├─ AWS（Amazon）      —— 收入 $742.78B 母公司现金流支撑
├─ Azure（Microsoft） —— 营业利润率 46.80%，最强利润引擎
└─ GCP（Google）      —— 净现金 $121.68B，弹药最充足

第二梯队（挑战者）
└─ OCI（Oracle）      —— 【Oracle 在这里】靠债务追赶
```

**Oracle 的战略选择**：既然无法在通用云上与三巨头竞争，就在**特定场景**建立优势：

| Oracle 的差异化尝试 | 是否成立 |
|---|---|
| **数据库 + 云的绑定** | 🟢 成立。跑 Oracle DB 的企业上 OCI 有真实理由 |
| **主权云 / 政府云** | 🟢 成立。五角大楼 $7B + 海军 $3.31B 是实证 |
| **裸金属 GPU 集群的性价比** | 🟡 部分成立。但可被复制，无持久壁垒 |
| **RDMA 网络架构** | 🟡 技术领先窗口期短 |
| **通用企业 IaaS** | 🔴 不成立。规模、生态、工具链全面落后 |

## 四、行业周期的核心风险：GPU 折旧的会计问题

这是整个 AI 资本开支周期最重要、也最少被认真讨论的问题。

### 问题本质

```
数据中心建筑物：折旧 20–30 年   ← 合理
电力/冷却设备：  折旧 10–15 年   ← 合理
GPU 服务器：     折旧 ??? 年     ← 争议核心
```

若 GPU 实际经济寿命是 **3–4 年**（新一代性能翻倍，旧卡电费效率不划算），而账面按 **5–6 年**折旧：
- 短期：利润被高估
- 长期：资产减值风险

### Oracle 的折旧数据

| 财年 | D&A（百万） | 累计 Capex（百万） |
|---|---|---|
| FY2022 | 3,122 | 4,511 |
| FY2023 | 6,108 | 8,695 |
| FY2024 | 6,139 | 6,866 |
| FY2025 | 6,174 | **21,215** |
| **FY2026** | **9,294** | **55,663** |

**关键观察**：FY2026 资本开支 $556.6 亿，但折旧只有 $92.9 亿。

**原因**：资产是年内陆续投产的，尚未计提完整年度折旧。

**推论**：**FY2027 的折旧会大幅跳升。** 粗略估算——FY2025+FY2026 两年共投入 $768.8 亿，若按 6 年直线折旧，仅这两年的资产就产生约 **$128 亿/年** 的折旧。加上 FY2027 新增的资本开支（预测隐含约 $880 亿），**FY2027 折旧可能达到 $200 亿量级，是 FY2026 的两倍以上。**

**这是 Forward PE 14.28 最大的隐患**：市场在用一个尚未承担完整折旧负担的盈利基数来计算"便宜"。

### 行业验证

分析师对 Oracle FY2027 的毛利率预测已经反映了这一点：

```
FY2026 实际毛利率  65.82%
FY2027E 毛利率     60.10%   ← 再降 5.72pp
```

**云基础设施的折旧计入营业成本（COGS）。毛利率下降就是折旧上升的直接体现。**

## 五、行业需求端：真实还是泡沫？

### 支持"真实"的证据

| 证据 | 说明 |
|---|---|
| 四大厂 $4,363 亿资本开支 | 不是一家的判断失误，是全行业共识 |
| Oracle 递延收入 +$46.4 亿 | 客户**预付了钱**，用现金投票 |
| 电力成为瓶颈 | 需求已经溢出到能源基础设施 |
| 政府/国防大规模采购 | 需求扩散到非科技行业 |
| 存储芯片暴涨（MU +738%，SNDK +3,241%） | 上游全面紧缺，需求传导链完整 |

### 支持"泡沫"的证据

| 证据 | 说明 |
|---|---|
| MSFT −24.55%、ORCL −52.46% | 市场已开始怀疑回报率 |
| Oracle FY2027E FCF **−$477 亿** | 资本开支没有见顶迹象 |
| 全行业毛利率承压 | 供给增长可能快于需求 |
| Oracle 债券收益率跳升 | **信用市场先于股票市场发出警告** |
| $7B 抵押品要求 | 交易对手开始要求担保 |
| 2 倍做空 ETF 上市 | 情绪进入极端 |

### 本报告判断

> **需求是真实的，回报率是可疑的。**

这两件事可以同时成立——就像 1999 年的光纤：**光纤需求的预测最终被证明是对的，但铺光纤的公司大多破产了，因为供给一次性建过了头，且是用债务建的。**

Oracle 目前的处境与当年的 Global Crossing / Level 3 有结构性相似之处：**用高杠杆抢建基础设施，赌需求会填满产能。**

⚠️ 这个类比不是预言，只是提醒：**需求正确 ≠ 投资者赚钱。中间隔着一个叫"资本纪律"的东西。**

## 六、供给端：电力已成为真正的瓶颈

| 事件 | 日期 | 含义 |
|---|---|---|
| Oracle 威斯康星数据中心遭遇 **$7B 电力问题** | 2026-07-23 | 电力接入成本超预期 |
| 报道称可能需 **$7B 抵押品** | 2026-07-21 | 融资条件恶化 |

**行业含义**：数据中心的约束条件正在从"能否买到 GPU"转向"能否接到电"。这会：
- 🟢 拉长供给释放周期 → 对已建成产能有利
- 🔴 推高单位建设成本 → 侵蚀 ROIC
- 🔴 造成项目延期 → 与客户预付款的交付义务冲突

**对 Oracle 尤其不利**：它的融资成本最高，项目延期的资金成本也最高。

## 七、政策与地缘环境

| 因素 | 对 Oracle 影响 |
|---|---|
| 美国政府软件整合采购（ESI） | 🟢 **显著正面**。$7B 五角大楼合同是直接受益 |
| TikTok 交易（Oracle 参与） | 🟡 政治关联度高，双刃剑 |
| 对华 AI 芯片管制 | 🟡 间接。限制中国云厂，但也限制全球需求池 |
| 主权 AI / 数据本地化趋势 | 🟢 **正面**。Oracle 的分布式云架构适配 |
| 利率环境 | 🔴 **关键负面**。$1,674 亿债务对利率极度敏感 |

**利率是 Oracle 最大的宏观敞口**。当前利息保障倍数 4.48。若债务再增 $500 亿且平均利率上升 100bp，利息保障可能跌破 3.0——那是评级机构开始行动的水平。

## 八、行业分析结论

| 问题 | 判断 |
|---|---|
| 行业处于周期什么位置？ | **资本开支狂热期的第一次信用检验**，尚未见顶 |
| 需求是否真实？ | 🟢 是（递延收入、上游紧缺、政府采购多重验证） |
| 回报率是否得到验证？ | 🔴 **否**。全行业 FCF 承压，Oracle 最严重 |
| Oracle 竞争位置 | 第二梯队，靠债务追赶，在细分场景（数据库绑定、主权云）有真实优势 |
| 最大行业风险 | **GPU 折旧周期 + 供给过建 + 融资成本上升** |
| Oracle 相对同业的行业风险敞口 | 🔴 **最高**（Capex/OCF 174% vs 同业 57–102%） |
