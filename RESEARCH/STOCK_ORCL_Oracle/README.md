## 🚦 综合信号：🟡🟡🔴 高风险 — 二元赌注，非价值机会

**一句话结论**：Oracle 正在用 **1,674 亿美元债务** 把自己改造成第四家超大规模云厂。收入端的转型正在成功（FY2026 +17.35%，FY2027E +32.6%），但**资本回报尚未被证明，而资产负债表已经没有第二次犯错的余地**。19.72 倍市盈率看起来便宜，但这家公司**过去五年累计自由现金流只有 12.25 亿美元**，同期却分掉了 **220 亿美元股息**——差额全部来自借债。

## ⚡ 三个必读发现

### 1️⃣ 五年股东回报全部来自借债

| 项目（FY2022–FY2026 累计） | 金额 |
|---|---|
| 累计自由现金流 | **+$1,225M** |
| 累计股息支付 | −$22,046M |
| 累计股票回购 | −$24,792M |
| **股东回报合计** | **−$46,838M** |
| **缺口** | **−$45,613M** |
| 同期净新增长期债务 | **+$43,552M** |

**缺口与新增债务几乎完全吻合。**

### 2️⃣ 资本开支强度是同业的三倍

| 公司 | Capex / 经营现金流 |
|---|---|
| MSFT | 57% |
| GOOGL | 71% |
| AMZN | 102% |
| **ORCL** | **174%** |

MSFT、GOOGL、AMZN 用自己赚的钱建数据中心。**Oracle 用借来的钱建。**

### 3️⃣ 毛利率正在被"云"结构性稀释

```
FY2022  79.08%  ← 数据库许可证时代
FY2023  72.85%
FY2024  71.41%
FY2025  70.51%
FY2026  65.82%  ← OCI 规模化
FY2027E 60.10%  ← 分析师预测
```

**五年 −19.0 个百分点。** 收入增长是用毛利率买来的。
