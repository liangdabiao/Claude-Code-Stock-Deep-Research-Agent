# 熊市情景分析 — Intel (INTC)

**熊市情景每股价值：$15　概率：30%　相对现价：−83.7%**

---

## 一、熊市情景的核心逻辑链

```
代工业务始终拿不到大型外部客户
        ↓
Intel Foundry 的巨额固定成本无法摊薄
        ↓
产能利用率长期不足 → 毛利率无法突破 40%
        ↓
自由现金流重新转负（共识已预期 FY2026 −$18.3 亿）
        ↓
需要再次大额股权融资（FY2025 已发行 $134.77 亿的先例）
        ↓
股本从 50.4 亿股稀释至 70 亿股
        ↓
同时 x86 份额继续被 AMD / ARM 侵蚀，收入回落至 $550 亿
        ↓
市场认清"转型溢价"不成立，PS 从 8.16 回落至 2.0
        ↓
股价 $15
```

---

## 二、熊市情景的七个触发因素

### 触发 1：代工外部客户始终不来 🔴🔴🔴

**这是熊市情景最核心、也最可能实现的因素。**

```
Intel Foundry 的结构性困境：

潜在客户名单：Apple / NVIDIA / AMD / Qualcomm / Broadcom / MediaTek
                ↑          ↑        ↑         ↑          ↑
              竞争对手   竞争对手  直接竞争   竞争对手   竞争对手

问题：这些客户都在与英特尔的产品部门直接竞争。
      把最核心的芯片设计交给竞争对手的晶圆厂流片，
      在商业上是一个极难说服自己的决定。
```

**这不是技术问题，是结构问题。即使 18A 良率完美，问题依然存在。**

| 缓解可能 | 概率评估 |
|---|---|
| 分拆 Foundry 为独立公司 | 中等——已有讨论，但资本需求巨大 |
| 政府订单/国防订单托底 | 高——但规模有限，无法填满产能 |
| 中小客户/AI 初创公司 | 中等——规模不足以摊薄成本 |
| 与 Lens Technology 的封装合作 | 已发生——但市场反应是股价下跌 |

### 触发 2：自由现金流重新转负 🔴🔴🔴

**共识已经预期了这一点，且新闻标题明确提示资本开支回升。**

```
TTM FCF：            +$28.31 亿   （靠砍 53% 资本开支实现）
FY2026E 共识 FCF：   −$18.30 亿   ← 已转负
新闻标题："CapEx Climbs"

若资本开支回到 FY2024 水平 $239.44 亿：
  FCF = OCF $149.36 亿 − $239.44 亿 = −$90.08 亿
```

**这个触发因素的特殊之处：它几乎已经确定会发生。差别只在幅度。**

### 触发 3：再次大额股权稀释 🔴🔴🔴

```
先例：FY2025 发行股票 $134.77 亿，股本一年 +13.28%

若熊市情景中英特尔每年烧掉 $50–100 亿自由现金流，
持续 4 年 → 累计 $200–400 亿资金缺口

填补方式（基于历史行为）：
  再次发行股票 → 股本从 50.4 亿股增至 65–70 亿股
  → 现有股东权益被稀释 29–39%
```

> **注意：稀释在熊市情景中是复合性的——公司越困难，越需要发股；股价越低，同样的融资额稀释越多股份。这是一个正反馈的价值毁灭循环。**

### 触发 4：x86 份额加速流失 🔴🔴

| 竞争来源 | 威胁程度 | 说明 |
|---|---|---|
| AMD（服务器 EPYC） | 🔴🔴🔴 | 毛利率 53.06% 说明其产品定价力强于英特尔 |
| ARM（AWS Graviton / NVDA Grace） | 🔴🔴🔴 | 云厂商自研 CPU，直接绕过英特尔 |
| Apple（M 系列） | 🔴🔴 | 已完全脱离，PC 份额永久损失 |
| RISC-V | 🔴 | 长期威胁，短期影响有限 |

```
关键事实：AMD 不拥有晶圆厂，毛利率却比英特尔高 14.2 个百分点。
         这说明英特尔的产品竞争力问题独立于制造能力问题。
         即使制程追上，产品定价力未必恢复。
```

### 触发 5：AI 让 CPU 的价值份额缩小 🔴🔴

```
传统服务器 BOM：CPU ≈ 30–40%
AI 服务器 BOM：  CPU ≈  5–10%，GPU ≈ 60–70%

即使 AI 服务器出货量翻倍，
CPU 的绝对价值池增长也远低于 GPU。

英伟达 TTM 收入 $2,534.9 亿 = 英特尔的 4.4 倍
```

> **"AI 需求推动英特尔收入增长"这一叙事的天花板，比市场想象的低得多。**

### 触发 6：估值倍数均值回归 🔴🔴🔴

```
当前 PS 8.16（历史 100% 分位，六年均值 3.59）

若 PS 回到六年均值：股价 = $40.62（−56.0%）
若 PS 回到 FY2024 低点 1.66：股价 = $18.78（−79.7%）
若 PS 回到 2.0（熊市假设）：股价约 $22（收入不变）

历史先例：FY2023 → FY2024，PS 一年内跌 57.7%，
         而同期收入只下降 2.1%。
```

**这是熊市情景中最容易发生、也最快发生的因素——估值可以在几个月内崩塌，而基本面需要数年。**

### 触发 7：财务约束触发恶性循环 🔴🔴

```
Altman Z-Score 2.23（灰色地带）
利息保障倍数 −0.07（EBIT 不足以付利息）
净债务 −$205.6 亿
Debt/FCF 17.85

若信用评级被下调：
  → 融资成本上升
    → 利息支出增加
      → EBIT 更难覆盖利息
        → 需要更多股权融资
          → 更多稀释
```

## 四、熊市情景的下限保护

即使转型完全失败，英特尔仍持有以下有价值的资产：

| 资产 | 估计价值 | 说明 |
|---|---|---|
| 晶圆厂与设备 | $500–800 亿账面 | 但变现价值远低于账面（专用性强） |
| x86 专利组合 | $100–200 亿？ | 授权价值可观 |
| 封装技术（Foveros/EMIB） | 未知 | 有实际客户需求 |
| Mobileye 等持股 | 未知 | 可变现 |
| 国家安全地位 | 无法量化 | **政府可能再次注资——但注资=稀释** |

> ### 🔑 下限保护的悖论
>
> **英特尔的下限保护主要来自政府支持——但政府支持的形式是股权注入（FY2025 已发生 $134.77 亿）。**
>
> **这意味着：拯救公司的行为本身就是稀释股东的行为。**
>
> **通用汽车与房利美的先例：公司被救活了，原股东的权益被大幅稀释或归零。**
>
> **这就是本报告将熊市情景每股价值设为 $15 而非更低的理由——公司大概率不会破产；但也不设得更高的理由——股东权益会被稀释。**

## 六、熊市情景的概率评估

**本报告给予 30% 概率，理由如下：**

| 支持高概率的因素 | 支持低概率的因素 |
|---|---|
| 🔴 代工客户的结构性障碍难以克服 | 🟢 收入已恢复增长 +7.47% |
| 🔴 共识已预期 FY2026 FCF 转负 | 🟢 毛利率在持续恢复 |
| 🔴 稀释先例已存在（FY2025 +13.28%） | 🟢 政府支持提供生存下限 |
| 🔴 估值倍数处历史 100% 分位 | 🟢 管理层执行力在改善 |
| 🔴 ROIC 3.42% < WACC 14.86% | 🟢 边际毛利率 87.2%，杠杆巨大 |
| 🔴 Altman Z 2.23，灰色地带 | 🟢 已净还债 $112.50 亿 |
| 🔴 AMD 无晶圆厂却毛利率更高 | 🟢 18A/14A 尚未给出结论 |

> **30% 不是"英特尔会破产"的概率，而是"转型未能达到市场当前定价所需水平，且估值大幅回归"的概率。**
>
> **考虑到当前估值处于历史最高分位、基本面仅恢复 36%、共识预期明年 FCF 转负，30% 是一个中性偏保守的估计。**
