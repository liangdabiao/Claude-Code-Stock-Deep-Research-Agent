## 三、市值增长的归因分解

### 分解方法：市值 = PS × 收入

| 时点 | PS | 收入 | 市值 |
|---|---|---|---|
| FY2024（谷底） | 1.66 | $53.101B | $88.15B |
| **当前** | **8.16** | **$57.032B** | **$465.42B** |
| 变化 | **+391.6%** | +7.4% | **+428.0%** |

```
情景 A：只有收入增长，PS 维持 1.66
  市值 = 1.66 × $57.032B = $94.67B
  相对 FY2024 增长 = +$6.52B

情景 B：只有 PS 扩张，收入维持 $53.101B
  市值 = 8.16 × $53.101B = $433.30B
  相对 FY2024 增长 = +$345.15B

实际增长 = $465.42B − $88.15B = +$377.27B

归因：
  收入增长贡献        +$  6.52B    1.7%
  估值倍数扩张贡献    +$370.75B   98.3%
```

```
市值增长归因：

估值扩张  ████████████████████████████████████████████████  98.3%
收入增长  █  1.7%
```

> ### 🔑 本报告对英特尔最核心的量化发现
>
> **过去两年英特尔市值增长的 98.3% 来自估值倍数扩张，只有 1.7% 来自收入增长。**
>
> **估值倍数是市场情绪的函数，可以在几个月内逆转（如 FY2023 的 PS 3.92 在一年内跌至 1.66，−58%）。收入是基本面的函数，变化缓慢。**
>
> **当一只股票的涨幅 98% 依赖情绪，它的下跌也会 98% 依赖情绪。**

## 四、估值倍数的历史波动性

| 财年 | PS | 年度变化 |
|---|---|---|
| FY2021 | 2.64 | — |
| FY2022 | 1.73 | **−34.5%** |
| FY2023 | 3.92 | **+126.6%** |
| FY2024 | 1.66 | **−57.7%** |
| FY2025 | 3.42 | +106.0% |
| **当前** | **8.16** | **+138.6%** |

> **英特尔的 PS 倍数在过去五年内经历了 −57.7%、+126.6%、+138.6% 的剧烈波动。**
>
> **这不是一只估值稳定的股票。当前 8.16 倍是历史最高，是 FY2024 低点的 4.9 倍。**
>
> **如果 PS 回到五年均值（约 3.6 倍），在收入不变的前提下，股价将是 $92.32 × (3.6 / 8.16) = $40.7。**

## 六、员工与生产率趋势

| 项目 | FY2021（估算） | 当前 | 变化 |
|---|---|---|---|
| 员工数 | ~121,100 | 85,100 | **−29.7%** |
| 收入 | $79,024M | $57,032M | −27.8% |
| 人均收入 | ~$652,551 | $670,176 | **+2.7%** |
| 人均利润 | ~$164,062 | **−$132,656** | 🔴 转负 |

> **裁员 29.7% 与收入下降 27.8% 几乎同步，人均收入基本持平（+2.7%）。**
>
> **这说明裁员是"收缩到匹配收入规模"，而不是"生产率提升"。真正的效率改善应当表现为人均收入显著提升。**

## 七、趋势总结：三条曲线的赛跑

```
曲线 A：基本面复苏  — 已完成约 36%，速度中等，方向确定
曲线 B：股价/估值    — 已完成 223%（相对 FY2021 峰值市值），速度极快
曲线 C：股本稀释     — 加速中，TTM +13.28%

三条曲线的关系：
  B 大幅跑赢 A  →  估值透支
  C 持续侵蚀 A 的每股价值  →  复苏的收益被稀释掉一部分
```

| 判断 | 结论 |
|---|---|
| 基本面在改善吗？ | 🟢 **是，确定无疑，且是多维同步的** |
| 改善的速度足以支撑股价吗？ | 🔴 **不能。36% vs 223%** |
| 改善会持续吗？ | 🟡 **短期会，FY2026 共识预期收入 +11.61%** |
| 有什么在抵消改善？ | 🔴 **13.28% 的年股本稀释** |
| 什么会让趋势逆转？ | PS 倍数从 8.16 均值回归；FY2026 FCF 转负兑现；代工客户迟迟不来 |
