## 二、盈利与现金流交叉验证（强制项）

| 财年 | 净利润 | 经营现金流 | **OCF/NI** | 自由现金流 | **FCF/NI** |
|---|---|---|---|---|---|
| FY2021 | 19,868 | 29,456 | 1.48 | +9,127 | 0.46 |
| FY2022 | 8,014 | 15,433 | 1.93 | −9,411 | 负 |
| FY2023 | 1,689 | 11,471 | **6.79** | −14,279 | 负 |
| FY2024 | −18,756 | 8,288 | 负/负 | −15,656 | 负 |
| FY2025 | −267 | 9,697 | 负/负 | −4,949 | 负 |
| **TTM** | **−11,289** | **14,936** | **负/负** | **+2,831** | **负** |

### 🟢 正面结论：现金流质量优于利润

**净利润与经营现金流的巨大背离方向是"现金流好于利润"，这是良性的。** 原因是：

```
TTM 现金流重构：
  净利润（现金流表口径）        −$11,192M
  + 折旧摊销                    +$12,379M
  + 股权激励                    +$ 2,393M
  + 其他调整（减值等非现金）     +$19,691M   ← 关键项
  ────────────────────────────────────────
  经营现金流                    +$14,936M
```

**$196.91 亿的"其他调整"是资产减值、递延税项等非现金损失。这意味着 TTM 的巨额净亏损中，绝大部分不消耗现金。**

### 🔴 但有三个必须提出的质疑

**质疑一：减值不是一次性的，是年年发生的**

| 财年 | 其他调整（非现金） |
|---|---|
| FY2021 | +$1,168M |
| FY2022 | −$9,086M |
| FY2023 | −$2,466M |
| FY2024 | **+$11,629M** |
| FY2025 | −$2,722M |
| **TTM** | **+$19,691M** |

> **FY2024 减值 $116 亿，TTM 再减值 $197 亿。两年累计 $313 亿。**
>
> **"非现金损失"不代表"不是真实损失"——它代表过去投出去的现金已经确认打了水漂。会计上它是非现金的，因为现金在几年前就花掉了。**

**质疑二：自由现金流转正 100% 由资本开支削减贡献**

```
TTM 自由现金流 = OCF $14,936M − Capex $12,105M = +$2,831M

反事实检验：若资本开支维持 FY2023 峰值 $25,750M：
  FCF = $14,936M − $25,750M = −$10,814M   ← 深度负值

若维持 FY2025 水平 $14,646M：
  FCF = $14,936M − $14,646M = +$290M      ← 勉强打平

结论：$136.45 亿的资本开支削减，是自由现金流转正的唯一原因。
```

**质疑三：分析师预期 FY2026 自由现金流立刻转负 −$18.3 亿**

> **市场共识（40 位分析师）预期 FY2026 自由现金流 −$18.3 亿，FY2026 净利润 −$18.6 亿（GAAP）。**
>
> **也就是说：连最看好英特尔的卖方，都不认为"自由现金流转正"能持续到明年。**

| 项目 | TTM | FY2025 | FY2024 | FY2023 | FY2022 | FY2021 | **五年累计** |
|---|---|---|---|---|---|---|---|
| 自由现金流 | +2,831 | −4,949 | −15,656 | −14,279 | −9,411 | +9,127 | **−32,337** |
| 股息 | 0 | 0 | −1,599 | −3,088 | −5,997 | −5,644 | **−16,328** |
| 回购 | −242 | −423 | −631 | −534 | −486 | −2,415 | **−4,489** |
| **股票发行** | **+707** | **+13,477** | +987 | +1,042 | +977 | +1,020 | **+17,503** |
| 净长期债务 | −11,250 | −3,750 | +687 | +10,968 | +1,564 | +2,474 | **+11,943** |
| 资产出售 | +4,222 | +6,157 | 0 | 0 | +6,579 | 0 | **+12,736** |

### 🔑 五年现金缺口的填补方式

```
FY2021–FY2025 累计自由现金流：      −$32,337M   （烧掉 323 亿）
FY2021–FY2025 累计股息+回购：       −$20,817M   （又发出 208 亿）
─────────────────────────────────────────────
五年累计现金缺口：                  −$53,154M

填补来源：
  股票发行                          +$17,503M   （33%）
  净新增长期债务                     +$11,943M   （22%）
  资产出售                          +$12,736M   （24%）
  动用存量现金 + 其他融资            +$10,972M   （21%）
```

> ### 🔴 结论
>
> **英特尔在五年内烧掉了 $323 亿自由现金流，同时还向股东发出 $208 亿股息和回购。这 $532 亿的缺口，100% 由稀释股东、举债和变卖资产填补。**
>
> **与甲骨文的对比很有意思：甲骨文用债务给股东发钱（伤害债权人的安全边际）；英特尔用股票给自己续命（直接伤害现有股东的每股价值）。两种都不是内生的股东回报。**

## 四、股本稀释：被忽视的价值毁灭

| 财年 | 期末股本（亿股，估算） | 回购收益率/稀释率 |
|---|---|---|
| FY2021 | ~40.9 | **+3.36%**（回购） |
| FY2022 | ~41.2 | −0.81% |
| FY2023 | ~42.1 | −2.16% |
| FY2024 | ~42.8 | −1.61% |
| FY2025 | ~45.3 | −5.84% |
| **当前** | **50.4** | **−13.28%** |

```
五年股本变化：40.9 亿股 → 50.4 亿股 = +23.3%
过去 12 个月稀释：+13.28%   ← 极高
```

### 稀释的代价：一个反事实计算

```
假设英特尔完全恢复到 FY2021 的盈利能力（净利润 $19,868M）：
  用当前 50.4 亿股：EPS = $19,868M / 5,040M = $3.94
  FY2021 实际 EPS：                          $4.86
  ────────────────────────────────────────────
  差异：−18.9%
```

> ### 🔑 关键洞察
>
> **即使英特尔完美复活、利润完全回到历史巅峰，每股收益也只有当年的 81%。**
>
> **稀释已经永久性地拿走了 19% 的上行空间。而且稀释仍在继续——FY2025 单年就发行了 $134.77 亿股票。**
