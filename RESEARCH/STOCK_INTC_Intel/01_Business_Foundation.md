## 三、商业模式：IDM（垂直整合制造商）

英特尔是全球少数几家同时进行**芯片设计**与**先进制程制造**的公司。

```
                英特尔 IDM 模式
    ┌──────────────────────────────────────┐
    │  设计（CCG / DCAI）                   │
    │    ↓                                 │
    │  制造（Intel Foundry）                │  ← 同时对外开放
    │    ↓                                 │
    │  封装测试                             │
    │    ↓                                 │
    │  销售给 OEM / 云厂 / 企业             │
    └──────────────────────────────────────┘

对比：
  台积电    = 纯代工（只制造，不设计，不与客户竞争）
  AMD/NVDA  = 纯设计（Fabless，制造外包给台积电）
  英特尔    = 两者都做  ← 既是优势也是根本矛盾
```

### IDM 模式的双面性

| 🟢 优势 | 🔴 劣势 |
|---|---|
| 设计与制造协同优化 | **资本开支极重**（FY2023 达 $257.50 亿） |
| 供应链自主可控 | **固定成本高**，收入下滑时毛利率暴跌 |
| 国家安全价值（美国本土产能） | **外部客户不愿把芯片交给竞争对手制造** |
| 制程领先时可获得双重利润 | **制程落后时双重承压**（产品和制造同时输） |

> ### 🔑 IDM 模式的根本矛盾
>
> **英特尔要求潜在代工客户（如 AMD、高通、英伟达）把自己最核心的芯片交给一个同时在产品市场上竞争的对手来制造。**
>
> **这是台积电"不与客户竞争"这一立身之本的反面。它是英特尔代工业务最大的结构性障碍，且无法通过技术进步解决。**
>
> ⚠️ **公平的反面**：英特尔已宣布将代工业务作为独立子公司运营，并设立独立董事会，正是为了缓解这一矛盾。此外，地缘政治压力（客户希望供应链多元化、减少对台湾的依赖）为英特尔提供了台积电没有的政治动力。

### 关键观察

**🟢 拐点是真实的**：
- 收入五年来首次正增长（+7.47%），且为**近 15 年最快**
- 毛利率从 32.66% 谷底回升 6.21 个百分点
- 营业利润从 −$116.78 亿收窄至 −$0.77 亿，几乎打平

**🔴 但离恢复还很远**：
- 收入 $570.32 亿仍比 FY2021 的 $790.24 亿低 **27.8%**
- 毛利率 38.87% 仍比 FY2021 的 55.45% 低 **16.58 个百分点**
- 营业利润 −$0.77 亿 vs FY2021 的 +$194.56 亿

> **英特尔恢复了"活着"，但没有恢复"赚钱"。**

## 五、TTM 净亏损的构成（重要）

```
收入                        $57,032M
毛利润                      $22,017M   （毛利率 38.60%）
─────────────────────────────────────
营业利润 (EBIT)             −$    77M   ← 经营层面基本打平
非经营性损益                −$ 9,773M   ← 减值、投资亏损等（隐含）
─────────────────────────────────────
税前利润                    −$ 9,850M   （税前利润率 −17.28%）
所得税费用                  −$ 1,340M   ← 亏损仍缴税
─────────────────────────────────────
净利润                      −$11,289M   （净利率 −19.79%）
```

> ### 🔑 关键判断
>
> **$112.89 亿净亏损中，约 87% 发生在营业利润线以下。经营业务本身已接近盈亏平衡。**
>
> **多头解读**：剔除一次性项目，英特尔实际上已经不亏钱了。
>
> **空头反驳**：现金流量表的"其他调整"项显示 TTM +$196.91 亿、FY2024 +$116.29 亿的非现金加回——**"一次性"减值在英特尔是年年发生的常态。把它们全部剔除等于假设未来永不再发生减值，而过去五年没有一年做到过。**

⚠️ **数据矛盾提示**：stockanalysis.com 的 Statistics 页显示营业利润 $4.46B（营业利润率 7.82%），而 Financials 页显示 TTM 营业利润 −$77M（−0.14%）。经交叉验证（EBITDA $12.30B − D&A $12.38B = −$0.08B），**本报告采用 −$77M 作为 GAAP 口径**。$4.46B 可能为非 GAAP 调整后口径。**已在 [sources/bibliography.md](sources/bibliography.md) 记录。**

## 六、股权结构：一个不寻常的股东名单

| 项目 | 数值 |
|---|---|
| 流通股 | **5.04B**（同比 **+13.28%**） |
| 自由流通股 | 4.58B（90.9%） |
| **内部人持股** | **0.08%** 🔴 极低 |
| 机构持股 | 68.03% |
| FY2025 股票发行 | **$13,477M** |

> **FY2025 单年 $134.77 亿的股票发行是英特尔历史上最大规模的股权融资之一。** 根据公开报道，其中包含美国政府、软银、英伟达等战略投资者的入股（C 级证据，未取得 SEC 文件确认）。

### 这带来了三个结构性变化

| 变化 | 影响 |
|---|---|
| 🟢 **"大到不能倒"** | 美国政府成为股东后，英特尔破产的政治可能性极低。**这是一个真实的下行保护** |
| 🟢 **战略客户绑定** | 若英伟达等确为股东，可能带来代工订单的政治动力 |
| 🔴 **股东利益稀释** | 一年 13.28% 的稀释直接摊薄每股价值 |
| 🔴 **决策可能非商业化** | 政府股东可能优先考虑就业与产能布局，而非资本回报率 |

> **内部人持股仅 0.08% 是一个显著的治理弱点——管理层与股东的利益绑定极弱。** 详见 [05_Governance_Analysis.md](05_Governance_Analysis.md)。

## 七、客户与价值链位置

> ⚠️ **本报告未能取得客户集中度数据（SEC 10-K 不可得）。以下为基于行业常识的定性描述，属 C 级。**

| 环节 | 英特尔的位置 |
|---|---|
| 上游 | ASML（EUV 光刻机）、应用材料、东京电子等设备商——**议价能力弱，EUV 是卖方市场** |
| **自身** | 设计 + 制造（IDM） |
| 下游（CCG） | 戴尔、惠普、联想等 PC OEM——**议价能力中等，但 AMD 提供了替代选项** |
| 下游（DCAI） | 超大规模云厂（AWS/Azure/GCP）、企业服务器——**议价能力弱，云厂已在自研 ARM 芯片** |
| 下游（Foundry） | 外部代工客户——**目前规模有限，是整个转型故事的关键未知数** |

### 🔴 价值链位置的结构性恶化

```
2015 年的英特尔：
  制程领先 2 代 → PC 与服务器 CPU 近乎垄断 → 定价权 → 55%+ 毛利率

2026 年的英特尔：
  制程落后台积电 → AMD 抢份额 + ARM 进入数据中心 + 云厂自研芯片
  → 定价权丧失 → 38.87% 毛利率
```

**英特尔失去的不是某个产品的竞争力，而是整条价值链上的议价地位。**
