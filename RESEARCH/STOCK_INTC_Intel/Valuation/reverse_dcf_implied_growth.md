# 反向 DCF：市场在为英特尔定价什么？ — Intel (INTC)

---

## 一、方法说明

反向 DCF 不预测未来，而是回答一个问题：

> **"以当前价格买入，市场隐含地假设了公司未来必须实现什么？"**

采用戈登永续增长模型的简化形式：

```
企业价值 (EV) = 永续自由现金流 (FCF) / (WACC − g)

变形：
永续自由现金流 = EV × (WACC − g)
```

**英特尔的输入参数**：
| 参数 | 数值 | 来源 |
|---|---|---|
| 企业价值 EV | **$486,222M** | stockanalysis 统计页 |
| WACC | **14.86%** | stockanalysis 统计页 |
| 永续增长率 g | 3.0%（假设） | 长期名义 GDP 增速 |

## 三、三个刺眼的对照

### 对照 1：与英特尔自己的历史最好水平比

```
市场要求（实际 WACC）：$576.66 亿永续自由现金流
英特尔历史最高年度 FCF：$91.27 亿（FY2021，x86 垄断的最后一年）

要求 / 历史峰值 = 6.32 倍
```

> **当前价格要求英特尔永续每年产生的自由现金流，是它在垄断地位下最好一年的 6.32 倍。**

### 对照 2：与全球最强晶圆厂比

```
台积电 TTM 自由现金流：$353.4 亿
市场对英特尔的要求：   $576.7 亿

要求 = 台积电当前 FCF 的 1.63 倍
```

> **市场在为英特尔定价"它将变得比今天的台积电更能产生现金"。**
>
> **而台积电的 ROIC 是 54.61%，毛利率 64.23%，资本开支 $469 亿（英特尔的 3.9 倍），且在制程上领先。**

### 对照 3：与分析师自己的预测比

```
市场（价格）隐含要求：      永续 FCF +$576.66 亿
40 位分析师 FY2026 共识预测：      FCF −$18.30 亿

差距：$594.96 亿，方向相反。
```

> **卖方一边给出 $115.65 的目标价（高于现价 25%），一边预测明年自由现金流是负的。这两个数字无法用同一个估值模型调和。**

## 四、从收入端反推：需要多大规模？

假设英特尔达到成熟期的自由现金流利润率（对标同业），倒推所需收入：

| 假设 FCF 利润率 | 参照 | **所需永续收入（WACC 14.86%）** | 所需收入（WACC 10%） |
|---|---|---|---|
| 4.96%（英特尔 TTM） | 当前 | **$1,162,621M**（$1.16 万亿） | $686,210M |
| 11.55%（英特尔 FY2021） | 峰值 | **$499,272M** | $294,684M |
| 20%（假设优秀执行） | — | **$288,330M** | $170,180M |
| 25.32%（台积电 TTM） | 台积电水平 | **$227,749M** | $134,423M |
| 46.98%（英伟达 TTM） | 英伟达水平 | $122,746M | $72,448M |

### 参照基准

```
英特尔 TTM 收入：           $   57.03B
英特尔历史峰值（FY2021）：   $   79.02B
台积电 TTM 收入：           $  139.57B
英伟达 TTM 收入：           $  253.49B
全球半导体行业总收入（估算）：约 $700B
```

> ### 🔑 反向 DCF 的核心结论
>
> **即使假设英特尔达到台积电级别的自由现金流利润率（25.32%）——这需要毛利率从 38.87% 升到 64% 级别——它仍需要 $2,277 亿的年收入才能支撑当前企业价值。**
>
> **$2,277 亿是英特尔当前收入的 4.0 倍、历史峰值的 2.9 倍、台积电当前收入的 1.6 倍。**
>
> **即使用极度宽容的 10% WACC，所需收入仍为 $1,344 亿——接近台积电当前的规模。**

## 五、时间维度：多久能实现？

假设英特尔要在 N 年内从 TTM 的 $28.31 亿 FCF 增长到隐含要求的水平：

| 目标 FCF | 5 年所需 CAGR | 10 年所需 CAGR | 15 年所需 CAGR |
|---|---|---|---|
| $576.66 亿（WACC 14.86%） | **82.9%** | **35.1%** | **21.9%** |
| $340.36 亿（WACC 10%） | **64.3%** | **28.2%** | **17.9%** |
| $291.73 亿（WACC 9%） | **59.5%** | **26.3%** | **16.8%** |

```
参照：过去五年英特尔的 FCF CAGR 为负（FY2021 $91.27 亿 → TTM $28.31 亿，−20.9%）
```

> **要在 10 年内达到市场隐含的要求，英特尔需要实现 35.1% 的自由现金流年复合增长率，持续十年。**
>
> **而过去五年，英特尔的自由现金流年复合增速是 −20.9%。**

## 六、与其他公司的反向 DCF 交叉对照

| 公司 | EV | WACC | 隐含永续 FCF (g=3%) | TTM 实际 FCF | **要求/实际** |
|---|---|---|---|---|---|
| **INTC** | $486.22B | 14.86% | **$57.67B** | $2.83B | **20.4×** 🔴 |
| AMD | $842.62B | 17.76% | $124.34B | $8.57B | 14.5× 🔴 |
| **TSM** | $1.81T | 10.94% | **$143.61B** | $35.34B | **4.1×** 🟡 |
| **NVDA** | $4.97T | 16.37% | **$664.99B** | $119.08B | **5.6×** 🟡 |

```
市场要求 / 当前实际 FCF：

INTC  ████████████████████  20.4×   ← 要求最激进
AMD   ██████████████  14.5×
NVDA  █████  5.6×
TSM   ████  4.1×   ← 要求最温和
```

> ### 🔑 交叉对照的意义
>
> **在四家公司中，英特尔的价格隐含了最激进的假设——要求当前自由现金流增长 20.4 倍。**
>
> **而台积电只要求 4.1 倍，且台积电的自由现金流是真实、稳定、正在增长的。**
>
> **换言之：如果一个投资者认为 AI 半导体的长期前景很好，他可以用"只要求 4.1 倍"的价格买台积电，而不必用"要求 20.4 倍"的价格买英特尔。**

⚠️ **方法论说明**：戈登模型对高增长早期企业（如 NVDA）本身不适用，会高估其要求。此表的价值在于**相对比较**，而非绝对判断。

## 七、反向 DCF 结论

| 问题 | 答案 |
|---|---|
| 市场隐含的永续 FCF 要求？ | **$576.66 亿**（WACC 14.86%）/ **$291.73 亿**（WACC 9%） |
| 相对英特尔历史峰值？ | **6.32 倍** / 3.20 倍 |
| 相对台积电当前 FCF？ | **1.63 倍** / 0.83 倍 |
| 需要多大收入规模？ | **$2,277 亿**（假设台积电级利润率） |
| 需要多快的增速？ | **10 年 35.1% CAGR**（过去五年是 −20.9%） |
| 与卖方自己的预测一致吗？ | 🔴 **不一致。共识 FY2026 FCF 为 −$18.3 亿** |
| 同业中最激进吗？ | 🔴 **是。20.4× vs 台积电 4.1×** |
| **反向 DCF 合理性评分** | **1.0 / 5** 🔴 |

> ### 最终判断
>
> **反向 DCF 是本报告认为英特尔当前价格不可辩护的最强证据。**
>
> **无论对 WACC、永续增长率做出多么宽容的假设，当前价格都要求英特尔达到它历史上从未接近过的现金生成能力——通常还要求超过今天的台积电。**
>
> **一个正在从亏损中恢复、ROIC 低于资金成本、每年稀释股东 13.28% 的企业，被定价为未来的现金流之王。**
