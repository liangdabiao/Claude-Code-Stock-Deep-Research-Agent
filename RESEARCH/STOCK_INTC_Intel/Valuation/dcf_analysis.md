# DCF 估值分析 — Intel (INTC)

> ⚠️ **重大方法论警告**：英特尔当前 GAAP 净利润为 −$112.89 亿，分析师共识预期 FY2026 自由现金流为 −$18.3 亿。**这意味着预测期内的现金流几乎全部为负或接近零，DCF 的价值 100% 由终值假设决定。**
>
> **本 DCF 应被视为"赔率结构的框架"，而非"精确的价格"。收入或利润率假设变动 10%，估值结果变动可达 ±30–40%。**

---

## 一、估值方法选择

| 方法 | 是否适用 | 原因 |
|---|---|---|
| PE 估值 | ❌ | 当前 GAAP 亏损，无 PE |
| DCF（现金流折现） | 🟡 部分适用 | 预测期现金流为负，价值全在终值 |
| **EV/EBITDA 终值法** | ✅ **主要方法** | EBITDA $123 亿为正，可建模 |
| PS 估值 | 🟡 辅助 | 不反映盈利能力差异 |
| PB / 重置成本法 | 🟡 辅助 | 重资产企业，账面价值有意义 |
| **三情景概率加权** | ✅ **核心框架** | 二元性极强的转型标的必须用情景法 |

**本报告采用：以 FY2030 为目标年，构建三情景 EV/EBITDA 终值模型，加回期间累计现金流，扣除净债务，按概率加权。**

## 五、赔率结构评估

```
理想的投资赔率：上行 ≥ 2 × 下行，且盈利概率 ≥ 50%

英特尔：
  上行 +78.7%，下行 −83.7%   →  赔率 0.94 : 1
  盈利概率 25%，亏损概率 75%
  期望回报 −16.3%

判定：负期望值的赌注。
```

### 与 $50 入场价的对比

```
若在 $50 买入（相对现价 −45.8%）：

  牛市 $165：+230.0%
  基准 $ 70：+ 40.0%
  熊市 $ 15：− 70.0%

  加权期望 = 165×25% + 70×45% + 15×30% = $77.25
  相对 $50 = +54.5%   ← 正期望值

  盈利概率 = 70%（牛市 + 基准）
  上下行比率 = 230 / 70 = 3.29 : 1   ← 优秀
```

> ### 🔑 本报告最实用的一个结论
>
> **英特尔这门生意本身并不"不值得投资"——问题完全在于价格。**
>
> **在 $50 附近，同样的三情景假设给出 +54.5% 的期望回报和 3.29:1 的赔率；在 $92.32，给出 −16.3% 的期望回报和 0.94:1 的赔率。**
>
> **投资者面对的不是"英特尔会不会成功"，而是"以什么价格下注"。**

## 七、与市场共识的差异对账

| 项目 | 卖方共识 | 本报告 | 差异原因 |
|---|---|---|---|
| 目标价 | $115.65 | **$77** | −33% |
| 估值方法 | 非 GAAP EPS × PE | 三情景概率加权 EV/EBITDA | 方法不同 |
| FY2026 EPS 口径 | $1.12（非 GAAP） | GAAP 净利润 −$18.6 亿 | 🔴 关键差异 |
| 是否建模股本稀释 | 通常不 | ✅ 基准 58 亿股 / 熊市 70 亿股 | 🔴 关键差异 |
| 转型成功概率 | 隐含较高 | 25% | 判断差异 |
| 自由现金流 | 自家预测 −$18.3 亿 | 与之一致 | — |

> ### 🔑 对账中最重要的一点
>
> **卖方共识本身是自相矛盾的：同一页面既预测 FY2026 GAAP 净利润 −$18.6 亿、自由现金流 −$18.3 亿，又给出 $115.65 的平均目标价。**
>
> **这个目标价只能通过"非 GAAP EPS × 行业 PE"得出，而非 GAAP EPS 系统性排除了股权激励（$23.93 亿/年）、重组费用、资产减值（两年 $313 亿）等真实的股东成本。**
>
> **本报告选择使用 GAAP 与现金流口径，因此结论保守得多。**

## 八、DCF 估值结论

| 结论项 | 数值 / 判断 |
|---|---|
| **加权公允价值** | **$77** |
| **相对现价 $92.32** | **−16.3%** |
| 亏损概率 | **75%** |
| 上下行比率 | **0.94 : 1** 🔴 |
| 要证明当前价格合理需要 | FY2030 收入 $1,120 亿 或 20× EV/EBITDA |
| **30% 安全边际入场价** | **$54** |
| **建议观察区间** | **$49 – $56** |
| 在 $50 的期望回报 | **+54.5%**，赔率 3.29:1 🟢 |
| **估值评分** | **1.5 / 5** 🔴 |

> ### 最终判断
>
> **DCF 的结论与反向 DCF、历史分位、同业对比三条独立路径高度一致：当前价格没有安全边际，且赔率结构为负。**
>
> **但同样重要的是：本 DCF 的牛市情景是真实存在的（25% 概率、+78.7% 回报）。英特尔不是一个"必然失败"的公司，而是一个"以错误价格交易的、可能成功的公司"。**
>
> **这两者的区别决定了正确的操作是"等待价格"，而不是"永久回避"。**
