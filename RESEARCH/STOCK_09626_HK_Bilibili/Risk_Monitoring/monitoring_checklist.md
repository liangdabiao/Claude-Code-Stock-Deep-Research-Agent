# 哔哩哔哩投资监控清单

## 📋 监控概览

**监控目的**: 及时识别投资风险与机会
**监控频率**: 季度深度评估 + 月度跟踪 + 日常关注
**起始日期**: 2025年3月8日

---

## 🎯 红旗风险预警系统

### 🔴 一级红旗 (立即行动)

**定义**: 可能导致投资逻辑失效的重大风险

#### 红旗1: 用户增长崩塌

**触发条件**:
- MAU连续2个季度下滑超2%
- DAU连续2个季度下滑超2%
- DAU/MAU比值连续下降

**影响**: 核心投资逻辑(用户增长)失效

**应对措施**:
1. 立即评估持仓合理性
2. 分析下滑原因(竞争vs自身)
3. 考虑减仓或退出

**监控数据源**:
- 公司财报 (MAU/DAU)
- QuestMobile (第三方验证)
- APP Store排名 (日活趋势)

#### 红旗2: 游戏业务失败

**触发条件**:
- 游戏收入连续2个季度下滑超20%
- 核心游戏流水连续下滑
- 无新游戏上线或版号获取停滞

**影响**: 收入增长引擎失效

**应对措施**:
1. 评估游戏管线质量
2. 分析行业环境(版号政策)
3. 重新估值(无游戏增长情景)

**监控数据源**:
- Sensor Tower (游戏排名)
- 公司财报 (游戏收入)
- 新闻报道 (版号动态)

#### 红旗3: 广告业务失速

**触发条件**:
- 广告收入增速降至15%以下
- 广告eCPM连续下滑
- 核心广告主流失

**影响**: 变现能力恶化

**应对措施**:
1. 分析广告市场环境
2. 评估vs竞争对手表现
3. 考虑减仓

**监控数据源**:
- 公司财报 (广告收入)
- 行业报告 (广告市场)
- 竞争对手对比

#### 红旗4: 社区生态恶化

**触发条件**:
- 月均互动量连续下滑
- UP主流失率上升
- 用户投诉量激增

**影响**: 核心护城河受损

**应对措施**:
1. 深度分析原因
2. 评估管理层应对能力
3. 考虑退出

**监控数据源**:
- 公司财报 (互动数据)
- 第三方监测 (UP主活跃度)
- 社交媒体舆情

## 🟠 二级风险 (密切监控)

**定义**: 可能影响业绩但不致命的风险

### 风险1: 管理层变动

**监控点**:
- 陈睿及其他高管变动
- 关键岗位人员流失
- 继任者计划

**数据源**: 公司公告、新闻报道

### 风险2: 监管政策变化

**监控点**:
- 游戏版号政策
- 青少年保护政策
- 内容审核标准
- 反垄断监管

**数据源**: 政府公告、行业新闻

### 风险3: 竞争加剧

**监控点**:
- 抖音、快手新策略
- 用户时长争夺
- UP主/主播争夺
- 价格战

**数据源**: 竞争对手动态、行业报告

### 风险4: 技术颠覆

**监控点**:
- AI技术进展
- AIGC对内容创作的影响
- 新平台/新形式出现

**数据源**: 技术新闻、行业研究

## 🚨 应急预案

### 情景1: 股价暴跌 (单日-15%以上)

**立即行动**:
1. 分析暴跌原因(财报vs行业vs宏观)
2. 检查基本面是否变化
3. 评估是否加仓机会

**决策树**:
```
基本面未变 → 考虑加仓
基本面恶化 → 减仓或退出
无法判断 → 观望
```

### 情景2: 财报暴雷 (亏损超预期)

**立即行动**:
1. 分析亏损原因(一次性vs持续性)
2. 评估管理层应对措施
3. 调整未来预期

**决策树**:
```
一次性因素 → 保持或加仓
持续性恶化 → 减仓
无法判断 → 减半仓位
```

### 情景3: 竞争对手推出竞品

**立即行动**:
1. 评估竞品威胁程度
2. 分析B站应对能力
3. 监控用户/UP主流向

**决策树**:
```
威胁有限 → 保持
威胁严重 → 减仓
无法应对 → 退出
```
