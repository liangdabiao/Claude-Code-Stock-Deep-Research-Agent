### 8.1 ⭐⭐ 冲突 1 的解决：杠杆化 vs 非杠杆化自由现金流

**这个 86.9% 的差异如果不解决，会导致完全错误的结论。**

| 步骤 | 数据 |
|---|---|
| 预测页 FY2025 FCF | **$6.86B** |
| 现金流量表 FY2025 FCF（OCF − 资本开支） | **$12,820M** |
| **现金流量表 FY2025 杠杆化 FCF（Levered FCF）** | **$6,852M** |
| **6,852 vs 6,860 的偏差** | **✅ 0.12%** |

# ✅✅ **解决：预测页使用的是杠杆化自由现金流（Levered FCF），不是标准 FCF。**

**这个发现改变了对预测的解读：**

| | 预测页原文 | 正确的对照基数 | 真实含义 |
|---|---|---|---|
| FY2026E FCF | **$11.67B** | 不能对照 FY2025 的 $6.86B | |
| **TTM 杠杆化 FCF** | | **$11,886M** | |
| **FY2026E vs TTM** | 11,670 vs 11,886 | | **🔴 −1.8%** |

# ⚠️⚠️ **如果直接把 $11.67B 与 $6.86B 对比，会得出"FCF 增长 +70%"的错误结论。**
