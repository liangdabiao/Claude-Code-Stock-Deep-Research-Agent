## 二、⭐⭐ Fabless 模式的数据证据

高通不自建晶圆厂。这不是从描述中读到的，而是从资本结构中算出来的：

| 指标 | QCOM | **对照：INTC（本项目已完成报告）** |
|---|---|---|
| 资本开支 / 营收 | **🟢 4.01%** | **🔴 超过 30%** |
| 资本开支 / OCF | **🟢 12.48%** | **🔴 超过 100%（需举债）** |
| 资本开支 / 折旧摊销 | **🟢 1.132×** | 🔴 远超 2× |
| FCF 利润率 | **🟢 28.10%** | 🔴 为负 |

# ⭐⭐ **资本开支/折旧 = 1.132× 是本报告的关键判别指标。**

**这个比率的含义：**
- **< 1.0×** = 公司投入低于资产折旧速度 → 产能在萎缩
- **≈ 1.0×** = 维持性投入，无扩张
- **> 2.0×** = 大规模扩张

**高通 = 1.132×：仅比维持性水平高 13.2%。**

# 🔑 **高通几乎没有在做产能扩张性投资。**
# 🔑 **这既是优点（资本轻、现金多），也是限制（无法通过投资买增长）。**

**六年资本开支合计仅 $96.16 亿，同期 OCF $714.30 亿 —— 资本开支只吃掉 13.46% 的经营现金流。**

## 三、⭐⭐⭐ 行业周期定位：高通处在周期的什么位置？

**用营收增速刻画周期：**

| 财年 | 营收增速 | 周期判读 |
|---|---|---|
| FY2021 | **+42.65%** | 🟢🟢 **繁荣顶点（缺芯潮）** |
| FY2022 | **+31.68%** | 🟢 繁荣尾声 |
| FY2023 | **🔴 −18.96%** | 🔴🔴 **衰退谷底（库存去化）** |
| FY2024 | +8.77% | 🟢 复苏 |
| FY2025 | +13.66% | 🟢 复苏加速 |
| **TTM** | **+5.21%** | 🟡 **复苏减速** |
| **FY2026E** | **🔴 −3.86%**（31 位分析师） | 🔴 **再次转负？** |

# ⚠️ **这是一个完整的半导体周期：繁荣（FY21-22）→ 衰退（FY23）→ 复苏（FY24-25）→ 减速（TTM）→ 预测转负（FY2026E）。**

**关键判断：高通处在复苏的尾声，而非中段。**

**三条佐证：**

| 佐证 | 数据 |
|---|---|
| 1. 增速已从 +13.66% 降至 +5.21% | **减速 61.9%** |
| 2. 31 位分析师中位预测 FY2026 营收 **−3.86%** | 最乐观的分析师也只给 **+0.6%** |
| 3. **TTM 营收（44,487）几乎与 FY2022 峰值（44,200）持平** | 复苏已经把营收带回上一轮峰值，进一步上行需要**新的需求**，而非周期修复 |

# 🔑 **周期修复的空间已经用完。高通的营收已经回到上一轮峰值。**
# 🔑 **从这里开始的任何增长，必须来自结构性的新需求（汽车、AI 数据中心），而不是库存补充。**

## 五、⭐⭐ 行业竞争格局

⚠️ **数据源未提供市场份额数据。以下竞争分析基于可验证的财务对照，不基于份额估计。**

### 5.1 对照组：博通 AVGO

| 指标 | **QCOM** | **AVGO** | 差距 |
|---|---|---|---|
| 营收 | $444.87 亿 | **$754.7 亿** | AVGO **+69.6%** |
| **毛利率** | 54.80% | **🟢 76.28%** | **AVGO 高 21.48pp** |
| 营业利润率 | 25.52% | **🟢 44.17%** | AVGO 高 18.65pp |
| 净利率 | 22.31% | **🟢 38.85%** | AVGO 高 16.54pp |
| **FCF 利润率** | 28.10% | **🟢 43.41%** | AVGO 高 15.31pp |
| **3 年营收增速** | **🔴 4.42%** | **🟢 53.38%** | **AVGO 高 12.1 倍** |
| ROIC | **🟢 32.74%** | 24.22% | **QCOM 高 8.52pp** |
| ROE | 39.42% | 37.28% | QCOM 略高 |
| **有效税率** | 15.19% | **🟢 3.81%** | AVGO 低 11.38pp |
| 资本开支/营收 | 4.01% | **🟢 1.14%** | AVGO 更轻 |

# ⭐⭐ **关键发现：高通在资本效率（ROIC 32.74% vs 24.22%）上胜出，在盈利能力和增长上全面落后。**

**为什么 ROIC 更高却更便宜？**

| QCOM | AVGO |
|---|---|
| PE 18.24 | **PE 63.56** |
| P/FCF **14.08** | P/FCF **55.46** |
| PEG **5.83** | PEG **0.53** |

# 🔑 **答案在 PEG。市场为 AVGO 的 53.38% 三年增长付 63.56 倍 PE；为 QCOM 的 4.42% 增长只付 18.24 倍。**
# 🔑 **两者的 PEG（0.53 vs 5.83）显示：按增长调整后，AVGO 比 QCOM 便宜 11 倍。**

⚠️ **PEG 是一个粗糙指标，不应单独作为结论。但 11 倍的差距远超指标本身的误差范围。**

### 5.2 ⭐ AVGO 的一个隐藏问题（对照分析的公平性）

**为公平起见，必须指出 AVGO 的估值也有其脆弱之处：**

| AVGO 指标 | 数值 | 观察 |
|---|---|---|
| 报告 FCF | $327.6 亿 | 资本开支仅 $8.60 亿 |
| **折旧摊销** | **$87.5 亿** | **是资本开支的 10.2 倍** |
| **正常化 FCF（OCF − D&A）** | **$248.7 亿** | 比报告 FCF **低 24.1%** |
| P / 报告 FCF | 55.46× | |
| **P / 正常化 FCF** | **🔴 73.2×** | **高 32%** |

# ⚠️ **AVGO 的资本开支仅为折旧的 9.8% —— 它的资产在以远快于重置的速度折旧（主要是并购形成的无形资产摊销）。**
# 🔑 **按正常化口径，AVGO 的 P/FCF 是 73.2×，而不是 55.46×。**

**同样口径下的高通：**

| | 报告 FCF | 正常化 FCF | 差异 |
|---|---|---|---|
| **QCOM** | $125.02 亿 | **$127.10 亿** | **🟢 仅 +1.66%** |
| **AVGO** | $327.6 亿 | $248.7 亿 | **🔴 −24.1%** |

# ⭐⭐⭐ **高通的报告自由现金流与正常化自由现金流只差 1.66% —— 它的现金流不需要任何调整就是真的。**
# 🔑 **这是本项目迄今为止最干净的现金流数据。MU、INTC、ORCL 的两个口径都相差 30%–100% 以上。**

**修正后的对照：**

| | P / 正常化 FCF |
|---|---|
| **QCOM** | **🟢 13.85×** |
| **AVGO** | **🔴 73.2×** |

**按正常化现金流，高通比博通便宜 5.3 倍。这是多头最强的论据。**
⚠️ **但它没有回答一个问题：便宜 5.3 倍，是因为增长慢 12.1 倍。**

⚠️ **两条报道都存在，但数据源中**没有任何数据中心业务的收入数字**。分部披露中也不存在这一项。**

| 判断 | 依据 |

# 🔑 **结论：数据中心是一个期权，不是一个业务。它可能值很多钱，但今天它在财务上不存在。**
**本报告在超级牛市情景（10% 概率，$260）中为其赋值，在基准情景中赋值为零。**

### 叙事 2：汽车（🟢 有数字，且优秀）

⚠️ **但增速已从 FY2024 的 +55.45% 降至 TTM 的 +12.81%。**

### 叙事 3：涨价（🟡 刚刚发生，方向未定）

**[Reuters, 2026-07-25 前后, "Qualcomm tells customers of double-digit price increases", https://stockanalysis.com/stocks/qcom/, 来源质量: C]**
**[TheFly, 同期, "Qualcomm raising prices double digits on higher costs", 同上, 来源质量: C]**

# ⭐ **这条新闻有双重解读，且方向相反：**

| 🟢 多头解读 | 🔴 空头解读 |
|---|---|
| 能涨价 = 有定价权 = 护城河存在 | 标题里写的是 **"on higher costs"（因成本上升）** |
| 双位数涨价将直接改善 FY2027 营收 | **成本转嫁 ≠ 定价权**。若涨价只是为了保住毛利率，则不增厚利润 |
| | 涨价可能加速客户自研替代 |

**关键判别数据（待 2026-07-29 财报）：**

# 🔑 **如果毛利率在涨价后回升至 56% 以上 → 是定价权。**
# 🔑 **如果毛利率停留在 54.8% 附近 → 只是成本转嫁。**

**这已被写入监控清单。**
