# 第三阶段：业务拆解 — 高通 QUALCOMM (QCOM)

**数据截止 2026-07-24 | 单位：百万美元**

---

## 一、⭐⭐ 利润引擎在哪里？

高通**不披露分部利润**，只披露分部营收。因此本报告用**反推法**估算利润归属。

### 1.1 已知条件

| 项目 | TTM |
|---|---|
| 总营收 | 44,487 |
| 毛利 | 24,379 |
| **综合毛利率** | **54.80%** |
| QTL 营收 | 5,701（12.81%） |
| QCT 营收（手机+汽车+IoT） | 38,503（86.55%） |

### 1.2 ⭐ 反推：QTL 的毛利率必须多高？

**QTL 是纯授权业务，其成本极低。假设 QTL 毛利率为 X，QCT 毛利率为 Y：**

`5,701 × X + 38,503 × Y + 283 × Y ≈ 24,379`

**情景 A：假设 QTL 毛利率 = 98%（授权业务的典型上限）**

| 项目 | 计算 | 结果 |
|---|---|---|
| QTL 毛利 | 5,701 × 98% | **5,587** |
| 剩余毛利归 QCT | 24,379 − 5,587 | **18,792** |
| **QCT 毛利率** | 18,792 ÷ 38,786 | **🔴 48.45%** |

**情景 B：假设 QTL 毛利率 = 90%**

| 项目 | 计算 | 结果 |
|---|---|---|
| QTL 毛利 | 5,701 × 90% | 5,131 |
| 剩余毛利归 QCT | 24,379 − 5,131 | 19,248 |
| **QCT 毛利率** | 19,248 ÷ 38,786 | **49.63%** |

# ⭐⭐ **结论：无论 QTL 毛利率取 90% 还是 98%，QCT 的毛利率都在 48%–50% 之间。**

**这个推算的验证价值：**

| 观察 | 含义 |
|---|---|
| QCT 毛利率 ≈ 49% | 对 Fabless 芯片设计公司是**优秀水平**（对照 AVGO 76.28% 含大量软件） |
| **QTL 用 12.81% 的营收贡献了约 22.9% 的毛利**（情景 A） | **QTL 的毛利贡献是其营收占比的 1.79 倍** |
| **QTL 萎缩 10.33% 对毛利的伤害是营收伤害的 1.79 倍** | **这就是毛利率从 57.84% 降至 54.80% 的机制** |

### 1.3 ⭐ 用毛利率变化反向验证这个推算

**如果 QTL 占比下降是毛利率下滑的主因，那么两者应该数量上吻合：**

| | FY2022 | TTM | 变化 |
|---|---|---|---|
| QTL 占营收 | 14.39% | 12.81% | **−1.58pp** |
| 综合毛利率 | 57.84% | 54.80% | **−3.04pp** |

**假设 QTL 毛利率 98%、QCT 毛利率不变，QTL 占比下降 1.58pp 应导致毛利率下降：**

`1.58% × (98% − 49%) = 1.58% × 49% = **0.77pp**`

| 项目 | 数值 |
|---|---|
| QTL 占比下降可解释的毛利率下滑 | **0.77pp** |
| 实际毛利率下滑 | **3.04pp** |
| **可解释比例** | **🟡 25.3%** |
| **剩余 2.27pp 需其他解释** | **🔴 74.7%** |

# ⚠️ **重要发现：QTL 占比下降只能解释毛利率下滑的 25.3%。**
# 🔑 **剩下 74.7%（2.27pp）必须来自 QCT 自身毛利率的下降 —— 即芯片业务的定价能力在减弱。**

**反推 QCT 毛利率的变化：**

| | FY2022 | TTM |
|---|---|---|
| QCT 营收 | 37,677 | 38,503 |
| QTL 毛利（98% 假设） | 6,231 | 5,587 |
| 总毛利 | 25,565 | 24,379 |
| **QCT 毛利** | **19,334** | **18,792** |
| QCT + 调节项营收 | 37,842 | 38,786 |
| **QCT 毛利率** | **🟢 51.09%** | **🔴 48.45%** |
| **变化** | | **🔴 −2.64pp** |

# ⭐⭐⭐ **QCT（芯片）的毛利率从 51.09% 降至 48.45%，下降 2.64pp。**
# 🔑 **这与"涨价新闻"形成直接矛盾 —— 一家毛利率在下滑的公司宣布涨价，"on higher costs"的解释更可信。**

⚠️ **本节全部为推算，基于 QTL 毛利率 98% 的假设。若真实 QTL 毛利率更低，QCT 毛利率的下滑幅度会更小。请将此视为方向性结论，不是精确值。**

## 三、⭐⭐⭐ FCF/净利润 = 125.98% 的完整拆解

**这是本报告最重要的财务发现。它必须被完整解释，否则不能作为多头论据。**

| 桥接项 | 金额 | 性质 | 是否真实增厚股东价值？ |
|---|---|---|---|
| 净利润 | 9,923 | 起点 | — |
| **+ 折旧摊销 1,575** | +1,575 | 非现金 | **🟡 部分** — 需与资本开支比较 |
| **+ 股权激励 3,071** | +3,071 | 非现金 | **🔴 否** — 稀释股东，是真实成本 |
| + 其他/营运资本 | −284 | | |
| = OCF | **14,285** | | |
| **− 资本开支 1,783** | −1,783 | 真实现金流出 | ✅ 已扣除 |
| **= FCF** | **12,502** | | **125.98% 的净利润** |

### 3.1 ⭐ 三重检验：这 125.98% 有多少是真的？

**检验 1：折旧 vs 资本开支**

| 项目 | 金额 |
|---|---|
| 折旧摊销（加回） | +1,575 |
| 资本开支（扣除） | −1,783 |
| **净额** | **🟢 −208** |

# ✅ **检验 1 通过：高通扣除的资本开支比加回的折旧还多 $2.08 亿。**
# 🔑 **这意味着 FCF 没有依靠"折旧加回大于实际投入"来虚增 —— 恰恰相反，它被略微低估了。**

**这与本项目此前分析的 MU、INTC、ORCL 形成鲜明对比 —— 那些公司的资本开支远超折旧，报告 FCF 被严重压低；而更常见的情况（如 AVGO）是折旧远超资本开支，报告 FCF 被虚增。**

**检验 2：正常化 FCF**

| 口径 | 计算 | 金额 | 利润率 |
|---|---|---|---|
| 报告 FCF | OCF − 资本开支 | 12,502 | 28.10% |
| **正常化 FCF** | **OCF − 折旧摊销** | **12,710** | **28.57%** |
| **差异** | | **+208** | **🟢 仅 +1.66%** |

# ⭐⭐⭐ **两个口径只差 1.66%。**
# 🔑 **在本项目分析过的所有公司中，这是唯一一家两个口径几乎相等的。MSFT 相差 57.5%，INTC 相差 100% 以上。**
# ✅ **含义：高通的自由现金流不需要任何"正常化调整"就是真实的。DCF 不需要双口径。**

**检验 3：股权激励**

| 项目 | 金额 | 占比 |
|---|---|---|
| SBC | **3,071** | 占营收 **🔴 6.90%** |
| | | 占 OCF **🔴 21.50%** |
| | | 占净利润 **🔴 30.95%** |
| **SBC 调整后 FCF** | 12,502 − 3,071 = **9,431** | 占营收 **21.20%** |
| **SBC 调整后 FCF / 净利** | 9,431 ÷ 9,923 | **🟡 95.04%** |

# ⚠️ **检验 3 是唯一的扣分项：扣除股权激励后，FCF/净利从 125.98% 降至 95.04%。**
# 🔑 **SBC 占经营现金流的 21.50% —— 每 5 美元经营现金流中有超过 1 美元是"用股票支付的工资"。**

**但股权激励并非纯粹损失，因为高通用现金回购抵消了稀释：**

| | 金额 |
|---|---|
| SBC（稀释） | +3,071 |
| 股票回购（反稀释） | −11,777 |
| **净回购** | **🟢 −8,706** |
| **股份数 YoY** | **🟢 −3.65%** |

✅ **股份数实际下降 3.65%，证明回购规模远超稀释。稀释被完全中和，且有余。**

### 3.2 三重检验的综合结论

| 检验 | 结论 |
|---|---|
| 1. 折旧 vs 资本开支 | **🟢 通过** — FCF 被略微低估而非高估 |
| 2. 正常化口径 | **🟢 通过** — 两口径仅差 1.66% |
| 3. 股权激励 | **🟡 部分通过** — 扣除后为 95.04%，且稀释被回购完全中和 |

# ✅ **综合结论：FCF/净利 = 125.98% 是真实的，其中约 30.94pp 来自折旧与股权激励的加回。**
# 🔑 **保守使用的数字是 SBC 调整后的 95.04% —— 即使按最严口径，高通的现金转换率仍接近 1:1，这在半导体行业中属优秀。**

## 五、⭐⭐ TTM 的返还强度是历史最高

| 财年 | 回购 | 分红 | 合计 | FCF | **返还/FCF** |
|---|---|---|---|---|---|
| FY2021 | 4,103 | 3,008 | 7,111 | 8,648 | **🟢 82.2%** |
| FY2022 | 3,895 | 3,212 | 7,107 | 6,834 | 🟡 104.0% |
| FY2023 | 3,494 | 3,462 | 6,956 | 9,849 | **🟢 70.6%** |
| FY2024 | 5,053 | 3,687 | 8,740 | 11,161 | **🟢 78.3%** |
| FY2025 | 9,906 | 3,805 | 13,711 | 12,820 | 🟡 107.0% |
| **TTM** | **11,777** | **3,820** | **15,597** | **12,502** | **🔴 124.76%** |

# ⚠️⚠️ **返还率从 FY2023 的 70.6% 升至 TTM 的 124.76%，两年半提高 54.2 个百分点。**

**扣除股权激励后（更严格口径）：**

| 财年 | 回购 − SBC + 分红 | FCF | **调整后返还/FCF** |
|---|---|---|---|
| FY2021 | 4,103−1,663+3,008 = 5,448 | 8,648 | **🟢 63.0%** |
| **TTM** | 11,777−3,071+3,820 = **12,526** | 12,502 | **🔴 100.19%** |

# ⭐⭐⭐ **SBC 调整后，TTM 返还 = 自由现金流的 100.19%。留存恰好为零。**
# 🔑 **FY2021 时这个数字是 63.0%。高通用了五年，把留存率从 37% 压到 0%。**

**这意味着什么？**

| 解读 | 论证 |
|---|---|
| 🟢 **多头解读** | 管理层承认没有高回报的再投资机会，把钱还给股东是**正确的资本配置** |
| 🔴 **空头解读** | 这个水平**在数学上不可持续**。要么增长回来，要么返还下调 |
| ⚠️ **本报告立场** | **两者都对。** 这是一个理性的短期决策，但它同时是"没有增长机会"的证据 |

# 🔑 **最关键的推论：股东回报率 5.85% 是当前估值的主要支柱。若返还回落至 FY2021 的 63% 水平，股东回报率将降至约 3.68%，估值支柱消失。**

## 七、⭐ 单位经济：股份回购的实际效果

| 指标 | 数值 |
|---|---|
| TTM 回购金额 | **$117.77 亿** |
| 净回购（扣 SBC） | $87.06 亿 |
| **净回购 / 市值** | **🟢 4.95%** |
| 股份数 YoY | **🟢 −3.65%** |
| 股份数 QoQ | −0.65% |
| 回购收益率 | **🟢 3.65%** |

**回购的价格效率检验：**

| 项目 | 计算 | 结果 |
|---|---|---|
| TTM 回购金额 | 11,777 | |
| 股份减少比例 | 3.65% | |
| 当前股数 | 1,050M | |
| 推算减少股数 | 1,050 ÷ (1−3.65%) − 1,050 | **≈ 39.8M 股** |
| **推算平均回购价** | 11,777 ÷ 39.8 | **≈ $296/股** |

⚠️ **这个推算值 $296 远高于当前股价 $166.97。**

**但必须谨慎解读：**
- 股份数变化同时受回购（减少）和 SBC 发行（增加）影响
- 净减少 39.8M 股 = 回购股数 − 新发行股数
- 若用净回购金额 $87.06 亿 ÷ 39.8M = **≈ $219/股**，仍高于现价

# 🟡 **方向性结论：高通过去一年的回购均价高于当前股价 —— 回购在价格上并不划算。**
⚠️ **这是推算，不是精确值。真实回购均价需 10-Q 披露，本报告无法获取。但即使按最保守口径（$219），也高于现价 31%。**

**对照 FY2024：回购收益率为 **−0.36%**（即净增发），当年股价 $170.13。**
**FY2025 回购收益率 2.21%，TTM 3.65% —— 回购在股价下跌时加速，这一点是正面的。**
