## 二、⭐⭐⭐ 必须回答的三个问题

### 问题 1：一家三年半零增长的公司，凭什么值 18.24 倍 PE？

| 财年 | 营收（百万） | 增速 |
|---|---|---|
| FY2021 | 33,566 | +42.65% |
| **FY2022** | **44,200** | **+31.68%** |
| FY2023 | 35,820 | **🔴 −18.96%** |
| FY2024 | 38,962 | +8.77% |
| FY2025 | 44,284 | +13.66% |
| **TTM** | **44,487** | +5.21% |

# 🔑 **TTM 营收 $444.87 亿，比 FY2022 的 $442.00 亿高 0.65%。三年半，净增长 $2.87 亿。**
# 🔑 **中间的大起大落（−18.96% 然后 +13.66%），掩盖了一个事实：高通没有在增长，它在原地波动。**

**答案：** 它值 18.24 倍 PE 的理由只有一个 —— **现金**。FCF 收益率 7.10%、股东回报率 5.85%。
**但这个理由有一个上限：现金回报不能永远超过现金产生（见问题 3）。**

---

### 问题 2：⭐⭐ 为什么高通给 5.85% 的股东回报却只得到"持有"评级，而博通净稀释股东却得到"强烈买入"？

| | **QCOM** | **AVGO** |
|---|---|---|
| 股东总回报率 | **🟢 +5.85%** | **🔴 −0.36%** |
| 回购收益率 | **🟢 +3.65%** | **🔴 −1.04%** |
| 股份数 YoY | **🟢 −3.65%** | 🔴 +1.04% |
| **分析师共识** | **🔴 持有（36 位）** | **🟢 强烈买入（48 位）** |
| **3 年营收增速预测** | **🔴 4.42%** | **🟢 53.38%** |
| **3 年 EPS 增速预测** | **🔴 3.50%** | **🟢 56.12%** |
| **PEG** | **🔴 5.83** | **🟢 0.53** |

# ⭐⭐⭐ **答案：市场不为资本回报付钱，只为增长付钱。**
# 🔑 **这是本报告最重要的一条投资常识 —— 也是"高股息 + 低估值"陷阱的本质。**

⚠️ **对高通而言，这意味着：即使它把 100% 的现金还给股东，只要增长不恢复，估值倍数就不会扩张。**
✅ **对投资者而言，这意味着：买高通的回报只能来自"股息 + 回购 + 基本面缓慢增长"，不能指望估值提升。**

**这个总回报的量化：股息 2.20% + 回购 3.65% + 假设 EPS 增速 3.50% ≈ 9.35%/年（若估值不变）。**
**这是一个合理但不出色的预期回报 —— 而它要求估值"不变"，即当前的 PEG 5.83 被永久接受。**

### 问题 3：⭐⭐ 高通已经把 100% 的自由现金流还给了股东。然后呢？

| TTM 资本返还 | 金额（百万） |
|---|---|
| 股票回购 | **11,777** |
| 现金分红 | **3,820** |
| **合计** | **15,597** |
| **占自由现金流 $12,502** | **🔴 124.76%** |
| 扣除股权激励后（回购 − SBC + 分红） | **12,526** |
| **占自由现金流** | **⭐ 100.19%** |

# ⭐⭐ **在中性化股权激励后，高通返还给股东的现金恰好等于它产生的自由现金流的 100.19%。**
# 🔑 **留存 = 零。**

**与 FY2021 对比：**

| | FY2021 | **TTM** |
|---|---|---|
| SBC 调整后返还 / FCF | **63.0%** | **🔴 100.19%** |
| 净现金流 | +$4.09 亿 | **🔴 −$17.68 亿** |

⚠️ **TTM 净现金流为 −$17.68 亿 —— 高通正在动用现金储备维持这个返还水平。**

**答案：** 这个水平**不可持续**。要么增长回来（则可以继续），要么返还必须下调（则"5.85% 股东回报"这个唯一的多头理由消失）。
🔑 **这就是高通的核心风险：它的估值支柱是资本回报，而资本回报的支柱是不可持续的支付率。**

## 七、⭐⭐ FY2025 的会计异常（读财报前必须知道）

| 财年 | 税前利润率 | **净利率** | **推算有效税率** |
|---|---|---|---|
| FY2024 | 26.53% | 25.95% | **🔴 1.88%** |
| **FY2025** | **28.59%** | **🔴 12.51%** | **🔴 56.23%** |
| TTM | 26.30% | 22.31% | 15.19% |

# ⚠️ **FY2024 与 FY2025 连续两年出现极端税率异常。这两年的 EPS 都不可直接使用。**

**佐证：**
- FY2025 营业利润 **+22.68%**，净利润却 **−45.36%** —— 差异全部在税线以下
- FY2025 现金流量表"其他调整"为 **+$36.72 亿**（其余年份均为负），符合大额非现金税项加回
- FY2025 GAAP EPS **$5.01** vs 非 GAAP EPS **$12.03**，差额约 **$77.64 亿**，其中约 **92%** 可由推算的税项异常（约 $71.19 亿）解释

✅ **结论：FY2025 的利润崩塌是税务事件，不是经营恶化。经营现金流当年反而增长 14.83%。**
⚠️ **但这也意味着：任何以 FY2025 EPS 为基数的"复苏"叙事都是统计假象。**
