# Lumentum (LITE) — 熊市情景（Bear Case）

> 数据截至 2026-07-24 | 股价 $384.87 | 市值 $59.36B

---

## 一、熊市论点摘要

> **LITE 是一家四年收入负增长、毛利率仍低于五年前、连续三年经营亏损、TTM 净利润近半来自非经营性项目、一年稀释 21.84% 股本的公司，被市场以 23.85 倍市销率、520 倍市现率定价。**

熊市情景不需要"坏事发生"—— 它只需要**已经存在的现实被重新认识**。

---

## 二、七条独立的看空理由

### 1. 收入四年负增长（最硬的事实）

| 财年 | 收入 |
|---|---|
| FY2021 | $1,743M |
| FY2025 | $1,645M |
| **4 年 CAGR** | **−1.4%** |

TTM $1,864M 仅比五年前高 6.9%。**没有任何"超级周期"的痕迹出现在收入曲线上。**

### 2. 毛利率证伪了定价权叙事

TTM 毛利率 **35.05%**，低于 FY2021 的 **44.3%**，也低于同业 COHR 的 **36.99%**。

若 LITE 真的握有 1.6T EML 的稀缺供应，毛利率应当超越历史高点。它没有。

### 3. 净利润质量：46% 来自非经营性

```
营业利润   $237.1M
净利润     $438.2M
差额       $201.1M  ← 不可持续
```

用营业利润看，市值/营业利润 = **250 倍**。
再扣除 SBC $169.4M，"真实股东经营利润"仅 $67.7M → **877 倍**。

### 4. 现金流塌陷：FCF/NI = 0.26

TTM 自由现金流 $114.0M。P/FCF = **520.71**。
过去五个财年累计 FCF 仅 $860.3M —— 市值是它的 **69 倍**。

### 5. 股本一年稀释 21.84%

可转债转股导致股数暴增。**股价越涨，稀释越严重**（转股价被击穿越深，转股越有利）。这形成一个自我强化的负反馈：股价上涨 → 更多转股 → 每股价值摊薄 → 需要更高增长才能支撑股价。

同时，流动比率从 **4.37 骤降至 1.14**，短期偿付缓冲基本消失。

### 6. 不扩产 = 对需求不确信，或将失去下一代份额

| 公司 | Capex TTM |
|---|---|
| **LITE** | **~$103M** |
| COHR | $678.6M |
| AAOI | $240.1M |

在一个"供不应求"的周期里，LITE 的扩产强度是 COHR 的 **15%**。两种解释都不利：要么管理层不相信需求持续性，要么它将在 1.6T 世代的产能竞赛中出局。

### 7. 中国厂商的替代进程

400G 世代中国厂商（中际旭创、新易盛、华工科技、光迅科技）已实现规模替代。800G 正在进行。1.6T 的技术窗口通常为 18–24 个月。

LITE 的护城河本质是**认证周期的时间差**，而非结构性壁垒。每一次代际切换都重置竞争。

## 三、三层下行路径

### 路径 A：估值回归（最可能，无需基本面恶化）

只需要市场重新用 COHR 的标准给 LITE 定价：

```
LITE 收入 $1.86B × COHR PS 8.37 = 市值 $15.6B
每股 ≈ $101
下行：−74%
```

**触发条件**：一次不及预期的季报、一次 AI 资本开支的疑虑、一次整体风险偏好收缩。不需要公司出任何事。

### 路径 B：增长不及预期（中等概率）

若 FY2027 收入增速从当前 +13.3% 降至个位数，"超级周期"叙事直接破裂：

```
市场重定价至 PS 6–8 → 市值 $11–15B → 每股 $72–97
下行：−75% ~ −81%
```

### 路径 C：周期见顶 + 价格战（DCF 熊市情景）

AI 数据中心资本开支在 FY2027–FY2028 见顶，中国厂商在 1.6T 完成替代：

```
FY2030E 收入回落至 $2.5B，营业利润率 10%，FCF $175M
DCF 股权价值 ≈ $2.83B → 每股 ≈ $18
下行：−95%
```

## 五、熊市论点可能出错的地方（诚实的反面）

熊市论点会失效，如果：

1. **1.6T EML 供应瓶颈是真实且持久的** —— 铟磷衬底与 EML 外延产能扩张周期长达 2–3 年，若确实无法快速扩张，LITE 可以在这段窗口收取垄断租金。这需要看到**毛利率突破 45%**来确认。
2. **CPO / 硅光集成让 LITE 从器件商升级为子系统商** —— ASP 可能提升一个数量级，收入曲线非线性跳升。
3. **公司披露多年期锁量合同** —— 若与 Nvidia 或超大规模云厂签订 $5B+ 的多年协议，现金流可见性质变，估值框架需重建。
4. **市场愿意长期支付赛道溢价** —— 估值可以在很长时间内脱离基本面（这是熊市论点最大的实践风险：**做空正确的估值判断，可能死在错误的时点上**）。

⚠️ **重要提醒**：本报告识别出严重高估，**不等于建议做空**。空头占比已达 12.41%，轧空风险显著。估值高估可以持续数季度甚至数年。
