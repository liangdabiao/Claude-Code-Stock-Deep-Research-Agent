# Lumentum (LITE) — 数据来源说明与数据质量问题

> 研究执行日期：2026-07-26 | 数据截止：2026-07-24 收盘

---

## 一、数据获取方法

本次研究采用**串行直接页面抓取**方式（WebFetch），未使用并行子代理。每只标的的标准数据管线为 6 个端点：

```
1. /statistics/                          → 估值倍数、盈利能力、资产负债、市场数据
2. /financials/                          → 5 年利润表
3. /financials/cash-flow-statement/      → 5 年现金流量表
4. /financials/ratios/                   → 历史比率与估值区间
5. /forecast/                            → 分析师一致预期
6. /（主页）                              → 业务描述与近期新闻
```

同业对照另抓取 COHR、AAOI、MU 的 `/statistics/`。

## 二、🔴 已发现的数据矛盾（重要）

### 矛盾 1：Debt/Equity 两个页面读数不一致

| 来源页面 | Debt/Equity 读数 |
|---|---|
| `/statistics/` | **1.11** |
| `/financials/ratios/`（Current 列） | **0.02** |

**本报告的判定过程：**

```
已知：市值 = $59,361M，PB = 18.40
反推账面权益 = 59,361 ÷ 18.40 ≈ $3,226M

已知：公司有可转债与银行借款，总债务量级约 $3.3B
则 D/E ≈ 3,300 / 3,226 ≈ 1.02

→ 与 statistics 页的 1.11 高度吻合
→ ratios 页的 0.02 若成立，意味着总债务仅约 $65M，
  与该公司存在大额可转债的事实矛盾
```

**判定：采用 D/E = 1.11。ratios 页的 0.02 判定为数据错误。**

⚠️ 本判定基于反推，未经一手 10-K 核实。投资者应自行查阅资产负债表确认。

### 矛盾 2：净利润 > 营业利润（非数据错误，是真实的财务事实）

| 项目 | TTM |
|---|---|
| 营业利润 | $237.1M |
| 净利润 | $438.2M |

这**不是**数据错误，而是真实存在的会计结果：约 $201M 净利润来自营业利润之下的项目（非经营性收益、税项转回等）。

⚠️ 具体构成未能核实（SEC EDGAR 403）。本报告在所有相关章节将其标注为**推断**。

## 三、🔴 数据获取失败清单

| # | 尝试的来源 | 结果 | 影响的分析 |
|---|---|---|---|
| 1 | SEC EDGAR (`sec.gov/cgi-bin/browse-edgar`) | **HTTP 403 Forbidden** | 无法获取 10-K/10-Q 原文 → 无 A 级来源 |
| 2 | stockanalysis.com `/stocks/lite/holders/` | **HTTP 404** | **Phase 5 股权治理分析几乎无数据** |
| 3 | WebSearch（通用检索） | **API 错误：`output_config.effort 'xhigh' is not supported when thinking is disabled`**（重现 3 次） | 无法获取新闻、行业报告、券商观点 |

### 因此缺失的关键信息

| 缺失项 | 应在何处获取 | 对结论的影响 |
|---|---|---|
| 分部收入（Cloud & Networking / Industrial Tech） | 10-K 分部报告 | 🔴 **Phase 3 业务拆解基本为推断** |
| 客户集中度 | 10-K「Concentration of Credit Risk」 | 🔴 无法量化单客户风险 |
| 地区收入（中国占比） | 10-K 地区分部 | 🟡 无法量化地缘政治敞口 |
| 可转债条款（余额/转股价/到期） | 10-K「Convertible Notes」附注 | 🔴 **无法预测未来稀释规模** |
| $201M 非经营性收益构成 | 10-K「Other income」+ 税项附注 | 🔴 **Forward PE 60.60 的可信度存疑** |
| 内部人持股与 Form 4 交易 | SEC Form 4 | 🔴 **无法判断管理层是否高位减持** |
| 机构持股（13F） | 13F 备案 | 🟡 筹码结构未知 |
| 存货与应收账款明细 | 10-Q 资产负债表 | 🟡 营运资本质量未核实 |
| Backlog / 订单积压 | 财报电话会 | 🟡 收入可见性未知 |
| 实际 ROIC | 需从 10-K 计算 | 🟡 资本效率未量化 |

## 四、数据可信度分层

| 数据类别 | 可信度 | 说明 |
|---|---|---|
| **估值倍数**（PS/PE/PB/P-FCF） | 🟢 高 | 由市值与财务数据直接计算，多处交叉一致 |
| **TTM 财务数据**（收入/利润/FCF/SBC） | 🟢 高 | 来自 SEC 备案的结构化提取 |
| **FY2021–FY2025 收入与净利润** | 🟢 高 | 财报页直接披露 |
| **FY2021–FY2025 毛利/营业利润/现金流分项** | 🟡 中 | 部分为区间近似（报告中以 `~` 标注） |
| **同业对比数据**（COHR/AAOI） | 🟢 高 | 同一平台同日读数，口径一致 |
| **历史 PS/PB 区间** | 🟡 中 | 由历年市值与财务数据推算，非逐日统计 |
| **D/E = 1.11** | 🟡 中 | 存在页面矛盾，经反推判定 |
| **分部/客户/地区/治理** | 🔴 **无数据** | 全部为推断或空白 |
| **DCF / 反向 DCF 测算** | 🟡 中 | 输入数据可靠，但假设为本报告设定（已全部披露） |

## 五、本报告的自我约束

基于上述数据限制，本报告采取以下处理：

1. **所有量化结论**（估值倍数、现金流比率、增长率）均基于直接披露值，可追溯。
2. **所有涉及分部、客户、地区、治理、可转债条款的表述**，均明确标注为「推断」或「待补证据」，不作为事实陈述。
3. **未能获取的数据不作猜测填充** —— 05_Governance_Analysis.md 明确列示为证据缺口，而非用行业常识虚构。
4. **发现的数据矛盾（D/E）公开披露判定过程**，而非静默选择一个数字。
5. **核心结论的鲁棒性检验**：本报告的主结论（严重高估）依赖的是 PS 23.85、P/FCF 520.71、4 年收入 CAGR −1.4% 这三个数字。即使其他所有数据存在误差，只要这三项成立，结论方向不变。
